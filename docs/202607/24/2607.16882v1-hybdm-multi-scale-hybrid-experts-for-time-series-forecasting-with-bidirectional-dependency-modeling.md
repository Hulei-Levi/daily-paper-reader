## 摘要
时间序列预测（TSF）对众多应用至关重要，但现有模型通常难以捕捉多变量时间序列中异质的长范围全局模式和短范围局部变化。尽管有些方法部分建模了这些依赖关系，但它们往往不能同时利用时间和特征维度的信息。为解决这一挑战，我们提出了HyBDM，一种多尺度混合模型，将时序动态分解为全局模式和局部变化，由两个专门的专家分别建模。全局模式专家采用增强的BiConv-Mamba模块，集成了双向卷积、M-SSM层、遗忘机制和用于跨通道建模的GDD-MLP模块。局部变化专家使用局部窗口变换器（LWT），以降低的计算复杂度执行高效的局部感知注意力。此外，多尺度分块器和长-短路由器实现了多分辨率表示以及两个专家的自适应融合。在六个基准数据集上的实验表明，HyBDM在预测精度和计算效率上均优于最先进的方法，证明了其在桥接多变量TSF的全局-局部依赖关系方面的有效性。

## Abstract
Time series forecasting (TSF) is vital to many applications, yet existing models often struggle to capture the heterogeneous long-range global patterns and short-range local variations in multivariate time series. While some approaches partially model these dependencies, they often do not jointly exploit temporal and feature-wise information. To address this challenge, we propose HyBDM, a multi-scale hybrid model that decomposes temporal dynamics into global patterns and local variations, which are modeled by two specialized experts. The Global Patterns Expert employs an enhanced BiConv-Mamba module that integrates bidirectional convolutions, an M-SSM layer, a forgetting mechanism, and a GDD-MLP module for cross-channel modeling. The Local Variations Expert uses a Local Window Transformer (LWT) to perform efficient locality-aware attention with reduced computational complexity. In addition, a Multi-Scale Patcher and a Long-Short Router enable multi-resolution representations and adaptive fusion of the two experts. Experiments on six benchmark datasets show that HyBDM outperforms state-of-the-art methods in both forecasting accuracy and computational efficiency, demonstrating its effectiveness in bridging global-local dependencies for multivariate TSF.

- **长程全局模式（long-range global patterns）**：如季节性温度周期、经济趋势，反映可预测的宏观行为。
- **短程局部变化（short-range local variations）**：如需求突增、市场突然波动，体现瞬时波动。

现有方法面临的主要挑战包括：
- **RNN/LSTM** 因梯度消失难以捕捉长程依赖；
- **ARIMA** 只能处理线性模式，无法应对非线性动态；
- **CNN** 感受野有限，难以覆盖全局；
- **Transformer** 自注意力复杂度为二次方，计算昂贵；
- **SSM（状态空间模型，如Mamba）** 虽线性复杂度，但常混合长、短程效应，难以分辨；
- 现有混合模型（如CNN-RNN、分解Transformer）要么灵活性不足，要么固守刚性分解方案，难以适应动态的真实序列。

**核心问题**：如何在一个统一的框架下，**同时高效建模长程全局模式与短程局部变化**，并兼顾精度与计算效率。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
将时间序列视为**全局趋势 + 局部波动**的叠加，分别由两个专家模型处理，再通过路由器自适应融合。四大组件：**多尺度分片器（Multi-Scale Patcher）**、**全局模式专家（BiConv-Mamba）**、**局部变化专家（LWT）**、**长-短路由器（Long-Short Router）**。

### 关键技术细节

#### （1）多尺度分片器（Multi-Scale Patcher）
- 对输入序列 `x ∈ R^{L×M}` 进行分片（patch），全局专家使用**大块长度和大步长**生成低分辨率序列（强调长期趋势、滤除高频噪声）；局部专家使用**小块长度和小步长**保留精细波动。
- 给定 patch 长度 `P` 和步长 `Str`，块数 `N = ⌊(L - P)/Str⌋ + 1`，产生 `x^{(p)} ∈ R^{N×P}`，分辨率 `R_{PTS} = P·Str / P`。

#### （2）全局模式专家——BiConv-Mamba 模块
由三个子组件构成：
- **双向卷积（Bidirectional Convolutions）**：正向卷积提取 `x_f`，反向卷积提取 `x_b`，融合：`x = w_f · x_f + (1 - w_f) · x_b`，`w_f` 可学习。
- **M-SSM 层**：对经典 Mamba 的扩展，增加数据依赖的跳跃连接。状态更新：`h_t = A h_{t-1} + B x_t`，输出：`y_t = C h_t + D x_t`，其中 `D` 由输入动态生成。
- **遗忘机制（Forgetting Mechanism）**：计算门控 `gate_f = 1 - sigmoid(gate_b2)`，控制历史信息的保留：`Output = gate_f · x' + gate_b2 · y`，其中 `x'` 是主分支输出，`y` 是 M-SSM 输出。用于过滤噪声，适应非平稳序列。

#### （3）局部变化专家——局部窗口变换器（LWT）
- 将自注意力限制在大小为 `w` 的滑动窗口内，复杂度从 `O(S^2)` 降至 `O(wS)`。
- 通过堆叠多层 LWT，逐步扩大感受野，保留局部特异性，适合快速波动。

#### （4）长-短路由器（Long-Short Router）
- 对两个专家输出 `z_L`（全局）和 `z_S`（局部）进行自适应融合：
  ```
  p_L, p_S = softmax(W·z_R)
  z_LS = p_L · z_L + p_S · z_S
  ```
  其中 `z_R` 是路由表示（通常来自主分支编码），`W` 为可学习权重。模型可根据输入特征动态强调全局趋势或局部突变。

### 整体流程（文字说明）
1. 输入多变量时间序列 `X ∈ R^{L×M}`；
2. 经过多尺度分片器，生成全局专家用的低分辨率序列和局部专家用的高分辨率序列；
3. 全局专家通过 BiConv-Mamba（双向卷积 + M-SSM + 遗忘门）提取长程模式，再经 GDD-MLP 进行跨通道建模；
4. 局部专家通过 LWT 提取短程波动；
5. 长-短路由器根据输入特征为两个专家分配软权重，融合后输出最终预测 `[x_{L+1}, ..., x_{L+T}]`。

### 计算复杂度
HyBDM 整体保持线性复杂度 `O(L)`（BiConv-Mamba 为线性，LWT 为 `O(wS)`），远优于二次复杂度的 Transformer。

6. **路由器自适应融合有效**：模型能够在不同输入特性下动态平衡全局和局部专家，避免了固定权重的缺点。

## 7. 优点

- **创新性的专家分工设计**：将时间序列明确拆解为全局和局部依赖，分别用不同结构（SSM + 遗忘门 / 窗口注意力）建模，思路清晰。

- **多尺度分片器**使两个专家看到互补的分辨率，增强对多尺度信息的捕捉。
- **长-短路由器**提供动态权重，适应性更强。
- **实验覆盖多领域、多分辨率、高维数据**，验证了泛化能力。
- **计算复杂度保持线性**，优于二次复杂度的 Transformer。
- **消融实验直接对比 SST**，证明了改进模块的有效性。
