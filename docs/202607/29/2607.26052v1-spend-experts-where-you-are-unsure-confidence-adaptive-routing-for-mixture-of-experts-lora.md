## 摘要
低秩适配（LoRA）的混合专家（MoE）变体会将每个令牌路由到固定数量的专家 k。不同令牌在模型对其的不确定性上存在差异，因此固定的 k 会过度消耗简单令牌的资源，而对困难令牌的服务不足。我们观察到路由器的输出分布本身就是一个令牌级别的不确定性信号：尖峰分布表示置信，而平坦分布表示歧义。我们提出了 CARE（置信自适应专家路由），它以核心方式接纳专家。专家按照路由器权重的降序被激活，直到其累积质量达到一个阈值，当已接纳的专家意见不一致时会进行少量扩展。一个预算调节器校准该阈值，使得活跃专家的平均数量与任意目标匹配。CARE 是一种即插即用、单次前向传播的规则，无需额外参数。在 LLaMA-3.1-8B 和 Qwen2.5-7B 上的八个常识基准测试以及数学、代码和知识任务中，CARE 在匹配计算量的情况下优于固定的 top-k MoE-LoRA，并且与固定的 k=4 基线相匹配的同时激活更少的专家。相同的置信和分歧信号还改进了与 MSP、熵和多轮代理相比的分布外检测。我们通过核心保真度、预算最优性以及对分歧的认知解释来支持这一设计，并发布了代码。

## Abstract
Mixture-of-Experts (MoE) variants of Low-Rank Adaptation (LoRA) route every token to a fixed number of experts $k$. Tokens differ in how uncertain the model is about them, so a single k over-spends on easy tokens and under-serves hard ones. We observe that the router's output distribution is already a per-token uncertainty signal: peaked mass indicates confidence, while a flat distribution indicates ambiguity. We introduce CARE (Confidence-Adaptive Routing of Experts), which admits experts in a nucleus fashion. Experts are activated in decreasing router weight until their cumulative mass reaches a threshold, with a small extension when the admitted experts disagree. A budget thermostat calibrates the threshold so that the average number of active experts matches any target. CARE is a drop-in, single-forward-pass rule with no extra parameters. Across eight commonsense benchmarks on LLaMA-3.1-8B and Qwen2.5-7B, as well as math, code, and knowledge tasks, CARE improves over fixed top-k MoE-LoRA at matched compute and matches the fixed-k=4 baseline while activating fewer experts. The same confidence and disagreement signals also improve out-of-distribution detection over MSP, entropy, and multi-pass proxies. We support the design with nucleus fidelity, budget optimality, and an epistemic reading of disagreement, and we release code.

## 1. 核心问题与整体含义（研究动机和背景）

**研究动机**：在 Mixture-of-Experts LoRA（MoE-LoRA）中，传统方法为每个 token 固定激活相同数量的专家（如 top-k=4）。但不同 token 的难度差异很大：简单 token（如功能词）几乎不需要专家适配，而困难 token（如歧义词）则需要更多专家。固定 k 导致简单 token 计算浪费，困难 token 计算不足，从而限制了整体准确率。

**背景**：现有 MoE-LoRA 方法（LoRAMoE、MixLoRA、DynMoLE 等）均采用固定 top-k 路由；参数高效微调（PEFT）中的不确定性估计通常需要多次前向传播（如深度集成、MC-Dropout），成本高昂。论文识别到路由器输出分布本身包含 token 级别的置信度信息：若分布尖锐（一个或少数专家概率很高），表明模型对该 token 很确定；若分布平坦，则模型不确定。基于这一观察，论文提出可根据不确定性动态调整每个 token 激活的专家数量，从而在固定计算预算下提升性能，同时获得免费的不确定性信号。

## 2. 方法论的详细说明

**核心思想**：将专家数量决策视为一个不确定性驱动的分配问题。利用路由器 softmax 输出的概率分布作为每个 token 的置信度信号，并利用已激活专家输出之间的分歧作为认知不确定性信号，以核采样（nucleus sampling）的方式自适应地激活专家。

**关键技术细节**：

- **置信度信号（aleatoric）**：路由器输出分布 p 的集中程度。使用累积概率 C_k 来度量：高 p(1) 或小熵表示置信，需要少量专家；否则需要更多。
- **分歧信号（epistemic）**：当已激活的专家输出差异较大时，说明 token 仍存在歧义，需要额外专家。分歧定义为输出加权方差的归一化值。
- **核专家接纳**：按权重降序排序专家，依次激活直到累积概率达到阈值 τ（如 0.7）。此时激活的专家数记为 k_ν。
- **分歧扩展**：若已激活专家的分歧超过阈值 δ（如 0.55），则额外激活最多 γ（如 2）个专家，额外数量由分歧超过 δ 的程度线性缩放。
- **预算恒温器**：在少量验证集上通过二分法搜索 τ，使得整个数据集上的平均活跃专家数等于目标预算 B（如 4）。该 τ 在测试时固定使用。
- **不确定性读出**：对于序列级别的 OOD 检测，将每个 token 的路由熵和分歧按权重 w=0.5 混合，得到序列不确定性得分 u(x)。

**算法流程**（文字描述）：
1. 对每个 token，路由器计算输出分布 p。
2. 将 p 按降序排序，计算累积概率。
3. 找到最小 k 使得累积概率 ≥ τ，记为 k_ν。
4. 评估前 k_ν 个专家的分歧 D。
5. 若 D > δ，额外激活 ⌈γ·(D-δ)/(1-δ)⌉ 个专家，总数限制在 [k_min, k_max] 内（k_min=1, k_max=8）。
6. 实际激活 top-k 个专家，并用其归一化的路由权重加权求和输出。
