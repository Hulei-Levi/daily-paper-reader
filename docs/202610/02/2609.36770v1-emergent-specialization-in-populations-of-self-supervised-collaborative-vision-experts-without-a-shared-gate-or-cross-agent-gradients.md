## 摘要
一组神经网络能否在没有共享门控或智能体间梯度的情况下发展出有用的分工？我们研究这样一种设定：每个网络拥有自己的权重，在相同的异构数据上独立训练，并可通过一次前向传播向另一个智能体求助。与由联合训练的门控将输入分配给专家的专家混合不同，这里的专业化必须在没有中心控制的情况下涌现。我们在一个用于预测性视觉预训练的小规模代理任务中对此进行测试。最初相同的智能体在六个视觉域的无标签混合数据上进行微调，使用对冻结 DINOv3 特征的掩码预测。我们通过询问对某个输入而言最佳智能体是否与其潜在域一致来衡量专业化，并通过询问责任是否分布在各个智能体之间来衡量利用率。我们逐步移除中心控制，最终得到 DISCO（DIStributed COllaboration，分布式协作）：每个智能体在本地选择一个助手，通过无梯度通道读取其内部状态，并且仅因帮助所带来的改进而奖励其路由器。专业化得以涌现且有用。随机路由的群体表现不如单个通才，而语义路由的群体则优于它，表明收益由专业化而非群体规模驱动。没有中心路由器时专业化仍然存在，而无梯度通信使非专家能够利用涌现出的专长。在 DISCO 中，得到专家帮助的随机智能体可媲美单独的通才，而专家则超过它，包括在专业化混合数据之外的数据上也是如此。本地路由器在 98% 的输入上选择涌现出的专家。这些效应在群体规模、模型容量、数据不平衡和微调随机种子变化下均持续存在，为去中心化预测性预训练所需的动力学提供了可测量的证据。

## Abstract
Can a population of neural networks develop a useful division of labor without a shared gate or gradients between agents? We study a setting where each network has its own weights, trains independently on the same heterogeneous data, and can ask another agent for help through a forward pass. Unlike mixtures of experts, where a jointly trained gate assigns inputs to experts, specialization here must emerge without central control. We test this in a small scale proxy for predictive visual pretraining. Initially identical agents are finetuned on an unlabeled mixture of six visual domains using masked prediction of frozen DINOv3 features. We measure specialization by asking whether the best agent for an input aligns with its latent domain, and utilization by asking whether responsibility is distributed across agents. We progressively remove central control, ending with DISCO (DIStributed COllaboration) where each agent locally selects a helper, reads its internal state through a gradient free channel, and rewards its router only for the improvement that help provides. Specialization emerges and is useful. Randomly routed populations underperform a single generalist, while semantically routed populations outperform it, showing that specialization rather than population size drives the gain. Specialization persists without a central router, and gradient free communication lets nonexperts exploit emergent expertise. In DISCO, a random agent helped by the expert matches the solo generalist, while experts surpass it, including on data outside the specialization mixture. Local routers select the emergent expert for 98% of inputs. These effects persist across population size, model capacity, data imbalance, and finetuning seeds, providing measurable evidence for the dynamics needed by decentralized predictive pretraining.

- **核心问题**：一组初始相同的神经网络，能否在没有共享门控、没有跨智能体梯度、也没有中心控制器的条件下，自行形成有用的分工？

## 2. 方法论

- **核心思想**：逐步移除中心控制，形成“控制阶梯”：
  - Solo：单个通才模型。
  - Random：随机路由，同规模、同预算，但无语义。
  - K-means：用干净 DINOv2 特征离线聚类，作为特权正对照。
  - Learned central：一个共享在线路由器，用策略梯度训练。
  - Distributed delegation：每个智能体拥有自己的路由器，移除中心路由器。
  - **DISCO**：目标设定，每个智能体本地选助手，通过无梯度通道读取助手内部状态，并仅按“帮助带来的改进”奖励路由器。
- **专业化与利用率指标**：
  - 专家定义为某输入上损失最低的智能体 \(e(x)=\arg\min_i l(x,a_i)\)。
  - 专业化 \(Sp=\mathrm{NMI}(e(x),y)\)，衡量最佳智能体是否与潜在域 \(y\) 对齐。
  - 利用率 \(U=H(e(x))/\ln K\)，衡量责任是否分散，避免“一个智能体包揽一切”的假专业化。
- **DISCO 关键技术细节**：
  - 每个智能体有独立 LoRA 权重和本地路由头。
  - 每步随机抽一个 requester \(a_q\)，其路由器为每个样本选择 helper \(j\)，并排除自选。
  - 通信层中，requester 的 query 同时关注自己的 key/value 与 helper 的 key/value，但 helper 的 key/value 被 stop-gradient：
    \[
    A_{\text{helped}}=\mathrm{SoftMax}(Q_iK_{\text{cat}}^\top/\sqrt d)V_{\text{cat}},\quad
    K_{\text{cat}}=\mathrm{sg}[K_i;K_j],\quad V_{\text{cat}}=\mathrm{sg}[V_i;V_j]
    \]
  - helper 用重构损失 \(L_{\text{rec}}\) 训练；requester 用受助重构损失 \(L_{\text{helped}}\) 训练；路由器奖励为 requester 自身改进：
    \[
    R_i=\mathrm{sg}[l_{\text{solo}}(x_i,a_q)-l_{\text{helped}}(x_i,a_q,a_j)]
    \]
  - 总目标：\(L_{\text{DISCO}}=\lambda_{\text{rec}}L_{\text{rec}}+\lambda_{\text{router}}L_{\text{router}}+\lambda_{\text{helped}}L_{\text{helped}}\)。
  - 所有学习型路由器加入 KL 负载均衡项，防止路由坍塌到单一智能体。
- **评价方式**：训练用余弦距离，但性能用轻量检索代理 R-Top5：对隐藏位置预测特征，在同图 196 个真实 patch 特征中检索 5 近邻，统计真实位置命中率。报告专家包络 Best/Worst、路由后 Delegation、通信后 Collaboration、最差智能体受助后 Worst+help。
