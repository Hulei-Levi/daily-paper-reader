## Abstract
Mixture-of-Experts (MoE), popularized by large language models, is a promising paradigm for scaling visual generative models. However, conventional token-wise MoE routes tokens independently within a homogeneous expert pool and regularizes expert usage toward uniformity, making it poorly matched to video data that is spatiotemporally redundant and semantically long-tailed. We show that existing visual MoEs fall into a uniformity trap: semantically under-organized routing, compounded by uniform expert-usage regularization, scatters coherent patches across disparate experts, causing routing fragmentation and structural distortion. To address this, we propose SplitMoE, a split-role sparse architecture that breaks the shackles of uniformity. To accommodate the inherent semantic imbalance, we explicitly bifurcate the expert pool into semantic experts and generic experts, with semantic experts capturing high-level semantic abstraction and generic experts preserving residual visual information and flexible generative capacity. Leveraging prototype-guided routing and pull-push regularization, SplitMoE enables tokens to cluster naturally by semantic attributes rather than arbitrary balancing constraints. Extensive results show that under an equivalent activated-parameter budget, SplitMoE outperforms traditional load-balanced MoEs in convergence speed, routing coherence, and video generation quality across standard benchmarks. By revealing an emergent coarse-to-fine denoising logic, SplitMoE provides the community with a modality-aware scaling path, serving as a critical reference for building large-scale video world models.

## 1. 核心问题与整体含义

- **研究背景**：Diffusion Transformer（DiT）在高质量视频生成中表现突出，但参数扩展成本高。MoE 通过稀疏激活解耦总容量与计算量，是扩展视觉生成模型的重要路径。
- **核心问题**：现有视觉 MoE 多直接沿用语言模型设计，采用 token-wise 独立路由，并通过负载均衡损失强制专家使用趋于均匀。论文认为这会造成“**均匀性陷阱**”（uniformity trap）。
- **视频数据的特殊性**：视频 token 具有强时空冗余、空间连续性和语义长尾分布，与离散、相对高熵的语言 token 不同。强制均匀路由会把同一语义区域的连贯 patch 分散到不同专家，同时让背景冗余 patch 主导多个专家。
- **后果**：出现路由碎片化、时空不一致、结构失真、时间抖动、空间条带和语义碎片等问题。
- **整体含义**：论文提出 SplitMoE，将专家池按角色拆分为“语义专家”和“通用专家”，打破均匀使用约束，使 token 按语义属性自然聚类。该工作为视频扩散模型提供了一条模态感知的稀疏扩展路径，可作为大规模视频世界模型构建的参考。

## 2. 方法论

### 2.1 核心思想

- 将标准同质专家池拆分为两个不相交子集：
  - **语义专家**：捕获高层语义抽象、对象结构和全局布局。
  - **通用专家**：保留残差视觉信息、局部外观和高频细节，维持灵活生成能力。
- 用“语义分支 + 通用分支”替代单一均匀路由空间，避免所有视觉 token 被强制塞进同一均匀路由分布。
- 通过原型引导路由和 pull-push 正则，使 token 按语义属性聚类，而非按任意负载均衡约束分配。

### 2.2 关键技术细节

- **标准 MoE 形式**：  
  \(y=\sum_{i\in I(x)} g_i(x)E_i(x)\)，每个 token 激活 \(K\ll M\) 个专家。传统方法常加入辅助负载均衡损失，迫使 token 均匀分布到专家上。
- **分裂专家池**：  
  \(E=E_{sem}\cup E_{gen}\)，\(E_{sem}\cap E_{gen}=\varnothing\)，\(M=M_s+M_g\)。  
  论文实现中，每个 MoE 层含 1 个共享专家和 100 个路由专家，其中 20 个语义专家、80 个通用专家。
- **双轨路由**：
  - 对 token 投影并计算语义/通用亲和度。
  - 使用独立 sigmoid 分数，而非全局 softmax，使一个 token 可同时兼容语义专家和通用专家。
  - 分别对语义组和通用组做 Top-K 选择：  
    \(I_{sem}=TopK(\tilde{s}_{sem},K_s)\)，\(I_{gen}=TopK(\tilde{s}_{gen},K_g)\)，\(I=I_{sem}\cup I_{gen}\)。
  - 最终混合权重由干净的原始分数归一化得到，保持路由保真度。
  - 固定激活预算：\(K=K_s+K_g\)，与标准 MoE 的 Top-K 一致。论文中采用 Top-8，即 \(K_s=2\) 个语义专家、\(K_g=6\) 个通用专家。
- **原型引导语义路由**：
  - 引入可学习原型 \(P=\{p_1,\dots,p_{M_s}\}\)，作为连续 VAE 特征与离散语义专家之间的语义瓶颈。
  - 用 clean VAE 特征计算 teacher 分配 \(q_i\)：基于温度缩放的余弦相似度。
  - Router 从 DiT 视觉 token 预测语义路由分布 \(r_i\)。
  - 用 KL 散度对齐：\(L_{align}=\frac{1}{N}\sum_i KL(q_i\|r_i)\)，并对原型目标 stop-gradient，避免 router 目标直接扭曲原型拓扑。
- **原型优化 \(L_{proto}\)：pull-push 正则**：
  - **Pull**：将原型拉向当前 mini-batch 和 token bank 中的历史 VAE 特征，减少死模式。
  - **Push**：对原型间余弦相似度超过 margin \(\delta\) 的情况施加惩罚，防止多个原型坍缩到冗余背景区域。
  - 二者耦合，使原型在 VAE 特征流形上形成分离且覆盖良好的中心。
- **总体目标**：  
  \(L=L_{flow}+\lambda_{align}L_{align}+\lambda_{proto}L_{proto}\)。  
  其中 \(L_{flow}\) 为 flow matching 损失。
- **负载均衡策略**：
  - 通用专家采用类似 DeepSeek-V3 的 loss-free load balancing。
  - 语义专家不做显式负载均衡，而是通过语义对齐自然实现自适应平衡。
  - 该机制只更新非梯度的路由偏置，不引入额外辅助优化损失。
