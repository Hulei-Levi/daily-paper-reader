# ABSTRACT 

Latent visual reasoning equips vision–language models with continuous interme-diate states that can process visual evidence without explicit textual reasoning traces or repeated image operations. However, existing methods often allow mul-tiple latent tokens to access the same visual evidence through shared value pro-jections, providing no mechanism for them to extract complementary visual infor-mation; simply increasing the latent budget can therefore yield redundant latent representations. We argue that effective latent reasoning should encourage differ-ent latent tokens to extract complementary visual information, and thereby act as specialized visual experts. Based on this insight, we propose M OLE, a Mixture of Latent Experts framework that controls both what visual evidence each latent visual expert observes and how it transforms that evidence. M OLE isolates latent visual experts during evidence extraction and uses dedicated latent summary ex-perts to aggregate the complementary representations of latent visual experts. A two-stage training pipeline first forces visual evidence through this latent pathway and then restores direct visual access, requiring neither predefined expert roles nor intermediate visual targets. Across five visual reasoning benchmarks, M OLE achieves an average score of 78.6, outperforming data-matched supervised fine-tuning by 4.9 and the strongest evaluated latent visual reasoning baseline at the same latent budget by 3.6. Representation analyses show lower latent-state simi-larity and more diverse visual attention, while masking the latent pathway reduces average performance by 9.2. These results demonstrate that specializing latent computation is more effective than merely increasing the number of latent tokens. 

# 1 INTRODUCTION 

Visual reasoning requires a vision–language model (VLM) to generate an answer through intermedi-ate computation over visual inputs. The model must identify visual evidence, preserve fine-grained details, and combine cues that may be distributed across multiple objects, regions, or images. Exist-ing approaches instantiate this intermediate process in different ways. Text-based chain-of-thought expresses it in discrete language (Wei et al., 2022; Xu et al., 2025; Huang et al., 2026). Interleaved approaches acquire additional visual observations during reasoning, but often require cropping, re-encoding, or external tools at inference (Shao et al., 2024; Su et al., 2025; Wu et al., 2026). Latent visual reasoning instead performs the intermediate computation in continuous hidden states (Li et al., 2026a; Qin et al., 2026; Li et al., 2026b). It therefore keeps the reasoning process internal without explicit textual traces or repeated image operations. However, this advantage does not by itself make multiple latent tokens useful. In a common design, all latents can access the same visual tokens and process them through a shared value projection (Li et al., 2026a; Qin et al., 2026; Li et al., 2026b). These latents may therefore converge to redundant representations. Merely increasing the latent count can add more redundant states rather than new reasoning capacity. 1arXiv:2610.01917v1 [cs.CV] 1 Oct 2026 Preprint

Explicitly spe-cializing what each latent observes and how it transforms that evidence encourages complementary representations and stronger reasoning without increasing the latent budget. This limitation motivates us to explore explicit specialization as a way to make better use of a fixed latent budget. A latent representation is determined by both what visual evidence it receives and 

how it transforms that evidence. When these two factors are shared across all latents, increasing the latent count can largely replicate the same computation and produce redundant representations. Differentiating both the available evidence and its transformation encourages latents to capture com-plementary visual information within a fixed budget. Figure 1 contrasts this explicit specialization with simply increasing the latent count under shared evidence and transformations. Motivated by this insight, we introduce MOLE (Mixture of Latent Experts) for complementary vi-sual reasoning. At every decoder layer, sparse visual routing assigns each visual token to a subset of latent visual experts, differentiating the evidence available to them. Each latent visual expert further uses an Expert-Specific Value Adapter (ESVA) to transform its routed visual evidence differently. We isolate latent visual experts from one another to preserve their complementarity, then introduce latent summary experts that aggregate only the representations produced by the latent visual experts. Answer tokens attend to both latent expert sets, allowing complementary visual information and its aggregated summary to jointly support answer prediction. MOLE is trained without predefined expert roles or intermediate visual targets. Because direct visual access can allow answer tokens to bypass the latent states, we follow LIVR (Li et al., 2026b) and adopt the two-stage training design to ensure that the latent pathway learns visual information useful for answer generation. Stage 1 imposes a visual attention bottleneck that forces visual evidence through the latent pathway. Stage 2 restores direct visual access, allowing answer generation to combine the learned latent representations with the original visual tokens. Training uses supervision only on answer tokens, together with the MoE loss for router optimization and a diversity objective for the ESVAs. Both stages use this same joint training objective. At inference, the latent states are computed during prefilling and require no additional image processing. Across five visual reasoning benchmarks, M OLE achieves an average score of 78.6, improving data-matched SFT by 4.9 and the strongest evaluated latent visual reasoning baseline at the same latent budget by 3.6. It produces the lowest latent-state similarity and the highest KL diversity of latent attention-pattern among the compared latent visual reasoning methods. Moreover, masking the learned latent pathway lowers the average by 9.2 despite preserving direct visual access, showing that the answer generation uses information carried by the latent tokens. Doubling the latent budget does not improve the best configuration, further supporting the importance of specializing latent computation rather than merely increasing its size. 2Preprint Our contributions are as follows: • We identify the lack of complementary latent computation as a central limitation of latent visual reasoning and motivate encouraging latents to extract complementary visual infor-mation. • We propose M OLE, a new latent visual reasoning method that combines dynamic visual al-location, expert-specific visual transformations, and topological latent aggregation without predefined expert roles or intermediate visual targets. • We demonstrate consistent gains across visual reasoning benchmarks and provide ablation, representation, and intervention evidence that the learned latents are complementary and functionally used for answer generation. 

# 2 RELATED WORK 

Text-based visual reasoning. Chain-of-thought (CoT) prompting improves reasoning in large lan-guage models (LLMs) by eliciting textual intermediate steps before an answer (Wei et al., 2022). This paradigm extends to vision–language models (VLMs): LLaVA-CoT organizes generation into summarization, visual interpretation, logical reasoning, and conclusion stages (Xu et al., 2025), whereas Vision-R1 combines a multimodal CoT cold start with reinforcement learning (Huang et al., 2026). These methods provide readable task decompositions, but expressing visual reasoning en-tirely through discrete text may omit fine-grained evidence, motivating methods that operate on visual information more directly. 

Interleaved multimodal reasoning. Interleaved multimodal reasoning incorporates processed vi-sual observations into textual trajectories. Visual CoT predicts a question-relevant bounding box, then combines re-encoded crop tokens with full-image tokens for answer generation (Shao et al., 2024). Tool-based methods acquire evidence more flexibly: Pixel Reasoner invokes zoom-in and frame-selection operations (Su et al., 2025); VTool-R1 learns to edit charts and tables with Python tools (Wu et al., 2026); and VISTA-R1 coordinates visual and symbolic tools over multi-turn in-teractions (Lu et al., 2026). These methods adapt evidence acquisition to the question but incur additional tool execution and visual processing at inference. 

Latent visual reasoning. Latent reasoning instead represents intermediate computation as continu-ous states. COCONUT, CODI, and SeLaR explore this paradigm in LLMs (Hao et al., 2025; Shen et al., 2025; Fu & Luo, 2026), motivating its extension to visual reasoning without explicit image operations at inference. Latent visual reasoning methods differ mainly in how they supervise latent states. LVR reconstructs query-relevant visual tokens, while LANTERN and VaLR align latents with vision-encoder features (Li et al., 2026a; Viveiros et al., 2026; Jeon et al., 2026). Mirage dis-tills latent tokens from ground-truth image embeddings, ILVR selectively distills relevant features from helper images, and Monet aligns observation-token representations under controlled access to auxiliary images (Yang et al., 2026; Dong et al., 2026; Wang et al., 2026). UniVLR compresses a shared canvas containing rendered reasoning traces and auxiliary images, whereas CoVT supervises distinct token groups with segmentation, depth, edge, and DINO targets (Jiang et al., 2026; Qin et al., 2026). In contrast, LIVR trains learnable latent tokens without intermediate targets, using an attention bottleneck and answer-token loss (Li et al., 2026b). However, these methods generally let multiple latents access the same visual evidence through shared value projections, without explicitly encouraging complementary extraction. Increasing the latent budget can therefore yield redundant representations. M OLE instead sparsely routes visual evidence to isolated latent visual experts with expert-specific value transformations, then aggregates their complementary representations through dedicated latent summary experts.

Two-stage training pipeline. Under conventional end-to-end training, answer tokens can directly attend to the original visual tokens, creating a shortcut that allows the model to minimize the an-swer loss while ignoring the latent pathway. The resulting latent tokens may therefore carry little visual information that is useful for answer generation. Following the two-stage training strategy of LIVR (Li et al., 2026b), we first make the latent pathway informative and then integrate it with direct visual access. In Stage 1, we block direct attention from ordinary prompt and answer tokens to visual tokens, so only latent visual experts can access routed visual evidence. This visual at-tention bottleneck trains the latent visual experts to extract and preserve task-relevant information. Stage 2 restores direct visual access for prompt and answer tokens, allowing answer generation to rely jointly on the learned latent representations and the original visual tokens. # 4 EXPERIMENTS 

We adopt Qwen2.5-VL-7B (Bai et al., 2025b) as the backbone VLM. In both training stages, we fine-tune the language backbone with LoRA (Hu et al., 2022) on its attention and MLP blocks, while keeping the vision encoder and projector frozen. In addition to the LoRA parameters, we unfreeze only the embedding rows corresponding to the E + S newly introduced latent experts. We construct a 63K-example training set by sampling from CoVT-Dataset (Qin et al., 2026), which combines vision-centric data from LLaVA-OneVision (Li et al., 2025) with counting and relative-depth samples derived from TallyQA (Acharya et al., 2019) and ADE20K (Zhou et al., 2017). We do not sample directly from any of the evaluation benchmarks described below, thereby avoiding direct reuse of their evaluation splits. Detailed data sampling, processing, and decontamination against the evaluation benchmarks are described in Appendix A.2. 4.1 EVALUATION BENCHMARKS 

We evaluate across five benchmarks with distinct perceptual demands. CVBench (Tong et al., 2024) separates 2D spatial relations and object counting from 3D depth ordering and relative-distance understanding. BLINK (Fu et al., 2024) broadens this coverage by recasting 14 classical computer-vision tasks as single- and multi-image multiple-choice questions, including visual correspondence, 6Preprint relative depth, and multi-view reasoning. RealWorldQA (RWQA) (xAI, 2024) shifts the evaluation to natural physical scenes, where questions involve properties such as relative size, direction, and navigability. V* (Wu & Xie, 2024) focuses specifically on visual search, requiring models to locate and reason about details in high-resolution, visually crowded images. Finally, POPE (Li et al., 2023) complements these capability-oriented benchmarks by probing resistance to object hallucination through binary questions about object presence. For CVBench, we report accuracy separately on its 2D and 3D subsets. We report F1 for POPE and accuracy for the remaining benchmarks. Avg. is the unweighted mean of these six metrics. 4.2 MAIN RESULTS 

Baselines. We compare M OLE with several categories of reasoning models. GPT-4o and Claude-4-Sonnet serve as proprietary VLM references. We also report the Qwen2.5-VL-7B base model and Qwen2.5-VL-7B-SFT, obtained by directly fine-tuning the same backbone on the same training set. The former establishes the pretrained starting point, while the latter provides a data-matched control for isolating gains attributable to M OLE rather than exposure to the training data. Vision-R1 (Huang et al., 2026) represents text-based visual reasoning, while PixelReasoner (Su et al., 2025) interleaves textual reasoning with image operations to actively acquire additional visual evidence during inference. We further compare with CoVT, LVR, and LIVR (Qin et al., 2026; Li et al., 2026a;b) as representative latent visual reasoning methods. For local evaluation, we use the official publicly released checkpoints of Vision-R1, PixelReasoner, CoVT, and LVR. We train LIVR on the same training set as M OLE. Detailed training configurations for our default M OLE model, Qwen2.5-VL-7B-SFT, and LIVR are provided in Appendix A.3. 

Evaluation configurations. We evaluate CoVT, LVR, and LIVR with different latent budgets of 8 and 16. For LVR, we can simply set the number of reasoning steps directly. For CoVT, we use two publicly released checkpoints: CoVT-Seg with 8 steps and CoVT-Seg-Depth-DINO with 16 steps. Because LIVR fixes its latent budget during training, we train separate models with 8 and 16 latent tokens on the same training set. Our main M OLE configuration uses a total latent budget of 

E + S = 8 . We evaluate all open models with our evaluation scripts, which follow the official eval-uation configurations of the respective benchmarks. For a fair comparison, every evaluated baseline and M OLE use the same scripts and benchmark-specific configurations. Detailed evaluation config-urations are provided in Appendix A.4. For the proprietary models, results on CVBench, BLINK, RWQA, and V* are taken from CoVT (Qin et al., 2026); their POPE scores follow Sarkar et al. (2025) for GPT-4o and the Moondream benchmark (M87 Labs, 2026) for Claude-4-Sonnet. Since CoVT does not report CVBench results separately for its 2D and 3D subsets, we use its reported GPT-4o and Claude-4-Sonnet results to calculate separate 2D and 3D scores for each model. The calculation is provided in Appendix A.5. 

Results. Table 1 shows that M OLE achieves the highest average score of 78.6 and the best result on all six reported metrics among the evaluated models. Compared with data-matched SFT, it improves every metric and raises the average by 4.9, showing that the gain cannot be explained solely by exposure to CoVT-Dataset. At the same latent budget of 8, M OLE outperforms the strongest latent visual reasoning baseline, LIVR, by 3.6 on average. Simply doubling the latent budget does not yield consistent gains: LVR degrades, while CoVT and LIVR improve only modestly. Even the strongest 16-step result remains 3.1 below M OLE with 8 latents. These results suggest that organizing a fixed latent budget around information complementarity is more effective than increasing the latent count alone. The largest improvements occur on CVBench-3D and BLINK, where predictions depend heavily on spatial structure and fine-grained perceptual cues. Improvements on V* and POPE further suggest that the benefits extend to visual search and reliable object grounding. 4.3 QUANTITATIVE ANALYSIS 

Where do the performance gains come from? Starting from the default configuration, we in-dependently retrain three variants that remove sparse visual routing, ESVAs, or topological latent aggregation (Figure 3(b)). Without the router, every visual token is made equally accessible to all visual experts. Removing ESVAs retains the shared value projection but eliminates the subsequent expert-specific transformations. Removing topological latent aggregation instead restores conven-tional causal attention among visual experts, allowing their representations to mix directly. Do the latents become more complementary? We assess latent redundancy from two perspectives. First, pairwise squared cosine similarity between latent-token hidden states measures their numerical similarity. Second, pairwise KL diversity between the visual-token attention patterns of latents measures how differently they attend to visual information. Both metrics are aggregated over the evaluation data, scaled by 100. As shown in Figure 3(a), M OLE achieves the lowest latent similarity and the highest attention-pattern diversity among the compared latent visual reasoning methods. Detailed formulations of both metrics are provided in Appendix A.6. 4.4 ABLATION STUDIES 

Latent allocation. We vary the allocation of visual and summary experts under fixed latent budgets of 8 and 16 (Table 2(a)). The balanced configurations, E = 4 , S = 4 and E = 8 , S = 8 , perform best within their respective budgets. However, the best configuration with 16 latents does not outper-form its 8-latent counterpart, indicating that simply increasing the latent budget does not necessarily improve visual reasoning performance. We also set S = 0 at both budgets to test whether summary experts are necessary. Although these variants devote the entire latent budget to visual experts, their average performance drops by 2.9 and 2.4, respectively. This result shows that allocating capacity to summary experts, which integrate the complementary representations produced by visual experts, is needed. 

Training stages and objectives. Table 2(b) examines both the training pipeline and its auxiliary objectives. All stage variants retain the other settings of the default M OLE model and are trained for three epochs in total: Stage 1 only uses Stage 1 for all three epochs, Stage 2 only uses Stage 2 for all three epochs, and Stage 1 + Stage 2 follows the default schedule of two Stage 1 epochs and one Stage 2 epoch. The complete two-stage pipeline outperforms either stage alone. Stage 1 shows that the latent pathway can preserve substantial visual information under the visual attention bottleneck, while the gain over Stage 2-only training supports first making this pathway informative before restoring direct visual access. Regarding the objectives, the MoE loss improves expert utilization and router stability, while the diversity loss encourages distinct ESVA transformations; combining both yields the best performance. 

More ablations. More ablations and results across random seeds are provided in Appendix A.7. 

# 5 CONCLUSION 

We introduced M OLE, a framework that organizes latent visual reasoning around complementary latent computation rather than latent count. M OLE routes visual evidence to isolated latent visual experts, applies expert-specific visual transformations to routed visual evidence through ESVAs, and aggregates the resulting complementary latent representations with latent summary experts. Across 9Preprint five benchmarks, M OLE improves data-matched SFT by 4.9 points on average and outperforms the evaluated latent reasoning methods. Ablations validate the contributions of the architecture and training objectives. Representation analyses show lower latent-state similarity and more diverse visual-attention patterns of latents than other latent visual reasoning methods. A.2.2 TASK -B ALANCED SAMPLING 

We organize the source records into ten high-level task families and allocate 6,300 examples to each family. Table 3 summarizes the resulting composition. For task families supported by multiple sources, we balance those sources where their capacities permit. When a source does not contain enough examples to meet an equal quota, we retain all available examples without replacement and fill the remaining quota from another source within the same task family. For every selected record, we use only the first question–answer pair as the training example. After assigning equal quotas to the ten task families, we further divide each family by question format or answer category and distribute its samples across these subtypes. Specifically, we stratify visual mathematics by direct, fill-in-the-blank, and multiple-choice questions; CLEVR by answer type; A-OKVQA by whether the answer contains a rationale; ST-VQA by numeric versus non-numeric answers; TallyQA by count range; and binary or multiple-choice tasks by their class or option labels. When a subtype lacks enough examples, we retain all of its available samples without replacement and fill the remaining quota with other subtypes from the same family. These labels are used only for sampling; the original answer text is preserved as the supervision target. 15 Preprint A.2.3 ONLINE SAMPLE DECONTAMINATION 

We perform decontamination online as part of the task-balanced sampling procedure described above. Whenever the sampler draws a record, we immediately compare it against the samples in POPE, BLINK, V*Bench, RealWorldQA, and CV-Bench and decide whether to retain or discard it. A discarded record does not count toward its task-family quota; instead, we draw a replace-ment using the same sampling rule. Invalid records and unreadable images are likewise skipped and replaced. The matching pipeline proceeds from exact matching to candidate retrieval and pairwise verification. First, we compare the file SHA-256 and normalized-pixel SHA-256 of the sampled image with those of all benchmark images. A match from either hash causes the record to be discarded immediately. Records with no exact match proceed to candidate retrieval. We narrow the subsequent comparison set using three retrieval signals. The first two are pHash and dHash, with maximum Hamming distances of 12 and 8, respectively. The third uses DINOv2 features (Oquab et al., 2024) from six image views: one full-image view, one 80% center crop, and four 70% corner crops. We retrieve the top 20 benchmark images for each view and take their union. If the normalized question text exactly matches a benchmark question, we also include its associated images and expand DINOv2 retrieval to the top 100. These signals only select benchmark candidates for further verification and do not directly cause a record to be discarded. We first apply whole-image verification to each retrieved candidate. The images are resized to 

256 × 256 , and a match requires all three conditions: an aspect-ratio difference of at most 0.02, a color mean absolute error (MAE) of at most 0.055, and a grayscale Pearson correlation of at least 0.97. If all three conditions hold for any candidate, the sampled record is discarded. Candidates that do not satisfy the whole-image conditions undergo local-feature and geometric ver-ification. We extract up to 2,500 SIFT features and apply the Lowe ratio test (Lowe, 2004) after limiting the longest image side to 768 pixels. We use a contrast threshold of 0.02 and retain matches with a ratio below 0.75. RANSAC (Fischler & Bolles, 1981) estimates the geometric alignment with a 4-pixel reprojection threshold, at most 2,000 iterations, and confidence 0.995. A geometric match requires at least 10 inliers, an inlier ratio of at least 0.28, coverage of at least 0.025 in both images and at least 0.12 in one image, a median reprojection error of at most 3.5 pixels, and an aligned overlap of at least 0.035. For aligned-pixel verification, we erode the valid mask with a 5 × 5 kernel and require at least 256 valid pixels. The aligned region must further satisfy either a grayscale cor-relation of at least 0.90 with an MAE of at most 0.12, a correlation of at least 0.97, or an MAE of at most 0.055. If any retrieved candidate satisfies the complete geometric and aligned-pixel conditions, the sampled record is discarded; otherwise, it is retained in the training set. A.3 TRAINING CONFIGURATIONS

CoVT (Qin et al., 2026) reports four CVBench-related scores for GPT-4o and Claude-4-Sonnet: CVBench, Count, Depth, and Dist. CVBench is the aggregate score over the full benchmark and reflects both 2D and 3D visual spatial understanding. Count corresponds to Object Counting, which asks how many instances of a specified object category appear in an image and evaluates instance recognition, object separation, and counting. Depth corresponds to Depth Order, which asks which of two objects is closer to the camera and evaluates depth perception, front–back ordering, and 3D geometry. Router Top-K controls how many latent visual experts receive each visual token at a decoder layer. Starting from the default M OLE configuration, we independently retrain models with

This suggests that moderate routing density balances selective evidence allocation with sufficient expert processing. A.7.5 ESVA H IDDEN DIMENSION 

We vary the hidden dimension db of the two-layer ESVA MLP over {16 , 32 , 64 , 128 } while keeping the remaining default configuration unchanged. This ablation tests whether the benefit of ESVA depends on increasing its transformation capacity. Table 9(b) shows that db = 32 performs best, while larger hidden dimensions do not improve performance. Thus, the ESVA gains do not arise from simply increasing adapter capacity, and a compact hidden dimension is sufficient for expert-specific visual transformation. A.7.6 INFERENCE COST 

We quantify the inference overhead of M OLE relative to its Qwen2.5-VL-7B backbone. For ev-ery RWQA example, we evaluate both models and record inference time, floating-point operations (FLOPs), and peak GPU memory, then average each measurement over the full benchmark. Table 10 reports the results. MOLE adds only 0.84% FLOPs and 1.55% peak memory, corresponding to 0.245 GiB. Its measured inference time increases by 22 .97% , but the absolute increase is 0.086 seconds per example and the average latency remains below 0.5 seconds. In return, M OLE improves the average benchmark score over the backbone by 6.1 points. We therefore consider this inference overhead acceptable for the resulting performance gain. 22
