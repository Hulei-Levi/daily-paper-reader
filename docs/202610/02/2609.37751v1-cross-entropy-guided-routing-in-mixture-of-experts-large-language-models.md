## Abstract
Sparse mixture-of-experts (MoE) large language models scale model capacity by routing each token to a small subset of experts. Their routers are regularized with load balancing terms and learn affinity scores through the language-model objective. However, these objectives do not provide direct alignment between routing affinities and token-level error. We introduce token-error supervision for sparse routing in two forms. The first form predicts an error score per expert. The affinity-weighted aggregate of these scores is aligned to the next-token cross-entropy loss, while the individual scores attenuate affinity before top-$K$ selection. The second directly aligns the router's affinities to the model's objective without requiring an additional head or inference-time modification. Both formulations use the Itakura--Saito divergence or an exponential negative log-likelihood for aligning affinities and token errors. Across two sparse MoE backbones and four multiple-choice question-answering benchmarks, we evaluate both supervision mechanisms. On Granite, our method improves accuracy by approximately 2.3 percentage points on average over a parameter-matched routing baseline. With stronger supervision, the gain on ARC-Challenge reaches 2.94 points. Both mechanisms preserve the native sparse execution budget and aggregation policy. Our code is available in the supplementary materials.

## 1. 核心问题与整体含义

- **研究背景**：稀疏混合专家（MoE）大语言模型通过路由器为每个 token 选择 top-$K$ 个专家，从而在不显著增加单 token 计算量的前提下扩大模型容量。
- **核心问题**：标准 MoE 路由器通常只依赖语言建模目标与负载均衡等辅助正则项学习 affinity score。这些目标提供专家之间的相对偏好，但没有显式告诉路由器“当前选择是否会导致高 token 级预测误差”。
- **论文含义**：作者提出用**实际下一 token 交叉熵损失**作为直接监督信号，引导 MoE 路由。核心观点是：路由 affinity 应与 token 级误差对齐，而不是仅靠间接的语言模型损失和负载均衡学习。
- **总体目标**：在保持原生 top-$K$ 执行预算和架构特定聚合策略的前提下，改善稀疏路由质量，并提升下游 MCQA 准确率。

## 2. 方法论

### 2.1 标准稀疏 MoE 路由回顾

- 对 token 表示 $h_t$，路由器计算：
  - affinity logits：$a_t = W_{\mathrm{aff}}h_t + b_{\mathrm{aff}}$
  - 概率：$p_t = \mathrm{softmax}(a_t)$
  - 选择：$S_t = \mathrm{TopK}(p_t, K)$
- 输出为所选专家输出的加权组合：
  - $y_t = \sum_{i\in S_t} g_{t,i}E_i(h_t)$
- 问题：affinity 只通过 LM 目标和负载均衡学习，未直接监督 token 级误差。

### 2.2 Token-Error Supervision（TES）

- **误差头**：从 pre-expert token 表示 $h_t$ 预测每个专家的正误差分数：
  - $\hat e_t = \mathrm{softplus}(W_e h_t + b_e)$，$\hat e_t \in \mathbb{R}^N_{>0}$
- **聚合预测**：在已执行专家集合 $S_t^{\mathrm{act}}$ 上，用归一化 native affinity 加权聚合专家误差：
  - $\bar p_{t,i} = p_{t,i}/\sum_{j\in S_t^{\mathrm{act}}}p_{t,j}$
  - $\hat e_t = \sum_{i\in S_t^{\mathrm{act}}}\bar p_{t,i}\hat e_{t,i}$
- **监督目标**：将聚合预测 $\hat e_t$ 与真实下一 token 交叉熵 $L_{\mathrm{CE},t}$ 对齐。
  - Itakura–Saito 散度：
    - $L_{\mathrm{IS},t} = \frac{L^+_{\mathrm{CE},t}}{\hat e_t} - \log\frac{L^+_{\mathrm{CE},t}}{\hat e_t} - 1$
  - 指数负对数似然：
    - $L_{\mathrm{ENLL},t} = \frac{L_{\mathrm{CE},t}}{\hat e_t} + \log\hat e_t$
- **误差感知路由衰减**：在 top-$K$ 选择前，用预测误差调整 native affinity logits：
  - $\tilde a_{t,i} = a_{t,i} - \gamma \phi_\tau(\hat e_{t,i})$
  - $\phi_\tau(\hat e) = \log(1+\hat e/\tau)$
  - 默认 $\gamma=1$，$\tau=1$。
- 概率形式：
  - $\tilde p_{t,i} \propto p_{t,i}(1+\hat e_{t,i}/\tau)^{-\gamma}$
- 含义：预测误差越大的专家，其相对 affinity 被压低，从而影响 top-$K$ 选择。该方法保留原生执行预算和聚合策略。
- **代价**：TES 增加一个线性误差头，约 $N(d+1)$ 参数和 $O(Nd)$ 每 token 计算；未测端到端延迟和内存。

### 2.3 Affinity-Concentration Supervision（ACS）

- ACS 不需要额外误差头，也不在推理时修改路由。
- 直接使用所选专家的 native affinity 归一化概率，计算**亲和度集中度**：
  - $\bar p_{t,i} = p_{t,i}/\sum_{j\in S_t}p_{t,j}$
  - $C_t = \sum_{i\in S_t}\bar p_{t,i}^2$
- 性质：
  - $1/K \le C_t \le 1$
  - $1/C_t$ 是有效专家
