## 摘要
混合专家（MoE）模型近来已不仅仅局限于路由固定数量的完整专家。共享专家设计保留可复用知识，细粒度方法在专家内部改变计算量，动态路由器自适应激活专家数量。然而，这些决策通常独立进行，忽略了一个基本依赖关系：提取可复用计算既改变了剩余内容，也改变了剩余部分所需的专家容量。我们通过将稀疏升级的前馈专家分解为键值通道来研究这一依赖关系。共同激活的专家在部分值位置上对齐；移除这些位置会改变专家偏好；更大的共享覆盖与更低的剩余专家需求相关。这些观察引出一个原则：先共享，再路由剩余部分。我们将其实例化为UniF-MoE，一个用于令牌自适应MoE计算的统一框架。每个专家被划分为对齐的块。共享需求分数设置共享块数量和路径权重，键原型选择共享内容，互补需求通过累积路由质量确定剩余专家数量。一个Gram正则化器分离并规范化路由器嵌入，促进多样化的路由方向、稀疏的专家重叠和简单的路由几何结构。在DomainBed和GLUE上的实验表明，这种统一设计在减少激活计算、推理延迟和内存的同时，比具有代表性的静态和动态MoE提高了预测性能。代码可在 https://github.com/existence0420/UniF-MoE 获取。

## Abstract
Mixture-of-experts (MoE) models have recently moved beyond routing a fixed number of complete experts. Shared-expert designs preserve reusable knowledge, fine-grained methods vary computation within experts, and dynamic routers adapt the number of active experts. Yet these decisions are usually made independently, overlooking a basic dependency: extracting reusable computation changes both what remains and how much expert capacity the remainder needs. We study this dependency by decomposing sparsely upcycled feed-forward experts into key-value channels. Co-activated experts align at a subset of value positions; removing these positions changes expert preference; and greater shared coverage is associated with lower residual expert demand. These observations lead to one principle: share first, then route what remains. We instantiate it in UniF-MoE, a unified framework for token-adaptive MoE computation. Each expert is partitioned into aligned blocks. A shared-demand score sets the shared block count and pathway weight, key prototypes select the shared content, and the complementary demand determines the residual expert count through cumulative routing mass. A Gram regularizer separates and normalizes router embeddings, promoting diverse routing directions, sparse expert overlap, and a simple routing geometry. Experiments on DomainBed and GLUE show that this unified design improves predictive performance over representative static and dynamic MoEs while reducing activated computation, inference latency, and memory. Code is available at https://github.com/existence0420/UniF-MoE.

## 1. 核心问题与整体含义

- **研究动机**：混合专家（MoE）模型通过路由只激活少数专家，在参数规模增长的同时保持计算稀疏。然而，现有 MoE 研究在三个方向——共享专家、细粒度计算（专家内部变宽）、动态路由（专家数量自适应）——通常各自独立设计与决策，忽略了它们之间的基本依赖关系：**一旦可复用计算被提取，剩余内容本身、最优专家选择以及所需专家容量都会发生变化**。顺序颠倒或独立决策会导致重复计算或错误路由。
- **核心观察（诊断实验）** ：作者将稀疏升级（sparse upcycling）的 MoE 专家分解为键值通道。在共享初始预训练权重的条件下，发现：
  1. 经常被共同激活的专家对在值空间位置上有高度对齐（共享度高，相关系数 0.697）；
  2. 将已对齐的位置移除后，原有路由决策几乎失效（仅 5.7% 的 token 保持原 top-2 集合），说明残差部分的专家偏好已发生改变；
  3. 不同 token 在共享响应被抽取后，所需的残差专家数量差异很大；共享覆盖越高，残差需求越低（相关系数 −0.673）。
- **整体含义**：共享建模、细粒度选择、动态路由不是三个平行旋钮，而是同一分配问题的三个阶段，应按严格顺序执行：**先共享，再路由剩余（share first, then route what remains）**。

## 2. 方法论：UniF-MoE 框架

- **核心思想**：每一层包含 1 个共享专家和 K 个残差专家，所有专家被划分为 B 个对齐块（block），每个块包含 M = H/B 个通道。对每个 token，按顺序决策：
  1. **共享多少**（how much to share）：由共享需求分数决定共享块数；
  2. **共享什么**（what to share）：由键原型选择具体共享块内容；
  3. **剩余需要多少专家**（how many experts the remainder needs）：由互补需求与累积路由质量共同决定激活的残差专家数。
- **关键技术细节**：
  - **共享需求分数**：扩展路由器为 W⋆g = [W_shr, W_g] ∈ R^{d×(K+1)}，新增共享专家嵌入列，通过 α(x) = τ + (1 − 2τ)σ(xW_shr) 计算共享需求，其中 τ = (B−1)/B²，保证 α(x) ∈ (τ, 1−τ)，从而确保共享块数 b(x) = round(Bα(x)) 始终落在 {1, …, B−1}，即每个 token 至少用一个共享块、至少留一个残差块。
  - **共享内容选择**：每个共享块以块内上投影键的均值作为原型 μ_b，对 token 计算优先级 u_b(x) = xμ_b，取 TopK 作为共享块集合 I_shr(x)，其余为残差块集合 I_res(x)。
  - **累积残差路由**：残差专家嵌入得到归一化亲和分布 s(x) = softmax(xW_g)，将排序后的累积亲和度首次达到 β(x) = 1 − α(x) 的最小前缀长度作为激活专家数 k(x)：
    k(x) = min { n : Σᵢ₌₁ⁿ pᵢ(x) ≥ β(x) }。
    该机制使专家数既取决于剩余需求大小，也取决于路由分布的形状（分布越尖锐，一个专家即可覆盖）。
  - **输出融合**：y = α(x)E_shr^S(x) + Σᵢ₌₁^{k(x)} pᵢ(x)E_{qᵢ(x)}^R(x)，共享输出权重为 α(x)，残差专家保留原始亲和度，总系数质量存在受控超调。
  - **Gram 正则化**：对路由器嵌入施加 L_div = ‖(W⋆g)ᵀW⋆g − I_{K+1}‖_F，配合正交初始化，促进路由方向分离、专家角色多样化、路由几何简单化，防止路由嵌入塌缩。
- **激活块数**：C_B(x) = b(x) + k(x)[B − b(x)]；相比常规 top-k MoE 的 kB 块，重复计算被限制在残差路径上，共享部分只执行一次。

## 6. 主要结论与发现

- **性能上**：UniF-MoE 在 DomainBed 五个数据集上平均准确率最高（69.5%），在 PACS、VLCS、OfficeHome、DomainNet 上均取得最佳或并列最佳；在 GLUE 五个任务上全部超过所有基线，平均分 82.76，优于固定 top-k 的最优逐任务上方包络（81.95）和动态 MoE（MASS 82.19）。
- **效率上**：相比 top-2 GMoE，激活参数减少 9.1%，FLOPs 减少 16.1%，推理时间降低 45.2%，推理内存降低 52.7%；相比 DynMoE 在所有计算与运行指标上均有优势，且取得与密集模型相当的推理内存（0.26 GiB vs 0.29 GiB）。
- **机制验证**：消融实验表明，三个自适应决策缺一不可——固定共享需求、退回 top-2 残差激活、使用前缀式块选择都会同时损害准确率和增加计算量。Gram 正则化使专家协同激活显著降低（−62.9%），同时保留必要合作。块粒度 B=8 或 16 较为最优。
- **定性分析**：路由实例显示共享块在语义元素间复用，而残差专家保持选择性偏好；资源分配响应类别证据而非仅响应域或对比度。

## 7. 优点

- **统一的视角创新**：将共享建模、细粒度计算、动态路由融合为单一有序原则，而非三项独立技术，论证扎实（有诊断实验支撑）。
- **设计简洁、耦合自然**：一个共享需求分数 α 同时驱动共享块数、共享权重和残差需求；专家数由累积路由质量自适应决定，无需额外超参或控制器。
- **计算效率与精度兼顾**：共享部分只算一次，残差重复成本低，实测推理延迟和内存显著下降，不是以牺牲精度为代价。
- **路由正则化设计巧妙**：Gram 约束在路由器嵌入层面实现多样性，不直接约束专家输出，避免干扰任务损失，且使路由几何直观可解释。
- **实验规范**：多数据集、多任务、多种子，附带效率测量、消融、超参扫描和定性分析，证据链完整。
