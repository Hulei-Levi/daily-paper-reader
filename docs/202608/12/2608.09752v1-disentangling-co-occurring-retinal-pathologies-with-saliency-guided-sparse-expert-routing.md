## 摘要
视网膜眼底图像常表现出多种共现病理，然而标准的深度学习分类器对每张图像应用静态的、相同的计算，而不考虑潜在的疾病分布。我们提出了一种新颖的架构，通过稀疏条件计算来解决这一问题，将引导上下文门控（GCG）空间注意力前端与在特征标记上运行的稀疏路由专家混合（MoE）模块配对。关键在于，这种路由产生了可解释的、数据驱动的分解。专家分配显著依赖于疾病（p < 0.001），健康的正常状态和形态上独特的病理（如ERM、AMD）被隔离到专门的专家。在五类、患者不重叠的5折交叉验证基准上，我们的模型实现了0.912 ± 0.008的宏AUC和0.653 ± 0.014的宏F1。此外，Grad-CAM++和MoE后的t-SNE可视化证实，专家路由与局部病变对齐，并在几何上将共现病例映射到其组成簇之间，将稀疏MoE定位为多疾病视网膜筛查的一种可解释方法。

## Abstract
Retinal fundus images frequently exhibit multiple co-occurring pathologies, yet standard deep learning classifiers apply static, identical computation to every image regardless of the underlying disease distribution. We propose a novel architecture that resolves this via sparse conditional computation, pairing a Guided Context Gating (GCG) spatial attention front-end with a sparsely-routed Mixture-of-Experts (MoE) block operating over feature tokens. Crucially, this routing yields an interpretable, data-driven decomposition. Expert allocation is significantly disease-dependent (p < 0.001), with the healthy Normal state and morphologically distinct pathologies (e.g., ERM, AMD) isolating to dedicated experts. On a five-class, patient-disjoint 5-fold cross-validation benchmark, our model achieves 0.912 +/- 0.008 macro AUC and 0.653 +/- 0.014 macro F1. Furthermore, Grad-CAM++ and post-MoE t-SNE visualizations confirm that expert routing aligns with localized lesions and geometrically maps co-occurring cases between their constituent clusters, positioning sparse MoE as an interpretable approach to multi-disease retinal screening.

## 1. 核心问题与整体含义（研究动机与背景）

- 眼底彩色照相是筛查糖尿病视网膜病变（DR）、年龄相关性黄斑变性（AMD）、视网膜前膜（ERM）、青光眼等疾病的主要非侵入性手段。
- 临床实践中，这些疾病常常在单只眼睛中**共现**（例如 DR 的微动脉瘤与青光眼的视盘凹陷同时出现），因此**多标签分类**才是更贴近临床的设定，但远比单疾病分类困难。
- 现有深度分类器大多使用单一共享特征提取器，将不同疾病的形态学特征编码到**同一个稠密嵌入**中，导致共现病理的表征**互相纠缠**，既降低准确率，也损害可解释性。
- 注意力机制（如通道/空间门控、非局部上下文等）虽然能解决“关注哪里”的问题，但计算本身仍然是**静态的**——每个空间位置都使用相同的权重，无法根据疾病类型动态调整计算过程。
- 稀疏混合专家（MoE）通过条件计算使网络能够为不同 token 分配不同专家，但以往视觉 MoE 多用于单标签自然图像的缩放，**在医学多疾病共现场景中是否能作为一种解耦机制、专家分配是否与疾病身份对齐**，仍缺乏探索。
- 本文核心含义：提出一种“显著性引导 + 稀疏专家路由”的管道，将眼底图像分析从静态处理转向**病理感知的条件计算**，并利用路由分布作为**可解释的诊断信号**，同时提升多标签分类性能与可解释性。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **整体架构**：预训练 ConvNeXt-Tiny 骨干 → Guided Context Gating（GCG）显著性引导 tokenization → 带共享专家的稀疏 MoE Transformer 块 → 多任务学习（MTL）分类头 → 本体论解码（Ontological Decoding）。
- **骨干与微调策略**：使用 ConvNeXt-Tiny 提取空间特征，输入分辨率 518×518；冻结前 80% 参数，仅微调最后 20%，保留低层 Gabor 类滤波器，适应眼底域。
- **显著性引导 tokenization（GCG）**
  - 包含两个子模块：**全局上下文注意力（GCA）** 和 **注意力门（AG）**。
  - GCA：利用 1×1 卷积计算空间注意力图，经 spatial softmax 归一化后执行加权全局池化得到全局上下文向量 g；再经非线性瓶颈变换（降维因子 r=8）生成 g′，与原始特征图按空间广播相加得到上下文增强特征。
  - AG：将局部特征 X 与全局上下文特征 Xctx 通过卷积融合，再经通道维度 LayerNorm 与 Sigmoid 生成空间门控图 A ∈ [0,1]；门控后的特征 X̃ = A ⊙ X，展平后得到病变中心相关的 token 序列 Z ∈ R^{B×S×D}。
- **稀疏 MoE 块**（核心创新）
  - 采用 pre-norm 结构，使用 **RMSNorm** 稳定训练。
  - 先经过 Multi-Head Self-Attention（MHSA）建模长程空间依赖：Z′ = Z + MHSA(RMSNorm(Z))。
  - 每个 token zt 由线性路由层 Wr 计算 E=8 个专家的 logits，采用 **top-k=2 硬路由**；路由权重在选中专家上做稀疏 softmax。
  - 引入 **DeepSeekMoE 式共享专家**：共享专家处理所有 token，吸收常见视网膜结构（如视盘、血管），使被路由的专家专注于区分疾病的残余变异，缓解专家利用不均衡问题。
  - 每个专家使用 **SwiGLU 前馈网络** 实现：E(x) = Dropout((SiLU(xW1) ⊙ (xW3))W2)。
- **MTL 与本体论解码**
  - MoE 块输出经全局平均池化得到图像级嵌入 v，送入 C 个独立的 MLP 头（维度 RD→512→256→1），每个头带 BatchNorm、ReLU 和 Dropout。
  - 损失函数为**动态加权 BCE**，正类权重 wc = clip(sqrt((N_total−Nc)/Nc), 1.0, 5.0)，缓解类别不平衡。
  - 本体论解码：在推理阶段对预测概率施加临床约束：任何病理概率超过阈值则强制否定“Normal”；若所有概率≤0.5，则强制预测最大概率的类别为 1。这些约束与训练损失解耦，避免在训练中引入逻辑矛盾。

## 6. 主要结论与发现

- 所提出的方法在 ODIR 五类多标签基准上达到 **宏 AUC 0.912 ± 0.008、宏 F1 0.653 ± 0.014、准确率 0.649 ± 0.011**，优于所有对比方法（宏 AUC 比 DKCNet 高 0.017，宏 F1 高 0.038）。
- **可解释路由**：专家分配显著依赖疾病类型（置换检验 p<0.001），形态学聚焦的疾病（ERM、青光眼、AMD）倾向于低熵、独占式专家，而弥散型状态（DR、Normal）则宽泛地经由共享通用通路。
- **共现解耦**：对双标签图像（如 DR+ERM、DR+青光眼），联合路由分布与单一疾病原型的联合（而非某种平均）高度相似（相似度 0.978 和 0.969），说明稀疏路由能够“按需组合”病变成分。
- **特征空间重构**：t-SNE 显示，MoE 块后特征空间的轮廓系数从 −0.098 升至 +0.075，单标签疾病各自聚成簇，共现病例落在其组成簇之间的走廊，实现可度量的解耦。
- **病灶定位**：Grad-CAM++ 验证 GCG 门控特征在路由前就聚焦到临床相关区域（如 DR 的出血灶、青光眼的视盘）。

## 7. 优点与亮点

- **方法创新性**：将现代 LLM 中的稀疏 MoE 与显著性门控结合，首次用于眼底多病理共现的**解耦**任务，而不仅仅作为缩放工具。
- **可解释性设计贯穿始终**：路由分布被当作诊断信号，专家-疾病关联是可统计检验的，共现路由表现出“原型联合”行为，提升模型可信度。
- **共享专家设计合理**：通过吸收公共解剖结构，提升路由稳定性并促进专家专业化，避免负载失衡对训练稳定性的影响。
