## 摘要
混合专家（MoE）架构显著扩大了模型容量，而无需按比例增加计算成本。然而，在模型规模和训练数据量（token预算）的极端尺度下，通过穷举搜索来优化其超参数——尤其是学习率——在计算上仍然难以承受。在本文中，我们提出了一种计算高效的两步超参数迁移框架，通过在不同模型宽度之间迁移，并随后外推到数万亿token的训练规模，来估计训练大型MoE模型的最优学习率。首先，我们为利用多头潜在注意力（MLA）和Muon优化器的MoE架构提出了一种最大更新参数化（$μ$P）适配方法，证明了最优学习率在宽度缩放的模型之间能够一致地迁移。其次，我们通过建立预测性缩放定律，将这种可迁移性沿token维度扩展。通过对有限预算下的小型代理模型得到的最优值进行线性回归，我们成功地将理想学习率外推到大规模训练范围（例如，10万亿token），并具有高保真度（$R^2=0.95$）。因此，这表明在小型模型上进行代理训练足以确定大规模MoE大规模训练的最优学习率。我们将所提出的方法应用于从头预训练我们的基础模型（总参数155B，激活参数17B），稳定的训练和评估结果验证了，以极小的消融成本即可准确预测全尺寸目标模型的最优配置。

## Abstract
Mixture-of-Experts (MoE) architectures significantly expand model capacity without a proportional increase in computational cost. However, optimizing their hyperparameters---particularly the learning rate---at extreme scales of both model size and token budget via sweeping remains computationally prohibitive. In this paper, we propose a compute-efficient, two-step hyperparameter transfer framework that estimates optimal learning rates for training large MoE models by transferring them across scaling model widths, and subsequently extrapolating to trillion-token horizons. First, we formulate a Maximal Update Parameterization ($μ$P) adaptation for MoE architectures utilizing Multi-head Latent Attention (MLA) and the Muon optimizer, demonstrating that optimal learning rates transfer consistently across width-scaled models. Second, we extend this transferability along the token dimension by establishing a predictive scaling law. By applying linear regression to the optimal values derived from small proxy models on limited budgets, we successfully extrapolate the ideal learning rate to massive training horizons (e.g., 10 trillion tokens) with high fidelity ($R^2=0.95$). Consequently, this indicates that proxy training on small models is sufficient to determine the optimal learning rate for the extensive training of large-scale MoEs. We apply the proposed methodology to pretrain our foundation model (155B total, 17B active parameters) from scratch, and the stable training and evaluation results validate that optimal configurations for full-scale target models can be accurately predicted with minimal ablation costs.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：混合专家（Mixture-of-Experts, MoE）架构能在不按比例增加计算成本的情况下大幅提升模型容量，已成为大规模语言模型的主流选择（如 DeepSeek-V3、Qwen3、Kimi-K2.5、GLM-5 等）。但 MoE 引入了更多超参数（如专家路由、负载均衡相关），使得超参数调优比稠密模型更复杂、更昂贵。
- **核心问题**：在模型规模和 token 预算都极大的情况下（例如总参数量超过 100B、训练 token 数达到万亿级），通过穷举扫描来确定最优学习率在计算上不可行。最优学习率对模型大小和训练数据量都非常敏感，每次改变规模都需要重新搜索。
- **现有方案的不足**：已有的 μP / μ-Transfer 等方法主要针对稠密模型和宽度缩放，而 MoE 还引入了“稀疏性”维度（总专家数与激活专家数之比），现有框架是否适用于 MoE 的宽度+稀疏度联合缩放尚未被充分验证。
- **本文的整体含义**：提出一种计算高效的两步超参数迁移框架，先在宽度维度上利用 μP 实现学习率迁移，再沿 token 维度建立缩放律，从而以极小的代理实验成本预测大规模 MoE 长训练的最优学习率，并进行了 155B 总参 / 17B 激活参数、10 万亿 token 的实际预训练验证。

### 2. 方法论：核心思想、关键技术细节与流程

本文提出“两步超参数迁移”框架，将模型规模（M）与 token 规模（D）两个维度解耦：

1. **第一步：μP 适配 MoE 架构（宽度迁移）**
   - 将模型参数按形状分为向量类（vector-like）和矩阵类（matrix-like）参数。
   - 对矩阵类隐藏权重应用 μP 初始化与学习率缩放；向量类（如 embedding、bias、专家 FC2 权重）仅做 μP 初始化，不缩放学习率。
   - 对 MLA（Multi-head Latent Attention）的低秩投影维度保持固定，使对应上投影矩阵的学习率缩放因子为 1。
   - 缩放路径：保持激活专家数 k 和 MoE 中间维度固定，增加隐藏维度、总专家数和注意力头数；即宽度与稀疏度联合缩放。
   - 在 Muon 优化器上验证 μP 迁移有效性，并采用 Muon 的 RMS 匹配技巧（学习率乘以 \(0.2 \cdot \sqrt{\max(A, B)}\)），使 AdamW 调好的学习率可直接迁移。

2. **第二步：token 维度缩放律（外推最优学习率）**
   - 使用 WSD（Warmup-Stable-Decay）调度器，但代理实验在稳定阶段提前终止，不进行衰减，改用指数移动平均（EMA）平滑权重，模拟衰减效果，从而从一次运行中提取多个 token 预算下的检查点。
   - 对每个 token 预算 \(B\)，用二次多项式拟合验证损失 \(L\) 与对数学习率 \(\log \eta\) 的关系：
     \[
     L(\eta) = a(\log \eta)^2 + b(\log \eta) + c
     \]
     抛物线顶点给出该预算下的最优学习率 \(\eta^* = \exp(-b/(2a))\)。
   - 在 \(\log \eta^*\) 与 \(\log B\) 之间做线性回归：
     \[
     \log(\eta^*) = \beta \log(B) + \gamma
     \]
     从而外推到 10T token 等极长训练范围。
   - 显式将 batch size 排除在迁移目标之外，固定 batch size 以最大化硬件效率，只迁移学习率，避免文献中关于最优 batch size 的争议。

- 在 MLA + Muon + MoE 的设定下，μP 能实现跨宽度（1×～8×）的学习率零样本迁移，而 SP 则失败。

### 8. 不足与局限

- 无法直接验证最优性：缺少在 10T token 规模上的完整学习率扫描，所谓“最优”是外推得到的，只能以“稳定训练+良好评测”间接确认。
