## 摘要
本文提出了一种具有混合专家（MoE）路由的Mamba替代模型，用于表示基于逆变器的资源的暂态动态。Mamba替代模型是一种基于Mamba架构的预测性机器学习模型。MoE路由使用路由器网络为专门的子网络（专家）分配数据相关的权重。所得的Mamba--MoE替代模型可以执行两项任务：（i）闭环仿真和（ii）逆变器暂态的测量窗口预测。一个具有任务条件和专家路由的单一Mamba主干网络同时服务于两项任务，取代了两个单独的专用模型。任务匹配的目标函数适配每种预测形式，自适应共形层为两项任务提供预测区间。对于所考虑的电网跟随逆变器，统一替代模型与一对Mamba专用模型保持相同的低误差区间，同时参数减少了13%。预测区间在两项任务中实现了94-96%的经验平均边际覆盖率。对于暂态动态——即平衡点附近之外的情况——与没有专家路由的共享Mamba主干网络相比，我们的具有MoE路由的替代模型在两项任务的所有输出上均产生了更低的误差。控制器硬件在环仿真验证了我们的结果，并表明仅使用有限的测量数据自适应共享输出头即可降低留出预测误差。

## Abstract
This paper proposes a Mamba surrogate model with mixture-of-experts (MoE) routing to represent the transient dynamics of inverter-based resources. A Mamba surrogate model is a predictive machine learning model built on the Mamba architecture. MoE routing uses a router network to assign data-dependent weights to specialized subnetworks (experts). The resulting Mamba--MoE surrogate can perform two tasks: (i) closed-loop simulation and (ii) measurement-window forecasting of inverter transients. A single Mamba backbone with task conditioning and expert routing serves both tasks, replacing two separate specialists. Task-matched objectives fit each prediction form, and an adaptive conformal layer provides prediction intervals for both tasks. For the considered grid-following inverter, the unified surrogate model remains in the same low-error regime as a Mamba specialist pair while using 13% fewer parameters. The prediction intervals achieve 94--96% empirical mean marginal coverage across the two tasks. For transient dynamics---that is, beyond the vicinity of an equilibrium point---our surrogate model with MoE routing yields lower errors across all outputs in both tasks compared to a shared Mamba backbone without expert routing. A controller hardware-in-the-loop simulation validates our results and shows that adapting only the shared output head with limited measured data reduces held-out forecasting error.

## 1. 论文的核心问题与整体含义

- **研究背景**：随着以逆变器为基础资源（IBR）在电力系统中的渗透率迅速提升（如 ERCOT 已超过 60%），IBR 的暂态动态建模变得至关重要。然而，传统第一性原理模型面临严重困难：IBR 物理参数因厂商硬件/软件实现而异、控制器结构复杂且多为非线性、厂商因安全和知识产权原因不公开内部细节，通用模型参数化又存在结构选择和可辨识性问题。
- **核心问题**：是否可以用**单一学习型替代模型**同时完成两项任务——(i) **闭环仿真**（自回归 rollout，预测逐步反馈给自身作为输入）和 (ii) **测量窗口预测**（基于固定长度的最近测量窗口一次性输出未来 H 步）。以往需要两个独立专用模型分别处理两项任务，造成参数冗余和动态信息重复。
- **整体含义**：本文证明可以通过一个统一模型（Mamba–MoE）共享两种任务背后的动力学结构，同时通过任务条件和专家路由保留任务特定的预测行为，实现低误差、参数高效、带不确定性量化（预测区间）的 IBR 暂态建模。

## 2. 论文提出的方法论

- **核心架构（Mamba–MoE）**：
  - **Mamba 主干**：基于选择性状态空间模型（SSM），递归更新隐藏状态以捕获暂态轨迹中的时间依赖。关键递归更新：`Δt = softplus(htWΔ)`, `Āt = exp(Δt ⊙ A)`, `st = Āt ⊙ st−1 + Δt ⊙ (htB)`，其中 A < 0，确保状态衰减稳定。
  - **任务条件化（FiLM）**：二进制任务标签 m ∈ {0,1}（0=仿真，1=预测）映射为任务嵌入 cm，通过特征级线性调制（FiLM）对每个 Mamba 块的层归一化进行调制：`γ = 1 + g_FiLM, LN_FiLM(u) = γ ⊙ LN(u) + β`。初始化时 γ=1、β=0，退化为标准层归一化。
  - **MoE 路由**：路由器网络将隐藏表示 hr 与任务嵌入 cm 拼接后映射到 K 个专家的 logits，经 softmax 得到软权重 gk，专家混合输出 `e = Σ gk·Ek(hr)`。采用密集软路由而非稀疏 top-k 路由，避免负载不均衡问题。
  - **统一输出头**：共享输出 Mamba 块 + 线性头生成 H 步残差矩阵；仿真只用第一步残差 `x̂_{t+1} = x̂_t + r1,t` 进行自回归 rollout，预测用全部 H 个残差 `x̂_{t+h} = x_t + rh`。
- **两阶段训练**：
  1. **预训练**：Mamba 主干先用一步残差预测目标（LPT 损失）学习与任务无关的过渡表示，任务条件向量置零；预训练头随后丢弃。
  2. **联合训练**：启用任务条件、FiLM、MoE 路由和共享输出头，最小化总损失：
     `L_total = λsim·Lsim + λfcast·Lfcast + λLB·LLB + λdiv·Ldiv`
     - Lsim：仿真 rollout Hroll 步的均方误差
     - Lfcast：预测 H 步残差的均方误差
     - LLB：负载均衡正则（基于平均软路由权重和 top-1 分配频率）
     - Ldiv：专家多样性正则（惩罚专家输出间的正余弦相似度）
- **自适应共形预测区间（ACI）**：
  - 仿真用**逐地平线共形宽度**（rollout 不确定性随时间累积）；预测用**最近窗口合并**（closest-window merging）后计算共形宽度。
  - 在线 ACI 通过覆盖率反馈更新每个输出维度的对数尺度因子：`z_{u+1}(j) = Π[−c,c]{z_u(j) + η_ACI(1[x_u,j ∉ Ĉ_u,j] − α)}`，严格前序（prequential），不泄漏未来标签。
  - 目标覆盖率 1−α = 95%。

## 6. 论文的主要结论与发现

1. **统一模型可行**：Mamba–MoE 以单一模型服务两项任务，与 Mamba 专用模型对保持同一低误差区间，参数减少约 13%（800,260 vs. 921,316）。
2. **MoE 路由在暂态下更优**：在较大运行点偏移（×1.5）条件下，K=4 的 MoE 路由在两项任务的所有输出上均优于无路由（K=1）的共享 Mamba 主干；在干净条件和较小偏移下也有更多输出取得更低误差。
3. **ACI 有效改善覆盖率**：仿真任务中静态 CP 的 MCOV 仅 91.70%（低于 95% 目标），ACI 提升至 94.47%，同时宽度减小；预测任务由 94.55% 提升至 96.04%。仿真任务中 ACI 收益最大。
4. **两个任务损失缺一不可**：移除任一任务损失会导致该任务误差急剧恶化（仿真 G-NRMSE 高达 65.65%~121.70%，预测高达 18.70%~22.74%）。
5. **共享输出头适配可行**：在 CHIL 跨系统场景中，仅用 10 s（5.1%）的实测数据微调共享输出头，冻结其余网络，平均归一化 RMSE 从 13.09% 降至 3.07%。
6. **传感器丢弃比噪声更具破坏性**：20% 随机丢弃使预测误差达 4.10% G-NRMSE，而测量噪声加倍仅为 0.23%。

## 7. 优点

- **任务统一框架**：将闭环仿真和测量窗口预测统一为共享动态的双任务学习问题，设计清晰、理论动机明确（多任务学习节省参数、共享动态信息）。
- **架构选择合理**：Mamba 的 SSM 天然适合时序递归；任务条件（FiLM）+ MoE 路由的组合既能共享表示又能适配任务差异；密集软路由避免了稀疏路由的负载不均衡和离散性。
- **不确定性量化完整**：ACI 自适应共形层为两种任务都提供校准的预测区间，且严格前序、不泄漏未来信息，具有实际部署价值。
- **实验覆盖面广**：从干净精度到分布偏移、传感器损坏、跨拓扑泛化和跨系统硬件在环验证，多角度验证了方法的鲁棒性和实用性。
- **消融设计规范**：逐一验证了任务损失、FiLM、MoE 路由的作用，且承认各设计选择的利弊（如无 FiLM 虽降低仿真空域误差但提高预测误差），较为客观。

## 8. 不足与局限

- **未报告算力资源**：缺少 GPU 型号、训练时间和推理效率数据，无法评估实际工程部署的算力代价。

- **偏差风险**：

- **应用限制**：
  - 方法本质上是数据驱动的黑箱替代模型，跨系统/跨拓扑需要目标域数据微调（零样本在 9-bus 上甚至劣于持久性预测）。
  - 暂态仿真中 rollout 误差累积的长期稳定性（超出 Hroll=20 步）未充分验证。
  - ACI 覆盖率的收敛性分析（理论上限）未讨论，接近扰动起始时刻仍存在约 0.5 个百分点的覆盖缺口。
