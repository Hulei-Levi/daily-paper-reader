## 摘要
负载不均衡是混合专家（MoE）模型分布式推理中专家并行效率的主要瓶颈。由于路由分布偏斜，负载最高的秩会阻塞全局执行，直接增加延迟。虽然离线专家放置可以缓解持续性的不均衡，但实际的多任务服务负载表现出与层和批次相关的路由动态，使得在线负载均衡不可或缺。现有方法依赖于每个MoE路由器之后收集的路由统计信息，要求专家权重加载或迁移只能在路由决策可用后开始，从而将迁移开销置于推理关键路径上。在这项工作中，我们观察到，如果能够提前准确预测路由分布，在线均衡可以在目标路由（如注意力）之前的计算阶段大部分重叠。因此，我们提出FreeBalance，一种无损的在线负载均衡框架，通过残差工作负载预测将专家迁移与前面的计算阶段重叠。FreeBalance利用残差网络中隐藏表示的跨层相似性来构建轻量级工作负载预测器。这使得在路由决策可用之前就能进行主动的专家迁移规划，在权重传输与计算密集型的路由前阶段之间产生大量重叠。此外，一个成本模型限制交换次数，以在可用窗口内完全隐藏同步开销。跨模型和数据集的实验表明，FreeBalance将最大与平均秩负载比降低了32.8%，端到端预填充延迟降低了13.1%。具体而言，我们的方法隐藏了每层平均5.1个专家的均衡开销，否则这些开销将占关键路径延迟的约8.5%。

## Abstract
Load imbalance poses a major bottleneck to the efficiency of expert parallelism in distributed inference of Mixture-of-Experts (MoE) models. The most heavily loaded rank stalls global execution due to skewed routing distributions, directly increasing latency. While offline expert placement can alleviate persistent imbalance, practical multi-task serving workloads exhibit layer- and batch-dependent routing dynamics, making online load balancing indispensable. Existing approaches rely on routing statistics collected after each MoE router, requiring expert weight load or migration to begin only after routing decisions are available, consequently placing migration overhead on the inference critical path. In this work, we observe that online balancing can instead be largely overlapped with computation before target routing (e.g., attention), if routing distributions can be predicted accurately in advance. Therefore, we propose FreeBalance, a lossless online load-balancing framework that overlaps expert migration with preceding computation stages via residual workload prediction. FreeBalance leverages cross-layer similarities in hidden representations within the residual network to build a lightweight workload predictor. This enables proactive expert migration planning before routing decisions are available, creating substantial overlap between weight transfer and computation-heavy pre-routing stages. Furthermore, a cost model constrains the number of swaps to fully hide the synchronization overhead within the available window. Experiments across models and datasets show that FreeBalance reduces the max-to-mean rank load ratio by 32.8% and end-to-end prefill latency by 13.1%. Specifically, our method hides balancing overhead of an average of 5.1 experts per layer, which would otherwise account for about 8.5% of the critical-path latency.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：在 MoE（Mixture-of-Experts，混合专家）模型的分布式推理中，专家并行（Expert Parallelism, EP）的负载不均衡问题严重拖慢整体性能。由于路由分布偏斜，负载最重的 GPU 秩（rank）成为瓶颈，迫使其他轻载设备空闲等待，直接增加推理延迟。
- **现有方案的缺陷**：
  - **离线负载均衡**（如 DeepSeek EPLB）：基于历史路由统计静态放置专家，无法适应多任务场景中随任务类型和批次动态变化的路由分布（实验中两个任务间专家激活重叠仅 4.1%）。
  - **在线负载均衡**：虽可动态迁移专家权重，但路由分布需在路由结束后才可用，导致专家迁移只能发生在路由完成与专家执行之间的窄小窗口内，该窗口正处于推理关键路径上，迁移开销直接增加延迟。
- **关键观察**：路由前阶段（尤其注意力计算）计算密集且耗时较长，若能在路由前准确预测工作负载分布，则可将专家迁移与路由前计算高度重叠，有效隐藏均衡开销。
- **论文目标**：提出 FreeBalance——一种**无损**的在线 MoE 负载均衡框架，通过残差工作负载预测打破“路由统计 → 映射调整”的顺序依赖，将平衡开销移出关键路径，实现动态、实时且不改变模型输出的负载均衡。

### 2. 方法论

#### 核心思想
利用残差网络相邻层隐藏表示的强相似性，在目标层路由执行之前（即在注意力计算阶段），提前调用同一路由器预测该层专家工作负载。基于预测结果规划专家迁移，并将权重传输与注意力计算重叠，从而隐藏迁移开销。

#### 关键技术细节

- **残差工作负载预测**：
  - 观察：残差连接使相邻层的隐藏表示高度相似，h_ℓ−1 与 h_ℓ 的余弦相似度接近 1，因此 h_ℓ−1 足以预测第 ℓ 层路由分布。
  - 做法：将同一冻结路由器 g_ℓ 调用两次：
    - 早期调用：g_ℓ(h_ℓ−1) 得到预测 logits，经 top-k 后聚合得到预测专家负载 ；
    - 正常调用：g_ℓ(H_ℓ) 产生最终路由决策，完全不受预测影响。
  - 增益：不引入任何额外预测器权重、训练流程或 checkpoint 状态，保持模型无损。
- **预算化专家交换规划（Budgeted Expert-Swap Planning）**：
  - 采用**成对专家交换**（pairwise swap）策略，保持每秩专家槽位数与内存占用不变，避免复制专家或改变调度策略。
  - 负载目标函数：Φ(L) = max_r L_r + γ Σ_r (L_r − L̄)²，兼顾最大负载与负载方差。
  - 成本模型：估计每次交换的通信代价 C(s)，结合注意力窗口长度 T_attn 和安全余量 δ 确定迁移预算 B_ℓ = max(0, T_attn − δ)。
  - 确定性贪心算法：所有 rank 基于全局一致的负载向量和放置图，按收益/成本比排序候选交换，剔除冲突项，按相同顺序本地生成相同计划，无需广播计划。
- **四阶段流程**：
  1. 残差工作负载预测（路由前）；
  2. 预算化专家交换规划（路由前）；
  3. 专家权重迁移，与注意力计算重叠；
  4. 正常路由 + 无损 MoE 计算。

### 3. 实验设计

- **模型**：Qwen3-30B-A3B-Instruct-2507（128 专家，top-8，16 专家/rank）、Moonlight-16B-A3B-Instruct（64 专家，top-6，8 专家/rank）。
- **数据集/Benchmark**：LongBench 的 19 个子集，覆盖六类长上下文能力：单文档 QA、多文档 QA、摘要、少样本学习、合成任务、代码补全。
- **动态多任务场景**：构造 **Mixed Tasks** 工作负载，每个 prefill 步骤从一个 LongBench 子集切换至另一个，模拟步间路由分布变化。
- **基线对比**：
  - Vanilla（固定专家放置）；
  - Vanilla + FreeBalance；
  - EPLB（历史驱动的离线专家负载均衡器）；
  - EPLB + FreeBalance。

### 6. 主要结论与发现

- FreeBalance 将最大/平均 rank 负载比从最高 2.01 降至 1.35，改善幅度最高达 **32.8%**。
- 在 19 个 LongBench 子集上，Qwen3-30B 平均 prefill 延迟降低 **13.1%**；TTFT 平均降低 14.7%（1K–8K 序列长度）。
- 每层平均隐藏 **5.1 个专家**的均衡开销，这部分若在关键路径上执行将占延迟的约 **8.5%**。
- 预测质量：logit 余弦相似度介于 0.9896–0.9952，top-k 命中率介于 0.7419–0.8494；在执迁移的层中 95% 实际降低了 max-to-mean 负载比。
- 自适应迁移预算优于固定迁移数策略：最长序列上 FreeBalance 达 1.1542× 加速，高于最佳固定策略的 1.1263×。
- 序列越长，重叠窗口越大（1K 时 12.55 ms → 8K 时 36.80 ms），隐藏迁移收益越明显（TTFT 改善从 11.0% 增至 23.3%）。

### 7. 优点

- **无损保障**：早期预测仅用于物理放置，最终路由仍由原路由器决定，保证输出与原始模型完全一致，实用性强。
- **零额外训练开销**：直接复用原路由器参数，无需新增预测器、权重或训练流程，部署成本极低。
- **创新性思路**：将“路由后反应式均衡”转变为“路由前预测式均衡”，首次充分利用残差网络跨层表示相似性这一结构特性来打破关键路径依赖。
- **工程实现友好**：确定性贪心规划消除了计划广播需求；成对交换保持每秩内存占用不变；成本模型按链路/秩分别限制，避免单参与者过载。
- **实验设计较全面**：覆盖多模型、多数据集、动态任务切换场景，并包含序列长度敏感性分析和重叠量测算，结论具有参考价值。

### 8. 不足与局限

- **实验覆盖有限**：仅测试两个模型（Qwen3-30B-A3B、Moonlight-16B-A3B）和两个 attention 类型（均为标准稠密注意力），未涉及混合注意力架构（如线性/稀疏注意力）的验证，而文中声称该方法支持混合注意力模型。
- **基线对比不够丰富**：未与 Lina、Harmony、UltraEP、MoonEP 等在线均衡系统直接对比，缺少与更先进方法（如冗余专家动态均衡）的横向参考。
- **真实动态压力不足**：Mixed Tasks 数据集是逐步切换子集，而非真实并发多用户混合请求，无法充分反映实际生产中路由分布的波动频率和幅度。
- **预测误差的鲁棒性分析不足**：虽然报告了 top-k 命中率，但未系统分析预测错误（如误判热门专家、负载估计偏差）对均衡效果和延迟的量化影响，安全余量 δ 的设置也缺乏敏感性实验。
- **可扩展性未验证**：实验仅在 EP = 8 的单机 NVLink 环境进行，未验证在跨节点、更大 EP 规模（如 EP = 32/64）、不同互联拓扑（如 InfiniBand）下的表现；成本模型的跨节点参数校准效果也未单独评估。
- **未报告端到端吞吐和 batch 大小敏感性**：仅在 batch = 16 下测试，未验证不同 batch size 下预测精度与迁移窗口的变化；也未报告 decode 阶段（而非仅 prefill）的负载均衡效果。
