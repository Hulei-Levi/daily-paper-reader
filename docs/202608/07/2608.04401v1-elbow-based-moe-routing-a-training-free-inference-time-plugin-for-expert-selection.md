## Abstract
Mixture-of-Experts (MoE) models enable model scaling while maintaining low inference-time compute by activating only a subset of experts per token. However, conventional routing relies on a fixed top-k selection, forcing the model to spend the same compute regardless of how many experts are relevant. We introduce elbow-based routing, a training-free inference-time modification that dynamically adjusts the number of experts on a per-token basis. Our method examines the sorted router probability distribution and identifies an elbow point that separates high- and low-probability experts. We find that most router distributions exhibit clear inflection points suitable for this strategy, and we show both theoretically and empirically that elbow-based routing preserves expert load balance. Experiments on a state-of-the-art MoE model demonstrate an average latency reduction of 5.3% while maintaining accuracy across six benchmarks.

### 1. 核心问题与整体含义

- **背景**：混合专家（MoE）模型通过为每个 token 仅激活部分专家，在保持低推理成本的同时实现模型规模扩展。
- **核心问题**：传统 MoE 路由采用**固定 top-k 选择**，无论当前 token 实际需要多少专家，均消耗相同的计算量。这导致两类问题：
  - 仅需少量专家的简单 token 被强制分配额外的专家，造成计算浪费；
  - 需要更多专家的复杂 token 可能面临"欠路由"（under-routed），限制了模型表达能力。
- **研究动机**：已有动态路由工作（如 Huang et al. 2024 的 top-p 路由、Guo et al. 2025 的 DynMoE）虽能调整专家数量，但**需要训练新路由器、引入辅助损失，或依赖昂贵的超参数网格搜索**。
- **研究问题**：能否在不重新训练、不引入额外超参数的前提下，让 MoE 模型在推理时动态调整每个 token 激活的专家数量，以降低延迟并保持精度？
- **整体含义**：本文提出的**基于肘部法则的路由（Elbow-Based Routing）**是一种**免训练、即插即用的推理时插件**，通过检测路由概率分布的拐点来动态决定专家数量，在保持精度的同时提升推理效率。

### 2. 方法论

- **核心思想**：MoE 路由器的 softmax 输出概率经降序排序后，通常呈现"**头部快速衰减 + 尾部平坦**"的结构。头部对应与当前 token 高度相关的"信号专家"，尾部对应相关性低的"噪声专家"。通过检测这一转折点（肘部），即可动态估计该 token 真正需要激活的专家数量。
- **算法流程（Kneedle 风格肘部检测）**：
  1. 对路由器输出的 logits $\ell(x) \in \mathbb{R}^N$ 施加 softmax，得到概率向量 $p(x)$；
  2. 将 $p(x)$ 降序排列为 $p_{(1)} \ge p_{(2)} \ge \dots \ge p_{(N)}$；
  3. 将索引和概率值分别归一化到 $[0,1]$；
  4. 计算每条曲线与参考线（从 $(0,0)$ 到 $(1,1)$ 的对角线）的垂直距离 $D_i = p'_i - x'_i$；
  5. 选择最大垂直距离对应的索引作为肘部索引 $e(x)$（即最大偏差法）。
- **专家数量确定**：最终激活的专家数为 $k(x) = \min(e(x), K)$，其中 $K$ 是原始模型固定 top-K 的激活数。这种**单调剪枝规则**保证：$k(x) \le K$，保持专家相对排序，不引入新专家，无需改动模型权重或结构。
- **信号-噪声解释**：路由器输入 $x$ 可分解为 $\mathbf{x} = \mathbf{x}_\parallel + \mathbf{x}_\perp$，分别对应路由相关方向的分量和残余噪声。与信号对齐的专家获得较大 logits 形成头部，受噪声主导的专家产生平坦尾部。肘部点即两者的分界，这一解释通过"尾部随机化"实验（替换肘部之后的专家不影响精度，替换肘部之前的专家则精度显著下降）得到验证。
- **肘部特征分析**：利用肘部角 $\theta$（第一点、肘部点、最后一点构成的几何夹角）量化"肘部程度"。对超过 200 万个路由分布的分析显示 **99.7% 的场景呈现清晰锐利的肘部（$\le 135°$）**，且该特征在不同数据集、不同路由层间高度稳定。
- **负载均衡理论保证**：定义 $\delta = 1 - \mathbb{E}[k(x)]/K$ 为期望剪枝比例，作者证明归一化专家利用率分布的变化满足：
$$\|q^{(elb-K)} - q^{(top-K)}\|_1 \le \frac{2\delta}{1 - \delta}$$
  该定理保证肘部路由对专家负载分布的影响有界；推论进一步保证最高负载专家的负载变化和 CV²（变异系数）变化均受控。

### 6. 主要结论与发现

- 肘部路由在 **6 个基准上平均降低 5.3% 延迟**（如 MMLU 从 13.287ms 降至 12.571ms），同时准确率**完全保持**（最大差异不超过 0.33 个百分点，部分数据集如 ARC-Easy、ARC-Challenge 甚至略有提升）。
- 平均每个 token 激活专家数为 **7.615**，对应 5% 的平均剪枝率（$\delta = 0.05$）。
- **路由概率分布普遍具有清晰、稳定的肘部特征**（99.7% 锐利），且与输入类型、路由层、数据集学科高度无关，表明 MoE 路由器内部存在普遍的"头-尾"信号结构。
