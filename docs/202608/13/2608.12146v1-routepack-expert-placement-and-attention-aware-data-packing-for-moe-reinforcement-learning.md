## 摘要
训练用于强化学习（RL）的混合专家（MoE）模型耦合了两个负载均衡问题：序列组合决定了每个数据并行微批次中的密集注意力计算量，而令牌路由则决定了专家并行秩上的稀疏专家计算量。单独优化任一方面都可能将瓶颈转移到另一方面。在MoE强化学习中， rollout期间的路由重放会在训练步骤之前暴露每个样本的序列长度和逐层专家需求。我们提出了RoutePack，一个分层规划器，它在优化器步骤窗口内协调状态一致的、逐层的专家重路由，并联合考虑注意力和专家感知的数据打包。RoutePack首先利用聚合路由需求在每个MoE层独立放置专家。然后，它将样本打包到最小的经过验证的或已知最佳可行的、具有令牌上限的执行行中，并通过投影的EDP分片感知目标优化其DP布局。该目标结合了窗口归一化的线性二次注意力代理与每层物理EP秩峰值，并最小化最慢EDP分片的累积成本。并行群体退火在保持样本覆盖、容量、非空单元、相等微批次数量和通信器拓扑的同时，搜索固定行可行布局。状态一致的物化保持了逻辑top-k路由和现有MoE内核，无需微批次级专家复制。在Ling-3.0-Tiny和Ling-3.0-Flash上，专家重路由分别将训练器测量的平均令牌吞吐量提高了3.80%和10.50%，而路由感知打包分别额外增加了4.86%和3.98%。总体而言，RoutePack相较于基线将吞吐量提高了8.85%和14.89%。

## Abstract
Training Mixture-of-Experts (MoE) models for reinforcement learning (RL) couples two load-balancing problems: sequence composition determines dense attention work in each data-parallel microbatch, while token routing determines sparse expert work on expert-parallel ranks. Optimizing either alone can shift the bottleneck to the other. In MoE RL, rollout-time routing replay exposes every sample's sequence length and layer-wise expert demand before its training step. We present RoutePack, a hierarchical planner that coordinates state-consistent, layer-wise expert rerouting with joint attention- and expert-aware data packing over an optimizer-step window. RoutePack first places experts independently at each MoE layer using aggregate routing demand. It then packs samples into the smallest certified, or best-known feasible, number of token-capped execution rows and optimizes their DP layout with a projected EDP-shard-aware objective. The objective combines a window-normalized linear-quadratic attention proxy with per-layer physical EP-rank peaks and minimizes the accumulated cost of the slowest EDP shard. Parallel population annealing searches fixed-row feasible layouts while preserving sample coverage, capacity, nonempty cells, equal microbatch counts, and communicator topology. State-consistent materialization preserves logical top-k routing and existing MoE kernels without microbatch-level expert replication. Across Ling-3.0-Tiny and Ling-3.0-Flash, expert rerouting improves mean trainer-measured token throughput by 3.80% and 10.50%, while routing-aware packing adds another 4.86% and 3.98%, respectively. Overall, RoutePack improves throughput by 8.85% and 14.89% over the baseline.

# RoutePack：面向MoE强化学习的专家放置与注意力感知数据打包

## 1. 核心问题与研究动机

**问题背景。** 在混合专家（Mixture-of-Experts, MoE）模型的强化学习（RL）训练中，一个训练步骤内同时存在两个相互耦合的负载均衡问题：

- **密集注意力负载**：由每个数据并行（DP）微批次的序列组成与长度决定；
- **稀疏专家负载**：由令牌在专家并行（EP）秩上的路由分配决定。

这两个问题分别由样本打包和令牌路由控制，若孤立地优化其中一个，瓶颈会转移到另一个。例如，仅做长度感知的打包可能将激活相同专家（相同路由签名）的长序列集中在一起，从而加剧专家侧峰值；而仅做专家侧的负载均衡则无法解决行内样本组合造成的注意力倾斜，也无法消除行局部的专家热点。

**特殊机遇。** MoE RL 中存在一个独有的信息优势——**路由重放（routing replay）**：Rollout 阶段与训练阶段处理相同的生成序列，因此可以在训练步骤被调度之前，提前获得每个样本的精确序列长度和逐层（layer-wise）的专家路由需求。这使得**同时协调"专家放置"与"样本打包"**成为可能，将数据布局从路由盲目的预处理升级为负载均衡控制手段。

**核心观察。** 作者证明了两个结构性结论：

1. **打包无法消除优化器窗口级的专家偏斜**：对于一个固定的专家放置，样本重排只改变专家需求暴露的时间，不改变每个物理秩在窗口内的总需求。当窗口级路由分布本身偏斜时，必须改变专家映射才能打破该下界。
2. **专家放置也不保证行局部的负载均衡**：即使窗口总量趋于均衡，路由相关的样本若被打包进同一行，仍可造成行级热点。

## 2. 方法论

### 2.1 总体框架：分层协调规划

RoutePack 采用**分层规划**（hierarchical planning），而非一次性求解单一全局问题，共分三个阶段：

```
阶段一：逐层 LPT 专家放置（固定专家映射 π）
阶段二：最小行数打包（确定并固定行数 R★）
阶段三：EDP 感知数据打包（在 R★ 内优化样本布局）
```

这种"先固定上界、再优化下料"的顺序避免了通过增加执行行或改变 EDP 通信拓扑来换取虚假负载均衡增益的做法。

### 2.2 阶段一：逐层专家放置

采用**最长处理时间（LPT）贪心调度**：对每个 MoE 层独立进行，按专家聚合路由需求降序排列，依次将专家分配给当前负载最小的物理 EP 秩，同时保证每个秩恰好持有 𝐻 个专家槽位。该阶段改进的是**打包不可改变的总量下界**，而非逐行峰值。

**状态一致性物化**：专家放置通过逻辑专家到物理槽位的映射表实现，不改变张量形状、通信器成员关系、梯度缓冲区描述符、分布式优化器的参数分片等，仅在训练步骤边界提交。路由器输出逻辑专家顺序不变，调度器在分发前施加逆列置换。逻辑 top-k 路由、DeepEP 的 dispatch/combine 接口等均无需修改。允许浮点重排序导致的 ULP 级数值漂移，但不改变逻辑输出与梯度。

### 2.3 阶段二：最小行数确定

约束条件（对容量 𝐶、DP 槽位数 𝐷、行数 𝑅）：
- 每个样本恰好出现一次（样本双射）；
- 每行每槽非空；
- 每单元内样本总 token 长度 ≤ 𝐶（容量约束）。

最小可行行数 𝑅★ 通过固定箱可行性检查确定；如果存在规划时间限制，则使用已知最佳可行行数。

### 2.4 阶段三：联合注意力-专家感知目标

**注意力代理（式 2、11、12）**：对注意力算子 A 定义两阶段线性-二次代理：

```
F_A(B) = α_A · Σ t_i + β_A · Σ t_i²     (β_A ≥ 0)
```

- 线性项（α）：投影、线性注意力、固定窗口注意力；
- 二次项（β）：全注意力的 token-pair 相互作用。

执行行在注意力类型的分段代价为按 DP 单元取最大值（在 EDP 分片内）后再跨阶段累加。评估的 Ling 模型中，KDA 用 β=0（线性），MLA 用 β>0（线性+二次）。

**专家负载代理（式 13、14）**：在一个 EDP 分片（EDP shard，即投影到同一物理 EP 通信器的 DP 槽位集合）内，逐 MoE 层累加物理 EP 秩的 routed-token 总数，并对每个层取最忙秩。

**最终精确得分（式 15，字典序）**：

```
Score(x; π) = ( max_g Σ_r J_{r,g},  Σ_g Σ_r J_{r,g},  max_{r,g} J_{r,g} )
```

三个分量依次为：全窗口最慢 EDP 分片的累积代价（主目标）、总投影代价（第一平局打破）、最差行局部尾（第二平局打破）。

### 2.5 搜索算法：多样种子 + 并行群体退火

- **多样种子生成（算法 2）**：三种构造算子——Window Shuffle（扰动长度降序）、RandomizedBestFit（按适应性选箱）、EDPAwarePair（感知路由峰值的行-槽映射）；随后正则化去重、按模糊哈希保持多样性、质量-多样性选择出初始群体。
- **并行群体退火（算法 3）**：每个温度层内各群体成员独立执行 𝐾 步固定温度联合模拟退火，用 Metropolis 准则依据标量搜索能量接受/拒绝候选（swap 或 relocation）。温度层间采用**系统重采样**，轨迹最优（trajectory-best）与终态（terminal）分离——终态仅用于重采样，轨迹最优仅用于更新全局最优。最终断言非回归性（不低于最佳初始种子）。

## 6. 主要结论与发现

1. **吞吐量提升**：在 Ling-3.0-Tiny 上，专家重路由提升 3.80%，路由感知打包再提升 4.86%，合计 **8.85%**；在 Flash 上重路由提升 10.50%，打包再提升 3.98%，合计 **14.89%**。第 10 百分位吞吐量 Tiny 从 39,651 提升到 43,891 tokens/s，Flash 从 61,588 提升到 75,033 tokens/s。所有两两对比在校正后仍显著（最大调整后 p 值 0.0110）。
2. **全局 EP 秩 CV**：LPT 在两种模型上将聚合 EP 秩变异系数降低超过 99%（Flash 低于日志分辨率上限）。
3. **打包的增量效果**：在固定专家放置下，长度导向 FFD 到引导打包使累加 EP 峰值降低约 3%、最差行/层峰值降低约 11%、EP 平衡效率分别从 0.891→0.920（Tiny）和 0.844→0.869（Flash）。
4. **联合目标的行为**：打包在注意力和专家两种负载之间做了权衡——注意力代理代价微增（Tiny +0.09%、Flash +0.77%），但联合瓶颈代理下降（Tiny −1.53%、Flash −1.35%）。这说明联合目标确实实现了跨组件的协调而非各组件独立改进。

## 7. 优点

- **问题建模精巧**：准确区分了 DP 单元注意力范围与 EDP 分片专家范围，避免优化没有对应实际集合体的代理量；准确识别了聚合偏斜下界与行局部峰值两个不同层次的不均衡来源。
- **分层优化避免了组合爆炸**：先固定专家映射、再固定行数、最后做样本布局搜索，每一步都有明确的可行性约束，既控制了搜索空间又保证了部署兼容性。
- **工程可行性高**：状态一致物化（step-boundary contract）使得 RoutePack 可以在不修改 MoE 内核、不引入微批次级专家复制、不改变 PP/TP/CP/EP/EDP 拓扑的前提下直接集成进现有栈（DeepEP 原样保留）。
- **保持训练语义**：样本双射、容量约束、非空单元、相等微批次数量等要求全部保留，且逻辑路由不变、梯度流仍可微，提供了正确性论证。
- **去重与多样性设计扎实**：对等价布局的 canonicalization、Sliced-Wasserstein 模糊哈希、质量-多样性选择、系统重采样、轨迹最优与终态分离等细节处理严谨，规避了经典群体退火中的常见问题。
- **复杂度分析完备**：给出了明确的主机侧并行复杂度上界，并导出了 CPU 打包不延长训练准入关键路径的充分条件。

## 8. 不足与局限

- **实验覆盖范围窄**：仅一个数据集（GSM8K）、一个 RL 算法配置（GRPO 64×8）和同一模型家族的两个 checkpoint；未覆盖编码、STEM、指令跟随、混合领域等多个场景，也缺乏大规模、跨节点、PP/CP 双维度的系统实验。
- **未验证理论调度的实际实现**：论文明确承认第 4.2 节的并行调度和零开销条件**尚未实现**，规划器实际执行、进程/IPC 开销、主机资源争用、状态传输与同步等暴露延迟均未量化。
- **目标函数为代理模型**：注意力用线性-二次近似、专家用最忙秩聚合路由负载近似，未建模框内序列数量与形状、秩内专家负载分布、活跃专家数、grouped-GEMM 磁贴和占用效应、算子规模的非线性行为，也未显式建模 all-to-all 拓扑与通信代价；在通信主导或拓扑敏感部署上可能需要扩展。
- **无模型质量对比**：未报告优化轨迹/模型质量（如 RL 训练曲线）随吞吐量提升的变化。
- **可复现性**：由于评估时相关 checkpoint 未公开，论文建议将来发布等价配置与路由轨迹，这反映出当前结果复现存在困难。
- **规划成本的门槛**：收益依赖于路由多样性与序列长度异质性，对于均匀路由或很小规划窗口的负载，收益有限；需要部署中动态调整搜索预算。
