## 摘要
我们介绍了Motif 3，一个仅解码器的混合专家语言模型，总参数为3140亿，每个token激活132亿参数。每个稀疏MoE层包含384个路由专家，每个token选择其中八个。这种细粒度稀疏性提供了充足的专家容量，同时限制了计算量。Motif 3围绕分组差分潜在注意力（GDLA）构建，该注意力将分组差分注意力与多头潜在注意力的压缩键值表示相结合。该架构进一步融入了改进的流形约束超连接、专家特定PolyNorm激活和多token预测，以提高优化稳定性、专家专业化和推理效率。我们在约12.5万亿个token上预训练Motif 3，涵盖网页文档、STEM、代码、数学、多语言内容和领域专业化语料库。专家平衡和数值稳定化技术支持大规模稳定训练，而选择性MXFP8计算和通信、内存高效的融合内核以及窗口感知的上下文并行使训练上下文长度达到256K个token。我们的后训练流程结合了通用监督微调、六个通过强化学习训练的专家教师、一个通过监督微调训练的软件工程教师，以及多教师在线策略蒸馏。最终的统一模型整合了推理、编码、工具使用、专业工作、长上下文理解、校准弃权和指令遵循等互补能力。在广泛的评估套件中，Motif 3展现出与领先的开源权重模型相当的性能，包括在长时程智能体任务、数学推理、科学知识和幻觉敏感评估上的强劲表现。

## Abstract
We introduce Motif 3, a decoder-only Mixture-of-Experts language model with 314 billion total parameters and 13.2 billion activated per token. Each sparse MoE layer contains 384 routed experts, with eight selected per token. This fine-grained sparsity provides substantial expert capacity while limiting computation. Motif 3 is built around Grouped Differential Latent Attention (GDLA), which integrates grouped differential attention with the compressed key-value representation of Multi-head Latent Attention. The architecture further incorporates modified manifold-constrained hyper-connections, Expert Specific PolyNorm activations, and multi-token prediction to improve optimization stability, expert specialization, and inference efficiency. We pretrain Motif 3 on approximately 12.5 trillion tokens spanning web documents, STEM, code, mathematics, multilingual content, and domain-specialized corpora. Expert-balancing and numerical-stabilization techniques support stable training at scale, while selective MXFP8 computation and communication, memory-efficient fused kernels, and window-aware context parallelism enable training with context lengths up to 256K tokens. Our post-training pipeline combines general supervised fine-tuning, six specialist teachers trained with reinforcement learning, a software-engineering teacher trained with supervised fine-tuning, and Multi-teacher On-Policy Distillation. The resulting unified model consolidates complementary capabilities in reasoning, coding, tool use, professional work, long-context understanding, calibrated abstention, and instruction following. Across a broad evaluation suite, Motif 3 demonstrates competitive performance against leading open weight models, including strong results on long-horizon agentic tasks, mathematical reasoning, scientific knowledge, and hallucination-sensitive evaluation.

- **研究动机**：大语言模型正向更强的推理、编码、工具使用和长时程智能体任务演进，但开放权重模型与专有系统之间仍存在能力差距。MoE架构虽能扩展模型容量而不成比例增加计算成本，但如何设计更高效、更具表达力的架构，将大规模训练转化为广泛可泛化的智能，仍是核心挑战。
- **核心问题**：现有MoE模型在专家容量与计算效率之间难以平衡；长上下文注意力机制存在效率与稳定性瓶颈；大规模训练下的路由坍缩、专家退化与激活异常值难以稳定控制。
- **整体含义**：Motif 3验证了“细粒度稀疏MoE + 新型注意力架构 + 系统性后训练整合”的技术路线，在314B总参数量、仅13.2B激活参数的条件下，达到与更大规模开放模型竞争的性能水平，证明了稀疏缩放与优化稳定技术的有效性。

### 2. 论文提出的方法论

- **整体架构**：仅解码器Transformer MoE模型，53层（2层密集 + 51层MoE），隐藏维度4096，总参数约314B，每token激活约13.2B参数。
- **核心创新——分组微分潜在注意力（GDLA）**：
  - 结合分组微分注意力（GDA）与多头潜在注意力（MLA），在保留微分注意力的噪声抑制能力的同时，通过低秩潜在表征大幅压缩KV缓存。
  - 查询路径分为信号头（64个）和噪声头（16个），信号头按分组比率g=4对噪声头输出进行受控重复；采用输入依赖的token级系数λt = σ(xtWλ) ∈ (0,1)缩放噪声项后再相减。
  - 引入基于查询潜在表征的逐元素sigmoid输出门控，使模型能按token控制注意力输出通道。
  - 混合注意力调度：每4层中1层使用全因果注意力、3层使用128-token滑动窗口注意力。
- **修改的流形约束超连接（mHC）**：用多并行残差流替代单一残差流，动态学习token依赖的映射；约束残差映射为Birkhoff多胞形（双随机矩阵），保留凸混合结构；后映射乘子从2退火至1，防止深层残差放大导致激活异常值累积。
- **专家特定PolyNorm激活**：为每个专家学习独立的3次多项式系数与偏置，系数经sigmoid约束在(0,1)、偏置裁剪至[-0.5,0.5]；各多项式分量先经RMS归一化再线性组合，解耦幅值与输入尺度，促进专家专业化。
- **MoE设计**：每层384个路由专家 + 1个共享专家，top-8路由；sigmoid路由 + 无辅助损失的专家选择偏置 + 序列级辅助负载均衡损失 + 衰减路由噪声 + 分层辅助损失系数。
- **稳定性技术**：FP32路由计算、FFN幅值正则化（软辅助惩罚）、专家健康监控（包括基于激活的专家相似度度量）、路由坍缩时从相邻层替换路由参数。
- **训练系统优化**：
  - 分层并行：EP=8（节点内NVLink）、DP-shard=8、DP-replicate；上下文并行仅用于长上下文阶段（CP=8，复用EP维度）。
  - 低精度训练：MXFP8用于MoE专家GEMM（DeepGEMM后端）；激活在EP分发前预量化（通信减半、量化成本降至1/8）；梯度同步用BF16传输、FP32本地累加；行到列MXFP8转换省一半通信。
  - Muon优化器：并行化Newton-Schulz正交化；QK-Clip控制注意力logit增长（考虑GQA共享键衰减问题，使用非对称裁剪）；优化器状态CPU卸载。
  - 长上下文训练：滑窗层用窗口感知Ring Attention（单次halo交换），全注意力层用Ulysses（消除文档掩码导致的不均衡）；注意力负载感知重调度（LPT启发式）均衡数据并行副本间的计算量。
- **后训练管线**：
  - 通用SFT（初步模型用于数据构建，最终从预训练checkpoint重新训练）。
  - 六位GRPO专家教师（智能体工具使用、专业工作、长上下文推理与弃权、数学、代码与科学、聊天）覆盖13个验证域 + 一位SFT软件工程教师。
  - 多教师在线策略蒸馏（MOPD）：以通用SFT模型为学生，按域路由到对应教师，使用ICE-POP重要性权重过滤，蒸馏token级对数概率，环境奖励不参与优化。

### 7. 优点

- **架构创新性强**：GDLA将微分注意力、MLA、分组头分配、逐元素门控四者有机结合，兼顾噪声抑制、KV缓存压缩与信号建模容量；在注意力机制设计上具有原创性。
- **系统工程深度扎实**：MXFP8选择性精度管理、窗口感知上下文并行（滑窗层halo交换 + 全注意力层Ulysses）、注意力负载感知重调度、QK-Clip非对称裁剪等技术细节丰富且可复现，反映了极高的工程水平。

- **开放资源**：提供了训练系统优化的参考实现仓库（motif3-training-example），利于复现与社区借鉴。
