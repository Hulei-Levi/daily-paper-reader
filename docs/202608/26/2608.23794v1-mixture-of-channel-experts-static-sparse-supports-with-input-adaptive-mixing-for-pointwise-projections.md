## 摘要
混合专家（MoE）通过将每个输入路由到一小部分独立参数化的专家来扩展语言模型。我们表明，将这种设计复制到卷积网络中会因结构原因而失败：读取相同输入通道的并行卷积专家会学习到几乎相同的滤波器。因此，我们将专家轴从算子复制转移到通道选择。我们引入了通道专家混合（MoCE），这是一种受MoE启发的结构化稀疏通道混合层，用于替代逐点（1x1）通道缩减投影。在MoCE中，一个专家是单个输出通道，具有学习的稀疏支持，支持k << C个输入通道。所选通道通过softmax组合，其温度按输入预测，因此每个专家可以在均值式与最大值式聚合之间切换。残差专家汇总未选择的通道，负载均衡损失保持通道覆盖完整。MoCE用相对成本随k/C缩放的机制替代了成本与C成二次关系的密集投影，预测的节省在实测墙钟时间中得到验证。在ImageNet-1K和CIFAR-100上的ResNet骨干网络、迁移学习、EfficientViT以及强现代训练配方中，MoCE匹配或超过密集基线和先前的通道选择方法，同时减少16.7%的MAC和端到端延迟。

## Abstract
Mixture-of-Experts (MoE) scales language models by routing each input through a small set of independently parameterized experts. We show that copying this design into convolutional networks fails for a structural reason: parallel convolutional experts that read the same input channels learn nearly identical filters. We therefore move the expert axis from operator duplication to channel selection. We introduce Mixture of Channel Experts (MoCE), a structured sparse channel-mixing layer, inspired by MoE, that replaces pointwise (1x1) channel-reduction projections. In MoCE, an expert is a single output channel with a learned sparse support of k << C input channels. The selected channels are combined by a softmax whose temperature is predicted per input, so each expert can move between mean-like and max-like aggregation. A residual expert summarizes the unselected channels, and a load-balancing loss keeps channel coverage complete. MoCE replaces a dense projection whose cost is quadratic in C with a mechanism whose relative cost scales as k/C, and the predicted savings hold in measured wall-clock time. Across ResNet backbones on ImageNet-1K and CIFAR-100, transfer learning, EfficientViT, and a strong modern training recipe, MoCE matches or exceeds dense baselines and prior channel-selection methods while reducing MACs by 16.7% and end-to-end latency.

## 一、核心问题与整体含义

- **研究动机**：混合专家（Mixture-of-Experts, MoE）通过将每个输入路由到少量独立参数化的专家来扩展模型容量，在语言模型中取得巨大成功。本文作者尝试将这一设计模式直接移植到卷积网络（CNN）中，但发现存在**结构性的失败原因**：当多个并行卷积专家读取相同的输入通道并共享相同目标时，它们学到的卷积核几乎完全相同（实验测得ResNet-50/CIFAR-100上八专家核间平均余弦相似度高达0.88，大部分在0.85–0.97之间），导致专家分化失效，参数被浪费。
- **核心洞察**：与其在“算子复制”（operator duplication）维度上做专家化，不如将专家轴转向**通道选择**（channel selection）——即让每个输出通道作为一个专家，学习从C个输入通道中选取k个稀疏子集进行混合。
- **整体意义**：本文提出的MoCE层替代了计算成本随通道数呈二次增长的密集1×1逐点投影，以相对成本k/C的稀疏混合机制实现了相近或更优的精度，同时减少MACs、部署参数和端到端延迟。这项工作将MoE专家分化的思想从token路由领域迁移到通道维度，为卷积网络中的逐点投影提供了高效的结构化稀疏方案。

## 二、方法论

### 2.1 核心思想
- MoCE将“专家”定义为**单个输出通道**，而非独立的参数化网络。
- 每个专家学习一个**静态稀疏支持集**（通过TopK选取的k个输入通道子集），推理时支持集预先固定，无数据依赖分支，可静态调度。
- 引入**输入自适应混合**：一个轻量门控根据输入预测每个专家的温度标量，控制softmax混合的“锐度”——温度低时接近max-like聚合，温度高时接近mean-like聚合。
- 增加**残差专家**汇总未被任何路由专家覆盖的通道，保证信息不丢失。
- 引入**负载均衡损失**鼓励通道被均匀覆盖。

### 2.2 关键技术细节
- **静态支持学习**：路由logits矩阵 L∈R^(E-1)×C 为每个专家分配通道偏好向量，支持集 S_e = TopK(L_e, k)。训练时通过任务损失对选中的logit值求导，覆盖损失对所有logit求导；离散索引本身不接收梯度，支持集在训练中随连续logits重排序而迁移。
- **输入自适应温度**：全局平均池化得到 z=GAP(X)∈R^(B×C)，一个共享的两层MLP门控 g:R^k→R 读取专家支持集上的k个描述符（按logit降序排列以保证共享位置语义），预测温度 τ_e(X) = τ_min + (τ_max - τ_min)·σ(g(z_{S_e}))。混合系数为 softmax(L_{e,i}/τ_e(X))，每个专家每个样本只有**一个标量**的自适应自由度。
- **残差专家**：U = {1,...,C} \ ∪_e S_e，输出 Y_res = |U|⁻¹∑_{i∈U}X_i（若U为空则输出0）。平均约7.7%的输入通道未被路由专家覆盖。
- **负载均衡损失**：定义 p_{e,c}=Softmax(L_e)_c，u_c=(E-1)⁻¹∑_e p_{e,c}，优化 L_cov = ∑_c(u_c - ū)²/(ū²+ε)，λ=5×10⁻⁴（ImageNet）或0.05（CIFAR-100）。
- **成本公式**：每层MACs约 M_MoCE = (E-1)kHW + CHW + |U|HW + M_g，相对密集投影的比值约 ≤ k/C + 2/E。盈亏平衡点 k* = C(E-2)/(E-1)，在s=4投影中k*≥252（C=256时），说明k=8远低于计算瓶颈，限制k的是表达能力而非算力。
- **部署存储**：训练时保留完整路由矩阵以便支持迁移；部署时仅保留(E-1)k个选定logit、整数索引和共享门控。ResNet-50部署参数量从25.56M降至21.26M（-16.8%）。

### 2.3 动态支持变体（用于消融）
论文还为实验设计了一个更强的动态变体：路由logits加入低秩输入偏移 L_e(X)_c = L_{e,c} + ⟨q_e⊙h(z), v_c⟩，支持集和混合权重都随输入变化，训练用straight-through Gumbel-softmax。该变体参数量增加0.96M，推理时路由-选择-聚合路径比静态版慢7.13倍。

## 六、主要结论与发现

1. **MoCE在多个场景匹配或超过密集基线**：ResNet-50 ImageNet Top-1从75.98%提升至76.71%（+0.73），MACs降低16.7%，部署参数降低16.8%；ResNet-152在20.8%更少MACs下+0.46点；CIFAR-100从零训练ResNet-50 +0.91点。
2. **输入依赖应作用于“如何混合”而非“读取哪些通道”**：动态支持变体仅+0.03点但路由-聚集路径慢7.13倍；移除温度门控则降低1.19点。这一不对称结果是全文的核心设计依据。
3. **通道投影存在大量冗余**：仅用8个通道的凸组合即可匹配密集投影（确定性循环支持78.27% vs 密集78.44%），学习支持后进一步超过密集投影。
4. **支持选择至关重要**：随机固定支持仅61.30%，说明支持集的质量对性能影响极大。
5. **负载均衡损失的贡献有限但必要**：独立均匀支持本身已能覆盖大部分通道，λ主要提供未选择logit的梯度以允许支持迁移。
6. **MACs节省大于时间节省**：4.6%的端到端加速远小于16.7%的MACs减少，原因是稀疏路径仍需读取全部输入激活张量，操作从算术受限转向带宽受限。减小激活流量比进一步减小k更具加速空间。
7. **MoCE方法适用性超出ResNet**：在EfficientViT上精度保持且MACs降低18–22%，证明其适用于token-wise线性投影。

## 七、优点

1. **动机诊断扎实**：用实验数据（核余弦相似度0.88）有力证明了“算子复制式”卷积MoE的根本缺陷，动机有据可依。
2. **设计简洁而精巧**：以输出通道为专家、静态稀疏支持+单标量温度自适应，概念清晰，实现轻量，无需数据依赖分支，推理可静态调度。
3. **成本分析透明**：给出完整的MACs公式、盈亏平衡点推导、存储对比，并诚实地解释MACs节省与时间节省之间的差距（带宽限制）。
4. **消融设计有说服力**：特别是“输入依赖用在何处更有价值”的对比设计——刻意让动态变体更强（全描述符、低秩偏移、两处自适应），结果仍无增益，反衬静态支持+温度混合是更优操作点；随机/循环/学习三种支持设计的对比也干净明了。
5. **评估覆盖面广**：多种骨架、数据集、训练方式和模型规模，并在多个指标（精度/MACs/参数/延迟）上给出完整视角。
6. **方法具有实际部署价值**：支持集静态化、索引打包、训练时保留完整矩阵以便迁移等工程细节体现了落地意识。
