## 摘要
使大型语言模型（LLM）针对不同能力进行专门化，支撑了从个性化助手到多智能体系统（MAS）的成功。单智能体范式依赖预定义角色或引导向量来诱发专门化，但这会带来单一固定的专门化，难以适应多样化的查询。相反，MAS通过编排具有不同文本角色的智能体实现动态的多视角问题求解，但融合这些专门化需要多轮交互，从而增加上下文长度和推理成本。为解决这些限制，我们提出了角色混合（MoRe），它能将多种专门化自适应地组合为单一的引导向量，用于单轮推理。具体而言，MoRe学习一个多样化的引导向量码本，每个向量编码一个潜在角色，并由查询感知路由器动态地将码本融合为包含多个角色的引导向量。通过用组合后的向量引导主干LLM，MoRe在单智能体、单轮推理过程中实现了多视角专门化。所提出的MoRe可通过三阶段SFT课程和GRPO后训练高效训练，且主干LLM保持冻结。在推理和个性基准上的实验表明，MoRe平均比单智能体基线高出2.2%，同时达到与MAS相当的性能，并将token成本降低20倍。

## Abstract
Specializing Large Language Models (LLMs) toward distinct abilities underpins successes ranging from personalized assistants to multi-agent systems (MAS). Single-agent paradigms rely on pre-defined personas or steering vectors to induce specialization, yet they impose a single fixed specialization that fails to adapt to diverse queries. Conversely, MAS achieves dynamic multi-perspective problem solving by orchestrating agents with distinct text-based roles, but fusing these specializations requires multi-turn interactions that inflate context length and inference cost. To address these limitations, we propose Mixture of Roles (MoRe), which adaptively composes multiple specializations into a single steering vector for single-turn inference. Specifically, MoRe learns a diversified codeboox of steering vectors, each of which encodes a latent role. A query-aware router dynamically fuses the codebook into a steering vector that encompasses multiple roles. By steering the backbone LLM with the composed vector, MoRe enables multi-perspective specialization in a single-agent, single-turn inference process. The proposed MoRe can be efficiently trained via a three-stage SFT curriculum and GRPO post-training, while the backbone LLM remains frozen. Experiments across reasoning and personality benchmarks show that MoRe outperforms single-agent baselines by 2.2% on average, and achieves performance on par with MAS while reducing token cost by 20x.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大型语言模型（LLM）在不同任务上具有通用能力，但通过专门化（specialization）可进一步激发特定行为、认知模式或专家角色。现有专门化路径主要有两条：
  - **单智能体范式**：通过文本角色扮演（role-playing）或激活引导（activation steering）施加单一固定专门化，如预定义人设或固定 steering vector。其优点是计算高效，但无法适应多样化查询，也缺乏多视角推理能力。
  - **多智能体系统（MAS）**：通过多个角色智能体多轮交互实现动态多视角协作，但需要多轮对话，导致上下文长度和推理成本大幅增加。
- **核心研究问题**：能否在**单个智能体、单轮推理**中实现**动态多视角专门化**，从而兼顾单智能体的效率与多智能体的适应性？
- **论文回答**：提出 **Mixture of Roles（MoRe）**——通过将多个“角色”以 latent steering vector 的形式编码到一个可学习码本中，并利用查询感知路由器动态融合为单一 steering vector，在冻结骨干 LLM 上实现单轮、多角色的协同推理。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 总体思路
- 将传统 MAS 中通过文本进行多智能体协作的方式，替换为**激活空间中的向量组合**。
- 学习一个包含 N 个候选 steering vector（码本）的集合，每个向量代表一个“潜在角色”。
- 对于每个输入查询，路由器动态选取并融合 Top-K 个候选向量，生成一个查询特定的组合 steering vector，注入骨干 LLM 的中间层。

### 2.2 关键模块
- **专门化码本（Specialization Codebook）**：
  - 码本 $\{e_n\}_{n=1}^N \subset \mathbb{R}^d$，每个 $e_n$ 是一个候选 steering direction。
  - 初始化：从对比激活（CAA，Contrastive Activation Addition）中提取 M 个方向作为前 M 个码本项，其余 N−M 项用这些方向的凸组合初始化，以锚定在行为上有意义的激活区域。
- **查询感知路由器（Query-aware Router）**：
  - 每个候选角色关联一个可学习 probe 向量 $u_n$，构成矩阵 $U \in \mathbb{R}^{N\times d}$。
  - 使用**多头交叉注意力**：以 U 为 Query，以输入查询的 token 嵌入 X 为 Key/Value，得到角色感知表示 Z，再经 MLP 得到路由 logits $g$。
  - 采用 **Top-K 稀疏路由**：只保留 logits 最大的 K 个专家，计算 softmax 权重并加权求和得到组合向量 $v_Q = \sum_{n\in \mathcal{T}_K} w_n e_n$，未选中专家的权重严格为 0。
- **Steering 操作**：
  - 在中间层（$\ell^* = \lfloor L/2\rfloor$）对查询的**最后一个 token** 应用：  
    $\tilde{h}_t^{(\ell^*)} = h_t^{(\ell^*)} + \alpha \frac{\|h_t^{(\ell^*)}\|_2}{\|v_Q\|_2} v_Q$。
  - 该设计通过单个 token 位置的局部干预传播影响整个后续生成过程。

### 2.3 训练流程（骨干 LLM 完全冻结）
- **三阶段 SFT 课程**：
  1. **阶段 1（只优化码本）**：每个查询均匀采样一个候选向量，优化 next-token prediction 损失，确保每个候选单独有效。
  2. **阶段 2（冻结码本，训练路由器）**：学习 Top-K 组合；加入负载均衡损失防止路由器坍塌到少数专家。
  3. **阶段 3（联合优化）**：码本和路由器同时微调，使候选向量适应查询相关的组合。
- **GRPO 后训练**：
  - 将冻结 LLM 视为黑盒环境，策略动作空间从 token 空间转移到**角色子集空间**（所有大小为 K 的无序子集）。
  - 路由器通过随机无放回采样 Top-K 角色（基于 softmax 概率）生成组合向量；策略概率为式 (5) 的边际概率（对排列求和）。
  - 对每组查询采样 G 个 steering 向量，用可验证任务奖励评分，计算组内优势，更新路由器。
  - 该设计实现精确的 credit assignment，且 rollout 不涉及 LLM 梯度，内存和计算开销小。

## 6. 主要结论与发现

- 专门的“角色”确实能提升 LLM 的推理能力，但**没有单一角色是普遍最优**的，不同任务需要不同专业化方向。
- **MoRe 优于所有单智能体基线**：平均准确率提升约 2.2%，且优势在长推理链任务上更明显。
- **MoRe 与 MAS 性能相当或更优**，但 token 消耗约为 MAS 的 1/20，实现了效率与性能的良好平衡。
- 在人格控制任务上，MoRe 在两种骨干模型上均达到最佳平均分和排名，且方差更小、跨模型鲁棒性更强。
- 分析表明：码本学到多样化的 steering 方向，路由器学会按数据集/查询需求动态组合相关角色（如数学任务更依赖数学家角色，MedQA 更依赖教师/怀疑者/医生角色组合）。

## 7. 优点

- **概念创新**：将多智能体的文本协作转化为激活空间中的向量组合，在单智能体、单轮推理中实现多视角专门化，思路新颖。
- **高效轻量**：骨干冻结，仅训练约 1.36M 参数；推理只额外增加一个轻量路由器的前向计算，token 开销与单智能体方法相当。
- **训练策略精巧**：三阶段 SFT 课程逐步预热码本和路由器，避免联合优化初期不稳定；GRPO 将策略定义在角色子集空间，credit assignment 清晰且 rollout 不依赖 LLM 梯度，训练效率高。
- **实验较全面**：覆盖推理、人格、消融、超参数、可视化和效率对比，证据链较完整，尤其对码本多样性和路由行为的分析很有启发性。

## 8. 不足与局限

- **需要内部隐藏状态**：MoRe 依赖对骨干 LLM 内部激活的访问，不能直接用于黑盒 API 模型（如闭源商业模型）。
- **可解释性有限**：学习到的 candidate vectors 是潜在表示，不像文本角色那样可解释；虽然初始化自文本角色，但训练后含义难以理解。
- **查询级固定人设**：组合向量在整段生成中保持不变；更细粒度的 token 级或推理步骤级路由可能带来额外自适应，但会增加计算开销。
- **实验范围限制**：仅使用 8B 量级开源模型，未验证更大模型或不同架构；人格评估依赖 LLM-as-judge，可能继承评判模型的偏见。
- **角色集与路由机制**：预设 7 个角色，未解决角色数量的自动选择、未知角色的发现以及路由器在分布外查询上的泛化问题。
- **与 MAS 的对比条件**：MAS 方法通常未进行充分的 token 预算校准，效率优势虽明显，但“性能对等”的结论依赖于特定评测协议。
