## 摘要
参数高效微调（PEFT）使得大型语言模型的高效适配成为可能，但现有的基于MoE的PEFT方法通常通过存储多个完整的LoRA专家来提升能力，导致适配器存储量随专家数量线性增长，并将适配限制在固定的专家池中。我们探究基于MoE的PEFT能否在不显式为每个专家存储独立LoRA模块的情况下，生成实例特定的适配。为填补这一空白，我们提出MoEGen，一种将基于MoE的PEFT从专家选择转向专家条件参数生成的适配框架。MoEGen不将每个专家存储为完整的LoRA适配器，而是将每个专家表示为一个小型可学习向量，称为专家代码。它通过这些向量路由每个输入，并利用其加权组合来条件化一个轻量级超网络，该超网络生成输入特定的低秩更新。这一设计将专家能力与适配器存储解耦，同时实现实例条件的适配。在八个常识推理基准上的实验表明，在三个主干网络上，该方法相较于强静态和基于MoE的PEFT基线均取得了一致的提升。MoEGen在医学和法律领域的联合适配中也表现出色。

## Abstract
Parameter-efficient fine-tuning (PEFT) enables efficient adaptation of large language models, but existing MoE-based PEFT methods typically improve capacity by storing multiple full LoRA experts, causing adapter storage to grow linearly with the number of experts and restricting adaptation to a fixed expert pool. We ask whether MoE-based PEFT can produce instance-specific adaptations without explicitly storing a separate LoRA module for each expert. To address this gap, we propose MoEGen, an adaptation framework that shifts MoE-based PEFT from expert selection to expert-conditioned parameter generation. Instead of storing each expert as a full LoRA adapter, MoEGen represents each expert as a small learnable vector, termed an expert code. It routes each input over these vectors and uses their weighted combination to condition a lightweight hypernetwork that generates input-specific low-rank updates. This design decouples expert capacity from adapter storage while enabling instance-conditioned adaptation. Experiments on eight commonsense reasoning benchmarks show consistent improvements over strong static and MoE-based PEFT baselines across three backbones. MoEGen also performs strongly in joint medical and legal-domain adaptation.

  - 适配器存储量随专家数量线性增长；

## 2. 论文提出的方法论

**核心思想**:MoEGen 将每个专家表示为一个小型可学习向量（专家代码，expert code），路由模块将输入映射到若干专家代码的加权组合，然后由一个共享的轻量超网络根据该组合动态生成输入特定的 LoRA 低秩矩阵。整个流程将“专家参数”从“存储的实体”变为“生成的结果”。

**关键技术细节：**

- **总体架构**：MoEGen 由四个模块组成：
  1. 冻结的预训练 LLM；
  2. 冻结的提示编码器（默认使用 Qwen3-Embedding-0.6B 句向量模型，用于提取输入语义 embedding）；
  3. 稀疏 MoE 路由器（负责对专家代码做 top-k 选择与加权）；
  4. 共享的 LoRA 超网络（负责从专家代码混合信号中逐行生成输入特定的 LoRA A 矩阵）。
- **专家代码（Expert Codes）**：共享的 N 个可学习向量 {E1, . . . , EN}，每个 Ei ∈ R^dh。这些向量不是完整的 LoRA 适配器，而是“风格化”的低维条件向量——只编码一种适应模式，不直接存储适配矩阵。
- **组件语义路由**：
  - 输入的语义 embedding z = f_enc(x) 与每个被适配组件（如每层注意力中的 Q/K/V/O 投影）的可学习组件嵌入 ℓ^{(l)} 拼接；
  - 经共享投影 Wr 得到组件特定路由特征 h^{(l)} = Wr[z; ℓ^{(l)}]；
  - 特征经 LayerNorm + GELU 后，通过一门控投影 Wg 得到专家 logits，再执行 top-k 选择与归一化，得到稀疏路由权重 w^{(l)}_i。
- **超网络生成 LoRA 参数**：
  - 每个被适配组件有一个可学习的坐标嵌入矩阵 P^{(l)} ∈ R^{d_in × d_h}，其第 j 行 p^{(l)}_j 表示输入第 j 维的“位置”；
  - 超网络将 [p^{(l)}_j; E_i] 线性投影到 R^r，生成 LoRA A 矩阵的第 j 行；
  - 对选中的 k 个专家分别生成候选 A_i^{(l)}，再按路由权重加权混合得到 A^{(l)} = Σ w_i A_i^{(l)}；
  - 与可训练的静态 B^{(l)} 矩阵相乘，构成最终动态低秩更新 ΔW^{(l)} = B^{(l)} (A^{(l)})^⊤。
- **不对称设计**：生成端（A 矩阵）是输入条件化的动态参数，而输出端（B 矩阵）是跨输入共享的静态参数——既保留实例适应性，又控制生成成本。
- **参数成本分析**：标准 MoE-LoRA 中每个专家需要 r·(d_in + d_out) 参数/组件，总成本随 N 线性增长；MoEGen 中专家池总成本仅 N·d_h，组件特定成本（P^{(l)} 和 B^{(l)}）与 N 无关。在 d_h ≪ r·d_in 的条件下，扩充专家池几乎零边际成本。
- **损失函数**：语言建模损失 + 负载均衡正则化（负载均衡损失定义见原文式 11），以鼓励专家均衡使用、防止路由崩溃。

## 6. 主要结论与发现

- **一致提升**：MoEGen 在三个骨干网络的常识推理平均得分分别达 84.2（LLaMA-2-7B）、87.9（LLaMA-3-8B）、89.9（Qwen3-8B-Base），分别比最强静态 PEFT 基线高 2.4、1.1、0.8 分；比最强 MoE 基线（MoELoRA）高 0.6、1.2、1.9 分。
- **超越全参数微调**：在 LLaMA-2-7B 上，仅用 0.52% 参数量的 MoEGen（84.2）甚至超过 Full Fine-tuning（82.2），说明输入条件化的低秩更新优于全局参数更新在常识推理上的表现。
- **跨域联合训练是主要收益场景**：在医学+法律的混合任务上，MoEGen 在三个骨干上的平均分分别达 61.5%（LLaMA-3-8B）、60.4%（Qwen3-8B-Base）、58.8%（LLaMA-2-13B），平均领先最强基线约 4.6 - 6.2 分。尤其 BillSum 的 ROUGE-L 较基线提升巨大（如 LLaMA-2-13B 从 18.8% 提升至 38.6%），说明静态 LoRA 在异构任务冲突下的瓶颈不在容量而在“有条件”的适配方式。
- **路由与专家数量的影响**：N=8 最优；top-2 优于 top-1，但添加共享专家反而会削弱专家专用化；句向量编码器提供的语义信号比骨干自身表征更干净。
- **定性结论**：路由在低维空间能自发形成任务相关簇；在法案摘要任务中，MoEGen 能抓住法案主题与核心条款，而基线方法则表现为重复套话或复制原文片段。

## 7. 优点

**方法层面的亮点：**

- **存储与容量解耦**：用低维专家代码替代完整 LoRA 专家，专家数量扩充几乎不增加存储，设计优雅、创新性强。
- **真正的实例级适配**：每个输入都能获得语义特定的低秩矩阵，而不仅是固定参数或专家组合的离散选择，表达能力更强。
- **架构轻量**：超网络参数复杂度为 O(d_h · r)，与被适配组件维度（d_in × d_out）解耦，天然适用于深层、宽模型的部署。
- **训练稳定性设计**：B 矩阵零初始化保证了训练初期与 LoRA 等价，负载均衡正则化防止路由崩溃。

- 消融实验覆盖了专家数量、路由策略、语义来源三个关键设计维度，并给出计算成本表。
