## 摘要
强化学习（RL）已成为大语言模型后训练的核心。近期面向混合专家（MoE）模型的强化学习进展，主要聚焦于提升优化稳定性和训练效率，同时将专家选择视为固定组件。由于路由决定了诱导输出分布的稀疏计算路径，专家选择为 rollout 多样性提供了额外来源。通过实证分析，我们发现扰动专家路由能有效改变模型输出并增加 rollout 多样性，这类似于提高解码温度。然而，直接扰动可能激活不合适的专家，并显著降低 rollout 质量。受这些观察启发，我们提出专家空间探索强化学习（ESRL），这是一个架构感知框架，显式探索 MoE 模型的专家路由空间。ESRL 将高置信度专家保留为锚点，并将随机路由限制在合理的候选池中，从而保留可靠的计算路径。扰动强度进一步根据路由器熵进行自适应调整，以避免过度扰动。为缓解扰动引入的路由不匹配，ESRL 记录 rollout 期间使用的专家路径，并在策略优化期间重放这些路径。实验表明，ESRL 在采用 top-K、top-1 和共享专家路由的 MoE 骨干模型上，以及在数学、科学和代码任务上，均在不增加额外采样或计算成本的情况下取得了最佳性能。具体而言，在 Qwen3-30B-A3B 上，ESRL 在所有对比方法中表现最佳，相比 GRPO 将平均 Pass@1 和 Pass@8 分别提升了 3.2 和 4.5 个百分点。对专家利用率和训练动力学的进一步分析，为利用 MoE 特有路由结构如何有益于 RL 训练提供了洞见。

## Abstract
Reinforcement learning (RL) has become central to post-training of large language models. Recent advances in RL for Mixture-of-Experts (MoE) models have primarily focused on improving optimization stability and training efficiency, while treating the expert selection as a fixed component. Since routing determines the sparse computation paths that induce output distributions, expert selection offers an additional source of rollout diversity. Through empirical analysis, we find that perturbing expert routing effectively alters model output and increases rollout diversity, which is similar to increasing the decoding temperature. However, direct perturbation can activate unsuitable experts and substantially degrade rollout quality. Motivated by these observations, we introduce Expert-Space Exploration Reinforcement Learning (ESRL), an architecture-aware framework that explicitly explores the expert-routing space of MoE models. ESRL preserves high-confidence experts as anchors, and restricts stochastic routing to a plausible candidate pool, thereby retaining reliable computation paths. The perturbation strength is further adapted according to router entropy to avoid over-perturbation. To mitigate the routing mismatch introduced by perturbation, ESRL records the expert paths used during rollout and replays them during policy optimization. Experiments demonstrate that ESRL achieves the best performance across MoE backbones with top-K, top-1, and shared-expert routing, as well as across mathematics, science, and code tasks without additional sampling or computational cost. Specifically, ESRL on Qwen3-30B-A3B achieves the best among all compared methods, improving average Pass@1 and Pass@8 over GRPO by 3.2 and 4.5 percentage points, respectively. Further analyses of expert utilization and training dynamics provide insights into how exploiting MoE-specific routing structure benefits RL training.

- **现有工作的盲区**：当前面向 MoE 的 RL 研究主要聚焦于**优化稳定性与训练效率**（如序列级重要性比率、路由重放、负载均衡辅助损失），而将**专家选择（routing）视为固定的架构组件**。然而，每个 token 被动态路由到稀疏专家集合，这些专家共同决定下一个 token 的分布——也就是说，路由实际上定义了「计算路径空间」。
- **核心矛盾**：标准 MoE rollout 依赖确定性的 Top-K 路由，对同一前缀总是激活同一组专家，使得同一上下文下的**替代计算路径未被探索**。虽然 token 采样能间接改变后续路由，但并未显式探索专家路径。这对 GRPO 这类**组相对**方法尤其不利：当组内轨迹奖励几乎相同，归一化优势趋近于零，学习信号被削弱。
- **关键实证发现**：
  - 扰动路由噪声会改变专家分配、拓宽专家利用率（专家负载变异系数 CV 下降），并显著重塑同上下文下的下一 token 分布（top-1 token 排名下降、Top-20 集合 Jaccard 下降、PCA 投影出现质心位移与扩散）。
  - 路由扰动具有「类温度」效应：增大噪声会降低 Self-BLEU（提升序列多样性），且 RL 训练越往后，维持同样多样性所需的温度越高（策略逐渐集中）。
  - 但**无约束的扰动会激活不匹配的专家**，在同等 Self-BLEU 下准确率明显低于纯温度采样，即存在质量–多样性权衡。
- **核心问题**：路由级扰动能否为 MoE LLM 的强化学习提供一种**架构感知的、超越 token 级采样的探索机制**？
- **整体含义**：论文将「专家路由」从架构角色重新定位为 RL 的**探索维度**，提出 ESRL 框架，在不修改奖励函数与策略优化目标的前提下，于 rollout 阶段显式探索专家空间。

## 2. 方法论（ESRL）

### 2.1 核心思想
在生成（rollout）阶段对路由器 logits 注入噪声，使同一前缀可激活替代专家路径，从而产生不同的下一 token 分布与轨迹；但通过**锚定高置信专家**与**限制在合理候选池**来保住可靠计算路径，通过**熵自适应**控制扰动强度，并通过**路由重放**保证 rollout 与训练的路由一致性。

### 2.2 三个关键组件

**(a) 自适应噪声强度（Entropy-Adaptive Noise）**
- 先对第 ℓ 层、第 t 个 token 的路由 logits 做 softmax 得到分布 p，再计算归一化路由熵 H ∈ [0,1]。
- 噪声尺度：**σ = σ_min + (σ_max − σ_min)(1 − H)**。
- 直觉：路由分布越尖锐（越自信），越需要更大扰动才能改变专家选择；分布本已弥散时则减小扰动，避免不必要地破坏专家选择。

**(b) 锚定专家采样（Anchored Expert Sampling）**
- 将 K 个激活专家拆分为 **K_anchored 个锚定专家** 与 **K_explore 个探索专家**（K_anchored + K_explore = K）。
- 锚定集合直接由原始 logits 的 Top-K 选出，保留高置信计算路径。
- 从剩余专家中取 logits 最高的 M_explore 个构成**探索候选池**，仅对该池内专家加高斯噪声（默认），再按扰动后 logits 取 Top-K_explore 作为探索专家。
- 最终激活集合为锚定集合与探索集合的并集。
- **关键细节**：扰动 logits **只用于决定激活哪些专家**；一旦专家索引确定，**聚合权重仍由原始 logits 计算**（保证相对置信度不变）。这样既改变了离散计算路径，又保持路由的原始置信结构。
- 对 top-1 路由模型设 K_anchored = 0（只有一个槽位，锚定失效），仅保留候选池约束；共享专家始终激活，不参与扰动。

**(c) 路由重放（Rollout Routing Replay, R3）**
- 问题：若训练时重新计算确定性 Top-K，同一 token 的专家集合可能与 rollout 不同，导致探索到的专家拿不到梯度，并造成 rollout 策略 π_roll 与当前策略 π_θ 的不匹配。
- 方案：rollout 时记录每条轨迹在每个 token、每个 MoE 层的激活专家集合 Z_i，并保存 rollout log 概率；优化时**绕过 Top-K**，固定使用记录的路由集合，仅用当前 router logits 重算门控权重与 MoE 输出。
- 这样探索到的专家在训练中被重新激活并获得梯度，同时降低重要性采样比率的方差。

### 2.3 优化目标
- 采用 GRPO：token 级策略比率 ρ 以「重放路由下的当前策略 π^Z_θ」除以「rollout 策略 π_roll」计算，优势 Â_i 为组相对归一化奖励，配合 PPO 式裁剪（δ 上下限 0.20/0.28）。
- ESRL **不修改奖励函数，也不修改策略优化损失**，只作用于 rollout 阶段，因此与优化层、奖励层的改进正交，可叠加。

### 2.4 算法流程（文字版）
对每个 token 的每一 MoE 层：① Top-K 选出锚定专家；② 从剩余专家中取 Top-M_explore 构成候选池；③ 由 softmax 计算归一化熵 H 并得到 σ；④ 对候选池内 logits 加噪声；⑤ 在池内取 Top-K_explore 得探索专家；⑥ 合并得最终路由集合；⑦ 用**原始 logits**计算门控权重；⑧ 存储该路由集合供重放。

  - **需注意的偏差风险**：Aux-Loss 与 N-Sampling 出现训练崩溃（表中标 †，取最佳 checkpoint），说明这两个基线未充分调优，可能低估其真实能力，使对比略显不利；主实验训练集仅用 MATH 单一数据集，科学/代码仅在 Qwen3-30B-A3B 上验证，域覆盖不均衡；部分指标提升幅度极小（如 MinervaMath Pass@1 仅 +0.1，Sigma 的 OlympiadBench Pass@8 为 **−1.5**，属负增益），说明并非所有设置都稳定获益。

## 6. 主要结论与发现

1. **路由扰动是一种有效的探索机制**：它能改变专家分配、拓宽专家利用、重塑下一 token 分布，并在序列层面产生类似温度的多样性增益。
2. **无约束扰动不可取**：直接加噪声容易激活不匹配专家，在同等多样性下准确率更低；必须「锚定 + 候选池 + 熵自适应」三重约束。
3. **性能全面提升**：
   - Qwen3-30B-A3B：平均 Pass@1 42.1、Pass@8 64.2，较 GRPO 提升 **+3.2 / +4.5 个百分点**，并超过更强的 GSPO 与 RO-GRPO；
   - Sigma：平均 Pass@8 较 GRPO +2.7；Moonlight：+3.5；
   - 科学/代码任务：平均 Pass@1 53.2 → 55.9，Pass@8 64.9 → **77.0**（+12.2），GPQA Pass@8 单项提升 **+23.3**；
   - Instruct 模型：平均 Pass@1 63.4 → 68.9（+5.5），说明在强起点上仍有增益。
4. **采样效率提升**：ESRL 用 64 样本已超过 GRPO-R3 用 128 样本，用 128 样本超过 GRPO-R3 用 256 样本；且在整个训练过程中维持更高的「信息组比例」（组内同时含正确与错误响应的比例），在后期基线奖励对比消失时优势尤为明显。
