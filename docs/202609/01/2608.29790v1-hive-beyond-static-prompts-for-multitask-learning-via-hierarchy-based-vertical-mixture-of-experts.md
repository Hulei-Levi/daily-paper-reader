## 摘要
随着大型语言模型（LLM）规模不断扩展，参数高效微调（PEFT）已成为全参数适应的实用替代方案。提示调优是有效的，但现有方法要么使用平面提示结构，要么使用具有固定提示组合的层次结构，限制了自适应提示的专业化。为解决这一限制，我们提出HiVe，一个提示调优框架，它在多个层次上建模提示，并实现输入相关的专业化。HiVe通过利用训练期间的任务间关系来构建提示层次，并在推理时采用垂直专家混合（V-MoE）机制，将提示组合到每个输入所需的专业化级别。实验表明，HiVe在多样化任务上始终优于强提示调优基线。

## Abstract
As large language models (LLMs) continue to scale, parameter-efficient fine-tuning (PEFT) has become a practical alternative to full-parameter adaptation. Prompt tuning is effective, but existing approaches either use flat prompt structures or hierarchical structures with fixed prompt composition, limiting adaptive prompt specialization. To address this limitation, we propose HiVe, a prompt tuning framework that models prompts at multiple levels and enables input-dependent specialization. HiVe constructs a prompt hierarchy by leveraging inter-task relationships during training, and employs a vertical mixture-of-experts (V-MoE) mechanism at inference time to compose prompts up to the level of specialization required for each input. Experiments show that HiVe consistently outperforms strong prompt tuning baselines across diverse tasks.

## 1. 核心问题与研究动机

- **背景**：随着大语言模型（LLM）规模不断增大，全参数微调成本高昂，参数高效微调（PEFT）成为主流实践。其中，提示调优（Prompt Tuning, PT）通过仅学习少量软提示（soft prompts）、冻结骨干模型，在保持性能的同时大幅降低可训练参数。
- **现有方法的不足**：
  - 传统 PT 使用单一共享提示，难以适应多任务、多领域下的数据分布差异。
  - 基于混合专家（MoE）的提示调优方法（如 SMoP、PT-MoE）虽然实现输入相关的提示选择，但采用**扁平提示空间**，将所有提示视为同一抽象层次，无法处理不同输入对“专业化程度”的差异化需求（图 1）。
  - 已有的层次化提示方法（如 HPT、MPrompt、HiPro）虽然引入了多级结构，但通常使用**固定的任务相关路径或固定提示组合**，不能根据单个输入动态选择层次深度。
- **核心挑战**：
  1. 在训练阶段自动利用任务间关系构建提示层次；
  2. 在推理阶段基于输入特征动态利用这些解耦的提示层次。
- **HiVe 的目标**：通过“层次化垂直专家混合”（V-MoE）实现输入自适应的提示专业化，兼顾共享知识利用与任务特定知识提取。

## 2. 方法论

### 2.1 总体框架
HiVe 构建 **Base（基础）→ Group（组）→ Task（任务）** 三层次提示结构，并采用“残差提示分解”分离共享与特定表示；推理时通过基于键（key）的 V-MoE 路由机制，动态决定每个输入在层次中应下探的深度。

### 2.2 残差提示分解（Residual Prompt Decomposition）
- **Base-Task 分解**：
  - 初始任务提示 \(P_T^{(\tau)}\) 可视为共享表示 \(P_{sh}\) 与任务特定表示 \(P_{sp}^{(\tau)}\) 的和。
  - 用所有任务提示的全局均值估计 \(P_{sh}\)，将其从任务提示中剥离并转移至基础提示：
    \[
    P_T^{(\tau)} \leftarrow P_T^{(\tau)} - P_{sh},\quad P_B \leftarrow P_B + P_{sh}
    \]
- **Group-Task 分解**（进入 Phase 2 后）：
  - 对每个任务组，取组内任务提示的均值作为该组共享表示，转移到组提示：
    \[
    P_T^{(\tau)} \leftarrow P_T^{(\tau)} - P_{sh}^{(c(\tau))},\quad P_G^{(g)} \leftarrow P_{sh}^{(g)}
    \]
- 作用：降低层内与层间冗余，避免信息过多集中于低层，使高层保留通用能力、低层保留任务专属信息。

### 2.3 稳定性驱动的层次构建（Stability-driven Hierarchy Construction）
- **Phase 1**：训练基础提示和任务提示，形成两层次结构：
  \[
  \tilde{P}_{\text{phase1}} = (P_B + P_T^{(t)})W
  \]
- 任务分组使用**层次凝聚聚类（HAC）**：基于任务提示均值向量的余弦不相似度矩阵。
- 为避免过早或过晚分组，采用 **ARI（Adjusted Rand Index）稳定性检查**：每 \(N\) 步计算一次聚类，并将其与前 \(K\) 次结果比较，若平均 ARI 连续 \(R\) 次超过阈值 \(\eta\)，则最终确定分组并进入 Phase 2。

### 2.4 垂直专家混合（V-MoE）路由
- **路由键设计**：任务键 \(k_T^{(\tau)}\) 显式优化，基础键与组键由其质心推导：
  \[
  k_B = \frac{1}{n}\sum_{\tau} k_T^{(\tau)},\quad k_G^{(g)} = \frac{1}{|T_g|}\sum_{\tau \in T_g} k_T^{(\tau)}
  \]
- **键训练**：输入经投影得到查询 \(q\)，与各级键计算余弦相似度，通过两层交叉熵损失（任务级和组级）优化，使查询靠近所属任务键、远离他人。
- **推理路由**：选择与查询相似度最高的键，决定层次深度：
  - 仅 Base：\(P_B\)
  - Base + Group：\(P_B + P_G^{(g^*)}\)
  - Base + Group + Task：\(P_B + P_G^{(c(\tau^*))} + P_T^{(\tau^*)}\)
- 与扁平 MoE 不同，V-MoE 不是从同层并行专家中选择，而是决定“下探多少层”，渐进组合路径上的提示，从而自适应调节专业化粒度。

1. **域内性能**：HiVe 在 MRQA 平均 F1 达 75.4，与全参数 FT（75.2）持平但仅更新约 0.007% 参数；在摘要任务上 ROUGE-L 平均 26.1，同样优于 FT（26.0）。明显超过 SMoP、PT-MoE 等扁平 MoE 方法。

3. **层次结构与 V-MoE 的有效性**：消融表明，去掉任一层次或使用固定单一键均导致性能下降，验证了动态选择专业化深度的重要性。

5. **路由偏好因任务而异**：不同任务在 Base/Group/Task 键上的选择分布不同，固定层次不可取。

## 7. 优点

1. **方法创新性**：首次将垂直 MoE 思想引入提示调优，将“选择哪个专家”转化为“选择多深的层次”，更贴合输入对专业化程度的需求。
2. **层次构建自动化**：通过 ARI 稳定性准则自适应确定分组时机，避免人工预设任务关系。
3. **残差分解降低干扰**：有效分离共享与特定知识，缓解多任务负迁移。
4. **参数高效**：以约 87K 可训练参数获得与全参数微调相当甚至更优的域外性能。
5. **泛化鲁棒性**：在 12 个 QA 和 11 个摘要数据集上均取得领先，域外表现尤为突出。
6. **实验规范**：多种子平均、统一模板、公平参数预算、详尽的消融与敏感性分析，提升了结论的可信度。

## 8. 不足与局限

1. **分组敏感性**：任务分组依赖随机种子、提示长度、低秩维度及分组超参数，某些配置可能过早固定分组，导致结构偏差和性能下降。
2. **评估范围限制**：仅评估了“任务目标不变、输入分布变化”的域内分布偏移；对于跨任务类型的泛化（如从 QA 到摘要）未做探究。
3. **不可见模式局限**：V-MoE 只能从已学习的层次中选择路径，无法处理超出该层次覆盖范围的显著分布偏移。
4. **路由决策可解释性有限**：当前是硬路由（选一个键），未来可探索 top-k 或软路由以增加灵活性。
5. **算力细节缺失**：未报告训练总 GPU 时长、能耗或推理延迟详细对比数据（仅给出相对 FLOPs 和单次延迟），复现成本评估不够透明。
