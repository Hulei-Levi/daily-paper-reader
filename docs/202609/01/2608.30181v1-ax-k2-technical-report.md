## 摘要
我们推出了 A.X K2，一个从零训练的 6880 亿参数混合专家（MoE）语言模型，作为高性能的智能体（agentic）应用基础。该模型在约 8.5 万亿 token 上训练——少于其前代 A.X K1——采用了规模更小但质量更高的数据混合，并大幅扩充了智能体与软件工程数据，然而它在各项性能上全面超越 A.X K1，在某些基准上提升超过 30 个百分点，反映出 token 效率的巨大提升。为了高效支持长上下文，我们引入了稀疏门控注意力（Sparse Gated Attention, SGA），将稀疏注意力与门控注意力相结合，并采用门控归一化（Gated Norm, GN）来稳定大规模训练。SGA 通过一种稀疏索引器预热（sparse indexer warmup）在 128K 上下文长度下进行原生训练，该预热针对索引器自身的稀疏 top-k 选择而非稠密注意力分布进行优化，使得适应成本显著降低：每个查询仅读取 2,048 个位置，但长上下文质量保持不变，A.X K2 在 RULER 上最长 256K 的评测中得分为 94.6。GN 的异常值抑制又能使 4 位 NVFP4 推理精度保持在 FP8 精度的 1 个点以内。一种简单而有效的 Think-Fusion 技术进一步使用户可以在单一统一模型中切换思考与非思考模式。广泛评估表明，A.X K2 与强大的开源权重基线模型相比具有竞争力，在数学和韩语基准上达到或超越它们。

## Abstract
We introduce A.X K2, a 688B-parameter Mixture-of-Experts (MoE) language model trained from scratch as a high-performance foundation for \emph{agentic} applications. Trained on approximately 8.5T tokens---fewer than its predecessor, A.X K1---on a smaller but higher-quality mixture with substantially expanded agentic and software-engineering data, it nonetheless improves over A.X K1 across the board, by over 30 percentage points on some benchmarks, reflecting large gains in token efficiency. To support long contexts efficiently, we introduce Sparse Gated Attention (SGA), which combines sparse attention with gated attention, and adopt Gated Norm (GN) to stabilize large-scale training. SGA is trained natively at 128K through a \emph{sparse} indexer warmup that optimizes the indexer against its own sparse top-$k$ selection rather than the dense attention distribution, making adaptation markedly cheaper: each query reads only 2,048 positions, yet long-context quality is unchanged and A.X K2 scores 94.6 on RULER out to 256K. The outlier suppression of GN in turn keeps 4-bit NVFP4 serving within one point of FP8 accuracy. A simple yet effective Think-Fusion recipe further lets users switch between thinking and non-thinking modes within a single unified model. Extensive evaluations show that A.X K2 performs competitively against strong open-weight baselines, matching or exceeding them on math and Korean-language benchmarks.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **核心问题**：大语言模型的前沿竞争力正日益由"智能体能力"（多步推理、工具使用、长时程任务执行）定义，但仅靠扩大模型规模无法解决实际部署中的关键挑战——如何在固定算力和时间预算下，训练出一个兼具广泛知识、强推理能力、高效推理服务、可控推理时计算量，且可训练性良好的基础模型。
- **背景**：A.X K2 是 SK Telecom 推出的 688B 总参数量（33B 激活参数）MoE 语言模型，为 A.X K1 的继任者，也是韩国"主权 AI 基础模型"国家项目的一部分。其目标是在减少训练 token 的情况下，通过更高质量的数据和架构创新实现全面性能超越，同时服务于韩语与韩国文化场景。
- **整体意义**：论文证明了一个关键反直觉结论——**更大的模型（688B  vs. 519B）可以同时更快、更便宜地部署**（通过 SGA 稀疏注意力、NVFP4 量化、EAGLE3 投机解码的组合），从而消解了模型规模与服务经济性之间的传统权衡。

## 二、方法论：核心思想与关键技术细节

### 1. 架构设计（Gated Transformer Blocks）

- **MLA（多头潜在注意力）**：沿用 DeepSeek-V3 的 KV 缓存压缩方案，降低长上下文内存开销。
- **SGA（稀疏门控注意力）** = 门控注意力 + 稀疏注意力：
  - 轻量级索引器（indexer）为每个 query 选出 top-k（k=2048）个位置进行注意力计算，固定预算使相对成本随上下文增长而下降（128K 时仅读 1.6% 位置，256K 时 0.8%）。
  - 头级输出门（head-specific output gate）：G = σ(W_g · q_latent)，引入非线性、抑制注意力汇聚（attention sinks），并为索引器提供更高质量的注意力分布信号。
- **GN（门控归一化）**：在 RMSNorm 后施加门控操作，抑制隐藏状态中的"巨量激活"（massive activations）异常值，稳定训练并改善低精度（FP8/NVFP4）量化的鲁棒性。GN 取代了 A.X K1 的双归一化方案。
- **MoE 配置**：61 层中首层为稠密 FFN，其余 60 层为 MoE 层；256 个路由专家（8 组，组内 top-4，共激活 8 个专家）+ 1 个共享专家；sigmoid 预 softmax 路由器，top-k 缩放因子 2.5。

### 2. 预训练方案

- **数据管线**：继承 K1 的多阶段处理管线（韩语文档解析、双路合成数据、三阶段质量过滤/去重/课程学习），但**全部刷新**：英文采用 Nemotron-CC v2.1，韩语爬虫语料更新，增加 FineWeb2 多语言覆盖，大幅扩充智能体轨迹与仓库级代码数据。
- **阶段式课程**：WSD 学习率调度下的三阶段预训练：
  - Stage 1（通用知识）：6.4T tokens，4K 上下文；
  - Stage 2（高质量推理）：1.4T tokens，4K 上下文，按难度递进；
  - Stage 3（长上下文扩展）：3A 阶段 32K（~0.22T tokens）→ 3B 阶段 128K + 3C 阶段 SGA 适配（合计 ~0.14T tokens）。
- **长上下文扩展**：采用 ABF（Adjusted Base Frequency）原生扩展而非后验插值——RoPE base 从 10⁴ 在 32K 阶段开始时提升至 10⁶，原生训练 128K 上下文；推理时通过 YaRN 缩放因子扩展到 256K。
- **SGA 稀疏预热（Sparse Warmup）**：与 DeepSeek-V3.2/GLM-5 先对稠密注意力分布做预热不同，索引器直接从自身稀疏 top-k 选择上优化 KL 散度损失，显著降低适配成本且质量近乎无损。
- **检查点合并**：对最后 6 个检查点（间隔约 1.6B tokens）做 WSM 风格的 SWA 加权平均（1−√· 权重方案）。

### 3. 后训练方案

- **Think-Fusion SFT**：构建"成对"数据集（同一 prompt 配思考 + 非思考两个回答），在单一轨道中训练，通过显式控制 token（`<think>...</think>`）实现模式切换，避免双轨训练的模式混淆问题。思考与非思考 token 比约 13:1。
- **两阶段 SFT**：先进行索引器 SFT（0.4M 样本，同时训练模型与索引器参数以学习控制 token），再固定索引器做主 SFT（约 900 万样本，128K 打包序列，FFD 装箱算法）。
- **多阶段 RL**：统一优化指令遵循、人类偏好、智能体工具使用和安全四大能力，使用 CISPO 算法 + GDPO 多奖励归一化，不施加 KL 惩罚，每 prompt 采样 16 个 rollout，共约 10 万 prompts。
- **训练-推理精度一致性**：端到端统一采用 blockwise FP8（训练器与 vLLM rollout 引擎数值一致），避免 MXFP8 训练与 blockwise FP8 推理之间的精度失配导致的奖励崩溃。

### 4. 关键算法流程（文字描述）

1. 预训练：数据质量过滤 + 课程调度 → WSD 调度（Stage 1 稳定阶段 → Stage 2 衰减阶段）→ 32K/128K 上下文原生扩展 → SGA 稀疏适配（索引器稀疏预热 + 全模型微调）→ 检查点合并。
2. 后训练：索引器 SFT（模型 + 索引器联合训练）→ 主 SFT（固定索引器，Think-Fusion 成对数据）→ 多阶段 RL（CISPO + GDPO，四大能力联合优化）。
3. 推理：用户通过控制 token 在思考/非思考模式间切换；长上下文通过 SGA（每 query 仅读 2048 位置） + EAGLE3 投机解码 + NVFP4 量化分层加速。

### 实验充分性分析

- **训练策略全面**：消融覆盖架构关键组件（GN）、训练阶段（SGA 预热 vs 预训练）、精度方案（FP8 vs NVFP4）和分布式推理配置，且均配套量化指标；
- **评估体系完整**：从数学推理、代码、科学知识到韩语专属能力、多语言泛化、长上下文与智能体工具使用，形成了"能力覆盖 + 语言覆盖 + 任务类型覆盖"的三维评价矩阵；
- **针对性验证强**：针对 SGA 引入的稀疏化风险，用 LongBench v1 前后对比证明质量中性；针对量化部署风险，用 11 项任务的平均精度保留率证明 NVFP4 可用性；
- **数据来源可信**：公共基准采用官方实现或开源评测框架（如 lm-evaluation-harness、Inspect 等），韩语自建基准均披露题目构建、过滤、人工审查流程；
- **对比对象先进**：对比阵营包含当时最强的开源与商业模型（Qwen3.5、Nemotron 3、DeepSeek-V4、GLM-5.1、Kimi-K2.6、MiniMax-M2.7），横向参照充分。

总体而言，实验设计在"广度—深度—严谨性"维度上达成了良好的平衡，尤其在后训练方案（Think-Fusion、精度一致性）和中间检查点评估（KMO、AIME 等用于课程决策）上有额外验证投入。

## 六、局限性

作者在论文中未设独立章节，但可从内容中提炼如下限制：

- **规模路径未经严格消融**：论文宣称"数据质量优于数据量"，但未提供纯 token 量对比（如 8.2T vs 更多 tokens 的同架构控制实验），该结论更多是纵向对比 K1（更大 token 量但更低性能）得到的间接证据；
- **SGA 的可扩展性未知**：当上下文长度超过 256K 或 k 值需进一步提升时，索引器训练成本、注意力质量与稀疏收益之间的权衡没有给出趋势性的分析；
- **韩语基准的工程性质较强**：KS-Eval 与制造业基准多数从行业题库/文档构建，与公开基准的可复现性和国际可比性有一定差距；
- **后训练过程描述粒度不足**：RL 各阶段的具体 reward 设计、prompt 分布、各阶段间的迭代策略细节披露有限，读者难以精确复现；
- **硬件门槛高**：512×B200 + 70 天预训练 + 后训练 token 量，意味着该训练方案对非大型机构几乎不可复现，其实用价值主要体现在架构和训练方法论层面的借鉴；
- **多项智能体基准分数处于个位数或低位**（BrowseComp 9.3、τ3-Banking 13.0、Terminal Bench 36.0），说明工具调用与长时程任务的真实泛化能力仍有显著提升空间，论文对此未做深入分析。

## 七、结论（与开篇核心问题呼应）

论文的核心结论是：**智能体时代的基础模型竞争力可以而且应该通过"数据—架构—训练策略—推理系统"的四层协同设计来构建，而不是单纯依赖规模扩增。** A.X K2 在 688B/33B 的规格上：

- 通过高质量数据管线 + 课程式训练，在更少 token 下超越前代；
- 通过 SGA 将注意力成本与上下文长度解耦，使长上下文推理在服务端"相对免费"；
- 通过 GN 与精度一致性方案，控制了大规模训练的稳定性与低精度推理的质量损失；
- 通过 Think-Fusion 后训练，在单一模型中实现了思考/非思考模式的动态切换，对齐了推理时计算预算的实际需求；
- 作为韩国主权 AI 项目成果，验证了中等规模团队 + 有限 GPU 资源下实现前沿模型的可能性。

## 八、个人批判性思考（客观评价）

### 优点

1. **技术完整度高**：从预训练数据到推理优化形成了一条完整的、自洽的技术链路，架构各组件（MLA、SGA、GN、MoE）之间的耦合性有清晰的动机铺垫；
2. **工程细节扎实**：并行策略（EP=8 + PP=8 无 TP）、精度管理（MXFP8 训练 → FP8 推理 + 一致化）、检查点合并等生产级细节大大提升了可信度；
3. **反直觉贡献突出**：SGA 使"更大模型的部署反而更快"这一不等式成立，是对可缩放服务技术的重要推进；
4. **评估诚实性较好**：在 Hero 集上采用严格的多模型独立评估流程，且部分基准分数不高（如 BrowseComp、Terminal Bench）也如实公开。

### 不足与疑问

1. **基准时效性陷阱**：论文发布时多个基线模型（Qwen3.5、DeepSeek-V4、Kimi-K2.6）与评测基准（AIME26、Apex）均为同期产物，模型之间存在"共同训练于相同数据"的风险，纵向分数的提升可能部分来自测试集污染，而非真实能力跃升；后续需独立评测持续追踪验证；
2. **"思考"模式的隐性成本**：Think-Fusion 数据中思考与非思考 token 比约 13:1，意味着思考模式的推理延迟远高于显式状态；控制 token 是否真正在学习选择"何时思考"还是仅仅在模仿训练分布中的模式，值得进一步分析；
3. **SGA 索引器的可解释性**：索引器与主模型参数联合训练后，attention sink 的抑制行为与 top-k 选择的语义逻辑没有可视化分析，存在黑箱风险；
4. **训练规模声明可能被低估**：预训练 8.2T + 后训练 0.3T tokens 只是前向计算量，RL 阶段每 prompt 16 个 rollout 的探索开销、多阶段迭代中的失败尝试等未计入，实际算力消耗应高于字面数字；
5. **韩语核心优势的竞争力定位**：KMMLU-Pro 80.5 与 CLIcK 91.6 说明 K2 的韩语能力确实领先，但论文未给出对 GPT-5/Claude 等闭源前沿模型的韩语对比，无法判断其在"绝对韩语能力"上的真实国际排位。

## 九、最终评价

A.X K2 是一篇工程密度极高的技术报告，其核心贡献不仅在于一个高性能 MoE 模型，更在于三套可复用的方法论：**稀疏注意力与长上下文服务解耦的 SGA 方案、思考/非思考单轨融合的 Think-Fusion 后训练方案、以及训练-推理精度一致性管理方案**。对于大模型训练与推理系统方向的从业者，这篇论文具有显著的借鉴价值。其局限性主要体现在实验评估的长周期可复制性、部分结论的证据强度以及多维能力中智能体泛化仍偏弱三个方面，可在后续工作中以更大规模的独立评测和更细粒度的消融研究作补充。
