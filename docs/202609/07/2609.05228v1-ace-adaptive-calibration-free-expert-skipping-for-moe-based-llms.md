## 摘要
混合专家（MoE）架构为扩展大型语言模型（LLMs）提供了高效范式，然而固定的top-k路由会对每个令牌激活相同数量的专家槽位，导致大量冗余计算。现有的专家跳过方法通常依赖路由器置信度、校准数据或额外训练，因此无法可靠估计被路由专家的实际贡献。为此，我们提出ACE，一种无需训练、无需校准且保持检查点不变的框架，用于基于MoE的LLMs中的令牌自适应专家跳过。ACE包含两个互补组件：1）全局频谱代理（GSP），从耦合的gate、up和down投影以及RMSNorm缩放中估计全局变换能力；2）路由条件细化（RCR），从居中的路由器权重构建专家特定方向原型，并沿路由优先方向评估专家响应。在推理期间，ACE将两种估计与运行时路由门控相结合，仅当两个视图均将某专家槽位识别为低贡献时跳过该槽位，同时始终保留top-1专家。所有专家统计信息均离线计算，在线仅需查表及轻量级标量操作。在三个基于MoE的LLM和八个基准上的广泛实验表明，ACE一致优于现有静态和动态基线，在激进专家跳过下优势愈发明显。例如，在Qwen3.6-35B-A3B上采用50%跳过比率时，ACE将WikiText-2困惑度降低7.96%，并将平均下游准确率较最强竞争方法提高4.15个百分点。

## Abstract
Mixture-of-Experts (MoE) architectures provide an efficient paradigm for scaling large language models (LLMs), yet fixed top-k routing activates the same number of expert slots for every token, causing substantial redundant computation. Existing expert-skipping methods often rely on router confidence, calibration data, or additional training, and therefore cannot reliably estimate the actual contribution of routed experts. To this end, we propose ACE, a training-free, calibration-free, and checkpoint-preserving framework for token-adaptive expert skipping in MoE-based LLMs. ACE contains two complementary components: 1) Global Spectral Proxy (GSP), which estimates global transformation capacity from the coupled gate, up, and down projections together with RMSNorm scaling; and 2) Router-Conditioned Refinement (RCR), which constructs expert-specific direction prototypes from centered router weights and evaluates expert responses along routing-preferred directions. During inference, ACE combines both estimates with runtime router gates and skips an expert slot only when both views identify it as low-contribution, while always retaining the top-1 expert. All expert statistics are computed offline, leaving only table lookups and lightweight scalar operations online. Extensive experiments across three MoE-based LLMs and eight benchmarks demonstrate that ACE consistently outperforms existing static and dynamic baselines, with increasingly pronounced advantages under aggressive expert skipping. For instance, at a 50% skipping ratio on Qwen3.6-35B-A3B, ACE reduces WikiText-2 perplexity by 7.96% and improves average downstream accuracy by 4.15 percentage points over the strongest competing method.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：Mixture-of-Experts（MoE）架构通过稀疏激活扩展大语言模型参数规模，是当前主流方案。但现有多数 MoE 模型采用固定 top-k 路由，对每个 token 激活相同数量的专家槽，忽视了不同 token 对专家需求的实际差异，导致大量冗余计算。
- **核心问题**：如何在不修改模型检查点、不引入校准数据的前提下，可靠地判断每个被路由专家对当前 token 的实际贡献，并据此跳过低贡献专家以节省计算？
- **现有方法的三大局限**：
  1. 路由置信度（router score）只反映**相对分配偏好**，而非该专家被执行后对 MoE 输出产生的**边际贡献**，仅凭门控值跳过会把"被偏好"误认为"有贡献"。
  2. SwiGLU 专家的输出由 gate、up、down 三个投影经**非线性乘性耦合**共同决定，单一矩阵范数、使用频率或全局路由统计无法充分刻画其变换能力。
  3. 专家贡献具有**方向依赖性**：全局响应弱的专家可能在路由器偏好的局部输入子空间内表现很强，贡献估计必须考虑路由器编码的方向选择性。

## 2. 论文提出的方法论

### 总体框架

ACE 采用"离线参数分析 + 在线轻量决策"两层架构：离线阶段从冻结的模型权重中计算两类专家统计表（GSP 表和 RCR 表），在线阶段仅通过查表、标量乘法和 top-k 内的归一化完成跳过决策。核心设计为**双视图保守跳过**——仅当 GSP 与 RCR 两个视角同时将某专家槽判为低贡献时才予以跳过，并始终保留原路由 top-1 专家。

### 组件一：Global Spectral Proxy（GSP）

GSP 从 SwiGLU 专家的参数结构中提取与方向无关的全局变换能力估计，完全不需要真实激活或校准数据。

- **推导出发点**：基于 |SiLU(z)| ≤ |z| 的性质，推导出 SwiGLU 专家输出的上界：
  ∥f(x)∥ ≤ ∥x̄∥² · ∥ΓW_gate∥ · ∥ΓW_up∥ · ∥W_down∥，
  说明响应上限由三个投影矩阵的范数以**乘性耦合**方式共同决定。
- **分支对称双路径构造**：
  - a_up = ∥ΓW_up∥_F · ∥ΓW_gate · W_down∥_F（up 分支响应规模 × gate-to-down 传输路径）
  - a_gate = ∥ΓW_gate∥_F · ∥ΓW_up · W_down∥_F（gate 分支等价对称式）
- **聚合**：取两条路径的**几何平均**，对路径间不均衡更敏感，避免单一路径异常大值的主导。
- **层内归一化**：原始值按层内均值归一化，得到相对该层平均水平的静态放大分数 A_GSP_l(e)，使不同层之间可比。

### 组件二：Router-Conditioned Refinement（RCR）

RCR 弥补 GSP 无法刻画"方向选择性"的缺陷，从路由器权重中提取专家特异性方向原型并测量该方向的响应强度。

- **路由器权重中心化**：w̃_l,e = w_l,e − (1/N_l)Σ_j w_l,j。利用 softmax 路由对共享平移不变的数学性质（论文给出完整证明），消除不可识别的共享成分，仅保留相对判别方向。
- **概率解释**：在高斯近似下，由中心化权重诱导的指数倾斜分布的均值偏移约等于 Σ_l·w̃_l,e；当协方差近似各向同性时，均值偏移方向与 w̃_l,e 对齐，故中心化路由器权重可作为专家条件输入方向的无数据近似。
- **方向原型构造**：对中心化权重做 RMS 归一化得到 q_l,e（ACE 中设输入尺度先验 ρ_l=1，保持完全免校准）。
- **前向评估**：离线将 q_l,e 输入对应专家做一次完整 SwiGLU 前向，计算响应增益 ẽ_RCR = ∥f(q)∥/∥q∥，再做层内归一化得到 A_RCR_l(e)。

### 在线推理与跳过决策

对原路由选出的 k 个专家槽位，分别计算：
- s_GSP = g·A_GSP（路由偏好 × 全局结构能力）
- s_RCR = g·A_RCR（路由偏好 × 路由条件响应）
- 各自在 top-k 内归一化得 p_GSP 和 p_RCR

最终贡献分数采用**保守最大准则**：c_ACE = max(p_GSP, p_RCR)。数学上等价于两个低贡献候选集的**交集**（S_ACE = S_GSP ∩ S_RCR），即一个专家槽仅当两种证据都认为它不重要时才被跳过。此外始终保留 top-1 专家，并通过最小活跃数约束与门控重新归一化保证输出稳定。论文还证明了该规则跳过的路由概率质量不超过任一单视图，输出扰动有界且不劣于任一单视图。

- **具体数据佐证**：Qwen3.6-35B-A3B 在 50% 跳过时，ACE 将 WikiText-2 PPL 从 MoDES 的 9.42 降至 8.67（降 7.96%），平均准确率从 71.42% 提升至 75.57%（+4.15 个百分点）；Gemma-4-26B-A4B-it 在 60% 跳过时 ACE 仍保持 72.11% 平均准确率，而最强基线仅 69.65%（GSP）且部分对比方法崩溃至 20–30% 区间。
- **PPL 与下游准确率互补**：部分方法 PPL 尚可但下游推理/代码能力崩溃，ACE 同时保持两方面的强表现，反映双视图判别的稳健性。
- **双视图融合有效**：ACE 相对单独 GSP 在 50% 跳过时仍有增益（Qwen3-30B：PPL 从 8.99→8.85，Avg 从 74.10→74.30），Max 融合规则优于 Min 与 Mean；RCR 单独表现较弱，但作为互补信号价值明显。
- **延迟收益明显**：60% 跳过时 TTFT 最高加速 2.25×、TPOT 最高 1.41×，且在线评分开销相对专家前向计算可忽略（与匹配预算方法延迟差异在 1% 以内）。

## 7. 优点

- **完全免训练、免校准、保权重**：GSP 与 RCR 仅从冻结模型参数与路由器几何中推导，无需真实样本、激活缓存、梯度或损失；未显式修改任何预训练权重，是实用的训练后轻量加速方案。
- **理论动机扎实**：从 SwiGLU 输出上界的乘性耦合推导 GSP 的对称双路径构造；从 softmax 平移不变性与高斯指数倾斜推导路由器权重中心化与方向原型假设，均给出严谨证明，使方法的每一步设计有数学依据而非工程启发式。
- **双视图互补设计精巧**：GSP 捕获全局结构容量（与方向无关），RCR 捕获路由条件方向专业化；两者通过保守交集（Max）规则融合，且该规则有输出扰动上界的理论保证，在跳过率升高时优于任何单视图信号。
- **在线开销极低**：推理阶段仅含查表和 top-k 标量操作，无高维专家前向；条件允许时可做到与匹配预算方法同速甚至更快。
- **阈值跨任务稳定**：实验表明同一模型在同一目标跳过率下不同数据集的阈值高度接近（表 8），支持一次未标注前向后跨数据集复用阈值。
- **工程可落地**：代码已开源，加速数据在真实 A100 环境测得，不只是算法层面的理论收益。

## 8. 不足与局限

- **缺少重复运行的统计不确定性报告**：所有结果为单次确定性运行（seed 42），在 GPQA-Diamond 等样本量小的基准上无法评估随机波动对结论的影响，论文承认亚点差异需谨慎

- **统计不确定性缺失**：所有结果为单次确定性运行（seed 42），在 GPQA-Diamond 等样本量小的基准上无法评估随机波动对结论的影响，论文承认亚点差异需谨慎。
- **扩张性／计算规模披露不足**：未报告完整 GPU 配置、总运行时间与能源开销，外部复现的基准线校准成本难以准确预估。
- **RCR 信号单独使用效果偏弱**：消融显示 RCR 单独作为跳过判据时性能明显低于 GSP 与 ACE，说明仅依赖路由器条件方向响应的建模能力有限——其对路由器几何依赖较强，且输入尺度先验 ρ_l=1 的免校准假设未必在更大规模模型上依然成立。论文未探讨不同 ρ 设置或更精细方向原型对 RCR 稳健性的影响。
- **离线生成的额外成本被低估**：RCR 需要为每个专家构造方向原型并额外做一次专家前向传播；虽然属于一次性成本，但论文对这一成本在不同模型规模/硬件上的显存、耗时开销没有单独量化，仅给出阈值搜索时间，容易让读者低估“免训练”方案的总部署成本。
- **理论保证的强度有限**：所给扰动上界与保守交集的不劣性质是在理想假设（如各向同性协方差、静态路由）下推导的；实际前向中 token 输入分布偏离这些假设时，保证的定量意义未给出敏感度分析。
- **只对 FFN/MoE 层做稀疏跳过**，不涉及注意力层及其他计算部分，因此延迟加速存在上限；对于 FFN 占比更低的较短序列或小 batch 场景，收益会被其他算子稀释，论文效率测量也印证了不同配置下加速窗口波动较大。
- **可扩展性验证偏窄**：仅在 Qwen3-30B-A3B、Qwen3.6-35B-A3B、Gemma-4-26B-A4B-it 三类中等规模模型上评估，未在更大参数族（如 DeepSeek 系列）或不同 MoE 风格（如细粒度专家、共享专家结构）上验证方法假设的普适性。

## 9. 总体评价与定位

- **定位清晰，补足了 MoE 无需训练的推理加速研究链条**：ACE 提供的不是比路由置信度“再精细一档”的启发式，而是首次系统地从 SwiGLU 参数结构（GSP）和路由器条件方向（RCR）两个可互补的视角，将“专家贡献”落地为无需校准数据的可计算量，并给出了保守融合的在线规则及其理论保障。
- **作为“训练后干预”的实际方案有较高的工程可用度**：不改权重，不需要在校准集上过一遍模型，不需要修改原路由算法，只对候选集打分与保守裁剪；与路由器联合学习的“提前退出”“专家合并”路径相比，保留了模型灵活性。
- **学术贡献面大于当前实验规模**：GSP 的上界推导与 RCR 的中心化构造、双视图保守交集等价证明，均具有超越本论文实验设置的启发价值；局限性在于统计验证宽度尚未反哺理论设计的置信度。
- **综合判断**：就“如何用免校准的低开销信号预测 MoE 专家计算价值”这一问题而言，ACE 是目前从机理到工程链条较完整的答案之一。在激进跳过率区间（40–60%）可提供可观的加速且几乎不损失能力；在温和跳过区间收益有限。建议作为“与现有专家路由并行使用的推理优化模块”在其适用的 MoE 模型上优先试用，并期待更大规模与多随机种子实验对结论的进一步夯实。
