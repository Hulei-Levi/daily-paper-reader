## 摘要
地球观测表征学习的最新进展通常通过更大的架构来适应异构传感器和缺失观测。我们提出 MEOX（Multimodal Earth Observation with eXperts），一种多模态掩码自编码器，其编码器有 293.9 万参数，总计 311.5 万参数。传感器特定适配器、显式有效性信号和共享的稀疏专家块在学习的逐补丁融合之前保留了依赖模态的处理。随后，四个元数据令牌与单个空间序列一起通过另外十四个编码器块。共享专家投影与私有低秩残差限制了参数增长，而旋转注意力支持与预训练不同的下游空间网格。该模型在 122.8 万个 MMEarth64 样本上预训练，采用模态平衡掩码重建和结构化传感器丢弃。在 64 和 224 像素下，对六个 GEO-Bench 任务进行了冻结迁移评估。该模型在 64 像素下的腰果分割任务上达到 64.42% 的平均交并比，在 224 像素下的 EuroSAT 上达到 90.56% 的平均准确率，超过了相应报道的 CSMoE 结果。BigEarthNet 微调达到 72.95% 的微平均精确率。路由诊断区分了专家参与度、空间依赖性、模态关联和功能贡献。一个留出的 WorldCover 探针测量出元数据带来了 0.64 个百分点的收益，而检索则将同传感器语义与跨传感器对齐区分开来。这些结果表明，在紧凑的参数预算下实现了传感器灵活的表征学习和强大的任务迁移。

## Abstract
Recent advances in Earth Observation representation learning accommodate heterogeneous sensors and missing observations, often through larger architectures. We present MEOX (Multimodal Earth Observation with eXperts), a multimodal masked autoencoder with a 2.939 million-parameter encoder and 3.115 million parameters in total. Sensor-specific adapters, explicit validity signals, and a shared sparse-expert block preserve modality-dependent processing before a learned patch-wise fusion. Four metadata tokens then accompany a single spatial sequence through fourteen further encoder blocks. Shared expert projections with private low-rank residuals constrain parameter growth, while rotary attention supports downstream spatial grids different from pretraining. The model is pretrained on 1.228 million MMEarth64 samples using modality-balanced masked reconstruction and structured sensor dropout. Frozen transfer is evaluated on six GEO-Bench tasks at both 64 and 224 pixels. The model reaches 64.42% mean intersection-over-union on cashew segmentation at 64 pixels and 90.56% average accuracy on EuroSAT at 224 pixels, exceeding the corresponding reported CSMoE results. BigEarthNet finetuning reaches 72.95% micro-average precision. Routing diagnostics distinguish expert participation, spatial dependence, modality association, and functional contribution. A held-out WorldCover probe measures a 0.64-percentage-point benefit from metadata, while retrieval separates same-sensor semantics from cross-sensor alignment. These results demonstrate sensor-flexible representation learning and strong task transfer using a compact parameter budget.

## 1. 论文核心问题与整体含义

地球观测（EO）中的基础模型通常需要灵活处理多源异构传感器（如 Sentinel-1 SAR 与 Sentinel-2 光学影像）、不同空间分辨率、以及普遍存在的数据缺失问题。然而，现有主流方案往往以更大的模型架构来换取这种灵活性，导致存储和计算成本高企，不利于大规模归档处理和有限硬件上的部署。论文的核心追问是：**仅用数百万参数（而非数十亿），能够在多大程度上保留多模态、多尺度、可处理缺失输入的 EO 表征学习能力？** 为此，作者提出 MEOX，一个仅约 311 万总参数的紧凑多模态掩码自编码器，在六个 GEO-Bench 任务上展示了与更大模型（如 CSMoE、DOFA、TerraMind 等）可比或更优的迁移性能，并为小规模 MoE 的可用性提供了系统的路由诊断证据。

## 2. 研究方法与关键技术

方法论的核心思想是**延迟的、有效性感知的融合**：不让每一种传感器各自维持一条贯穿整个编码器的 token 序列，而是先用一个共享参数的 transformer-MoE 块对每个可用传感器独立编码，再通过逐补丁学习的门控权重将多模态流融合为单一序列。具体技术要点如下：

- **输入表征与缺失建模**：每个传感器图像被划分为 4×4 的 patch，产生 256 个宽 144 的 token。传感器 m 的 patch token 由四项构成：
  - 卷积适配器对 patch 内容的嵌入 \\(A_m(X_m)_i\\)；
  - 有效性掩码的嵌入 \\(Q_m(V_m)_i\\)（初始化零，初始不扰动图像表征），使缺失值与有效归一化零值区分开来；
  - 传感器身份向量 \\(\epsilon_m\\)；
  - 波段存在向量 \\(r_m\\) 的投影 \\(R_m r_m\\)（支持命名波段子集）。
- **元数据 token**：四个元数据 token 分别对应纬度、经度、月份和 ERA5 气候上下文，每个 token 通过公式 \\(u_j = W_j(x_j \odot v_j) + \gamma_j + \epsilon^\text{type}_j + (1 - \bar{v}_j)\epsilon^\text{miss}_j\\) 构造，使缺失状态成为显式表示而非零值解释。
- **共享传感器处理与延迟门控融合**：每个可用传感器独立经过同一 layer‑0 共享 transformer-MoE 块；随后逐位置计算融合分数（见公式 3–4），融合分数包含传感器偏置和一个**对数有效性先验** \\(\log(\max(q_{m,i}, 10^{-6}))\\)（来自 patch 内有效元素比例），softmax 权重在所有可用传感器间归一化。融合参数初始化为零，使等有效性传感器初始权重相等，模型可后续学习逐位置偏好。融合后 CLS 和元数据 token 才进入序列，后续 14 层编码器只处理单一空间流，节省了大量计算。
- **紧凑稀疏专家设计**：
  - 层内共享 value 投影 \\(W_v\\) 和输出投影 \\(W_o\\)，每个专家具有私有 rank‑8 残差路径 \\(U_{v,e}D_{v,e}\\) 和 \\(U_{o,e}D_{o,e}\\)（公式 7–8），U 矩阵零初始化；
  - 专家数随深度增加（前 5 层每层 3 个，中间 5 层 4 个，后 5 层 5 个），隐藏宽度从 144 递减到 72；
  - 采用 top‑2 软路由（公式 5–6），路由 logits 加高斯噪声训练，推理时确定性；无容量上限，token 不会被丢弃。
- **轴向 RoPE 替换可学习绝对位置表**，支持与预训练不同尺寸的空间网格（64 与 224 均可）。
- **预训练目标**：
  - 重建损失 \\(L_m\\)（公式 9）只在空间掩码且目标有效的元素上计算，按有效目标元素数归一化；
  - 所有可供重建的传感器损失等权平均（公式 10），避免 13 波段 S2 主导 2 波段 S1；
  - 辅助平衡损失（公式 13–14）基于 Switch 式概率–执行分配乘积，权重 β=0.01。
- **传感器丢弃**：10% 批次中随机将三种传感器流子集输入编码器，但重建目标仍包含全部传感器，迫使模型具备缺失输入条件下的跨传感器预测能力。
- **推理阶段**：删除解码器和空间掩码，直接返回编码器前/后 LayerNorm 特征。

## 6. 主要结论与发现

- **冻结迁移**：在 64 像素下，MEOX 在 cashew（mIoU 64.42%）和 EuroSAT（AA 89.70%）上均超过 CSMoE 全部变体（分别领先 5.02 和 1.40 个百分点）；224 像素下 EuroSAT 达 90.56%。但在 BigEarthNet（57.22% mAP）和 SA-crop-type（32.33% mIoU）上仍与大型模型存在明显差距。
- **分辨率行为非单调**：224 输入可提升 crop type 4.68 点，却降低 So2Sat 2.43 点，说明空间重采样效果因任务而异，不存在统一的"更大分辨率更好"结论。
- **参数与计算权衡**：总参数量为 CSMoE P=14 的约 1/87；64 像素下 S2 编码器 FLOPs 远低于 CSMoE 全部变体（1.029G vs 2.92–13.40G），但 224 像素下因全局注意力升至 51.477G，参数优势仍在但计算优势消失。
- **路由诊断发现**：每个专家都有 token 执行（最小执行率 25.12%），全局平衡但逐 token 选择具有选择性；路由与绝对图像位置没有明显关联（NMI 接近置换基线），而与地物语义存在可观测关联；传感器条件路由在共享 layer‑0 中确实发生；不同专家输出余弦相似度在中深层显著降低（0.68–0.89 到 0.39–0.69）；干预说明部分专家比其它专家功能影响更大——完全执行不代表贡献相等。
- **元数据收益小但为正**：去掉全部元数据损失 0.64 个 mIoU 点（匹配重训头），其中 ERA5 贡献最大（0.292 点），月份几乎无影响；该收益不能外推为所有下游任务表现。
- **嵌入几何问题**：有效秩低（约 8.44/144），均值余弦高（0.54）主要来自共享均值方向；减均值后余弦降到 0.01 附近。移除前 2 个主成分后 EuroSAT 线性探测掉至 86.8%，说明"主导方向"携带语义而非仅噪声。
- **检索**：S1→S1 与 S2→S2 的 F1（64.41%/66.33%)优于 CSMAE 和部分 CSMoE 变体，但跨传感器方向的检索弱于最强参考；重建式多模态训练未等效产生齐整的雷达–光学语义同构。

## 7. 主要优点

- 以极小参数预算（约 3.1M）实现与大规模模型可比的部分冻结转移精度，是轻量化方向上一个可复现的竞争基线。
- 结构设计注意效率和模块化：共享 layer‑0 + 控制深度语义（14 层混合语义）可降低多流 Transformer 成本；低秩专家残差在不大幅增加存储的前提下保持专家区分度；显式有效性掩码嵌入与波段存在向量在语义上区分"缺失"与"均值填充"。
- 统一支持 64 与 224 空间网格，且用轴向 RoPE 而非可学习位置嵌入，设计合理，边界可扩展至矩形输入。
- 路由分析不是只给平衡或熵，而是从执行率、门控占比、位置/语义互信息、传感器条件、干预损失五个维度提供可操作的诊断结果，对"MoE 是否真的专家化"给出了多侧面的正面和限定证据。
- 完整性较高：作了表级元数据消融、嵌入策略消融、归一化消融、主成分删除消融、头不确定性度量等，且从数据加载到噪声路由均有可用开源仓库。

## 8. 不足与局限

- **跨 benchmark 缺乏全局对齐的对比设置**：许多对比来自不同度量定义、输入通道、池化方式与"验证集依赖的调优"，可能带来无法完全由表值消化的偏差（作者自己承认输入配置、预训练分布和实现差异不可控）。
- **几何表示仍集中于少量主成分**，有效秩很低；虽然文中证明主成分含语义信息，但这未必适用于所有的下游密集任务；对此类模型的高维潜力留有疑问。
- **检索结果显示跨传感器对齐较弱**，说明当前重建式多模态任务并不天然形成统一的雷达–光学嵌入空间，需要显式对比或对齐目标。
- **元数据消融在单语料进行**，且预训练期间不可缺失元数据的干预未测试，无法估计预训练阶段元数据缺失鲁棒性的因果归因。
- **只测试了 P=4 token 化一种配置**，没有评估 patch 大小、掩码比、专家数、低秩秩值及噪声幅度变化对冻结任务性能的影响。
- 训练资源披露不充分（MIG 切片而非整卡），缺少吞吐量/推理时延的报告，使得"紧凑"更多是参数量意义上的结论，而非计算路径上的严格比较。
- 未涉及时序输入、更长波长地物目标（如动态世界 / 土地覆盖分割真实场景输入）或超大影像的重叠窗口推理。

总体而言，该工作很清晰地回答了"小参数 MoE 在多模态地球观测中能走多远"，方法层面的设计透明度和分析系统的完备性是主要学术价值，但在对比公平性和外部验证方面仍属初步成果。
