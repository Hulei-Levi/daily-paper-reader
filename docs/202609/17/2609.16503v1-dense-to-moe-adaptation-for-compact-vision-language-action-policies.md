## 摘要
视觉-语言-动作（VLA）策略的参数量持续增长，使其难以部署在资源受限的机器人平台上。核心目标是在保持下游任务性能的同时，减少部署策略中保留的LLM侧参数量。我们的方法AdaDE将选定的稠密前馈块适配为专家混合（MoE）层，并在微调过程中根据路由器统计量推导专家保留掩码。Dense2MoE转换在初始化时保留了原始稠密FFN功能，因此专家停用无需单独的恢复阶段即可开始。我们没有使用固定的关闭规则，而是根据路由器使用统计量动态更新专家掩码，并采用分阶段训练和专家保护来避免早期崩溃。在停用40%的LLM参数后，AdaDE在LIBERO上保持95.1%的平均成功率，在全部50个RobotWin2.0任务上保持42.0%的平均成功率。这些结果表明，具有动态专家停用的稠密到MoE适配是在不造成严重性能损失的情况下减小活跃VLA模型规模的一个实用方向。

## Abstract
Vision language action (VLA) policies continue to grow in parameter count, making deployment on resource-constrained robot platforms difficult. The central goal is to reduce the number of LLM-side parameters retained in the deployed policy while preserving downstream task performance. Our approach, AdaDE, adapts selected dense feed forward blocks into mixture of experts (MoE) layers and derives expert retention masks from router statistics during fine tuning. The Dense2MoE conversion preserves the original dense FFN function at initialization, so expert deactivation can start without a separate recovery stage. Instead of using a fixed shutdown rule, expert masks are updated dynamically from router usage statistics, with staged training and expert protection to avoid early collapse. With 40% of the LLM parameters deactivated, AdaDE retains 95.1% average success in LIBERO and 42.0% average success across all 50 RobotWin2.0 tasks. These results suggest that dense to MoE adaptation with dynamic expert deactivation is a practical direction for reducing active VLA model size without severe performance loss.

# 论文总结：Dense to MoE Adaptation for Compact Vision Language Action Policies

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）策略将感知、语言条件与动作预测统一到单一模型中，已成为机器人学习的可扩展范式。但随着模型规模持续增长，部署到算力、内存与功耗预算有限的真实机器人平台变得愈发困难。
- **核心矛盾**：机器人策略与离线多模态生成不同，其模型体积直接影响硬件需求与可及性。作者通过参数构成分析发现，在多种代表性 VLA 系统中（GR00T、LingBot-VLA-4B、X-VLA、pi0.5），LLM 侧骨干占据了总参数的相当大比例，因此 LLM 侧 FFN 是压缩部署参数量的自然目标。
- **关键观察**：初步实验表明，ViT 与动作生成模块对压缩更为敏感，而语言骨干具有显著更高的冗余度。
- **核心目标**：在保留下游任务性能的前提下，减少部署策略中保留的 LLM 侧参数量。
- **与既有方法的分歧**：传统稠密结构化剪枝会直接移除耦合的层、注意力头或中间通道，改变预训练网络函数并引入输出误差，通常需要额外的微调或补偿来恢复性能；而本文追求的是"先无损重参数化、再自适应稀疏化"的路径。

## 2. 方法论

### 2.1 核心思想
- 提出 **AdaDE（Adaptive Dynamic Expert Deactivation）** 框架，分两步走：先用 **Dense2MoE** 将稠密 FFN 无损转换为 MoE 结构，再在策略微调过程中自适应地停用弱专家。
- 与常规 top-k 稀疏 MoE 不同，AdaDE 是一种**面向压缩的宽度划分、掩码式 MoE**：路由器为所有专家计算概率，由逐层二值掩码决定保留哪些专家切片，而非追求 token 级稀疏路由加速。

### 2.2 Dense2MoE：函数保持的稠密到 MoE 转换
- **通道划分**：设 FFN 中间宽度为 H、专家数为 E，计算 q = ⌊H/E⌋、r = H mod E，前 r 个专家分得 q+1 个通道，其余分得 q 个通道，实现无填充、无重叠的精确划分。
- **权重切片**：W_gate 与 W_up 沿第一维切片，W_down 沿第二维切片，保持总参数量不变，避免复制整个 FFN 形成冗余专家。
- **路由器初始化**：路由器为线性投影，权重与偏置均初始化为零，使所有专家初始概率相同（1/E）。
- **函数保持性**：经掩码重归一化与缩放因子 G(e) = E·p̃_e(x) 后，初始化时 G(e)=1，转换后 MoE 块与原始稠密 SwiGLU 块在浮点误差范围内完全等价（Output_moe ≡ Output_dense）。

### 2.3 基于 EMA 的专家重要性估计
- 每个转换层独立维护专家的指数移动平均（EMA）重要性分数：s_r,j^(t) = β·s_r,j^(t−1) + (1−β)·ū_r,j^(t)。
- 其中 ū 为当前批次内该专家的平均路由器利用率，β 为平滑系数。EMA 抑制短期路由噪声，使停用决策依赖于持续利用率而非瞬时波动。

### 2.4 AdaDE 掩码更新规则
- 每个专家关联二值掩码 m_r,j ∈ {0,1}；未激活专家被掩蔽后，剩余概率在激活集上重归一化：g̃ = m·g / Σ(m·g)。
- **更新流程**：先进行 T_warm 步预热，之后每 ΔT 步根据 EMA 分数更新一次掩码；EMA 分数低于阈值 τ_deact 的专家成为停用候选。
- **局部约束**：每层至少保留 M_min 个专家；单次更新最多移除 K_update 个专家；专家不可重新激活，保证从稠密到稀疏的单调过渡。
- **Wanda 保护**：预热后，基于 Wanda 重要性准则将每层前 25% 的重要专家锁定为保护专家，排除在停用候选之外。

### 2.5 辅助路由正则化
- 定义层内最小平均路由器概率 p_r,min = min_j p̂_r,j，并施加辅助损失 L_aux = (1/R)Σ max(0, τ_aux − p_r,min)。
- 与标准负载均衡目标不同，该损失**不要求所有专家被均匀使用**，仅防止最弱专家的原始路由概率过早塌缩，为路由器留出形成有意义竞争的时间。
- 总训练目标：L = L_task + λ_aux · L_aux。

### 2.6 训练调度与推理
- **三阶段训练**：
  1. **预热阶段**：所有专家保持激活，联合优化任务损失与辅助路由损失。
  2. **AdaDE 动态阶段**：更新 EMA 统计，在预算与最小激活约束下停用持续弱专家。
  3. **最终冻结阶段**：从 T_freeze 起停止停用并固定掩码，使策略适应最终稀疏结构。
- **导出与推理**：训练后将非激活专家切片从检查点中**物理移除**，仅保留 W_gate、W_up 的激活行与 W_down 的激活列，部署时无需运行时掩码，直接减少部署参数量与专家侧计算。

## 6. 主要结论与发现

- **主结果**：在停用约 40% LLM 参数时，AdaDE 在 LIBERO 上保持 95.1% 平均成功率，在全部 50 个 RobotWin2.0 任务上保持 42.0% 平均成功率（稠密策略为 46.7%），TFLOPs 从 4.38 降至 3.18；50% 停用时仍分别保持约 95%（LIBERO Spatial）与 38.1%（RobotWin2.0）。
- **无损转换验证**：0% 设置下 Dense2MoE 转换本身几乎完全保留稠密策略行为（如 LIBERO Spatial 94.0% vs 98.6% 基线附近），验证了函数保持初始化。
- **自适应优于固定**：在 50% LLM 停用下，固定停用计划使 Spatial 成功率降至 88%，而 AdaDE 保持约 95%；移除 Wanda 保护后降至 90%。
- **参数与显存收益**：40% 停用使总参数从 3.618B 降至 2.841B，50% 降至 2.619B；峰值显存（batch=1）从 7.12 GB 降至 5.69 GB（40%）/5.25 GB（50%）。
- **模块敏感性差异**：动作重模块对激进停用更敏感，其包含更多任务关键计算路径；压缩容忍度呈"渐进操作区间"而非陡峭阈值。
- **真实机器人**：AdaDE（40%）平均成功率 61.4% vs Pi0.5 的 63.2%，显存从 9.16 GB 降至 7.48 GB，但部分任务执行时间因纠错动作而变长。
- **压缩对比**：LLM-Pruner 与 FLAP 在无 SFT 恢复时性能大幅下降（23.4%、0.2%），加 SFT 后可恢复（84.0%、82.6%）；AdaDE 无需单独恢复阶段即可达 84.3%（20%）。

## 7. 优点

- **方法设计亮点**：
  - Dense2MoE 采用**通道划分而非专家复制**，保持总参数量不变，且路由器零初始化实现严格的函数保持，使模型无需单独恢复阶段即可进入稀疏化。
  - 引入**EMA 平滑的路由统计**驱动停用决策，有效抑制短期噪声；结合单调不可逆掩码、单次更新预算与最小激活约束，避免训练崩溃。
  - **Wanda 保护机制**与自适应停用互补，保护结构重要专家，消融证明其必要性。
  - 辅助路由损失设计独特，不强制均匀负载，仅防止最弱专家过早塌缩，契合压缩目标。
  - 训练后**物理移除**非激活专家切片，部署检查点真正变小，而非依赖运行时掩码。
- **实验设计亮点**：
  - 同时覆盖仿真（LIBERO、RobotWin2.0）与真实机器人，验证了稀疏结构的可迁移性。
  - 报告了参数量、TFLOPs、峰值显存等多维部署指标，贴近实际部署需求。
  - 与剪枝、量化等多种压缩范式的横向对比增强了结论说服力。
- **分析亮点**：对逐层停用行为、任务相关专家利用、路由统计时序演化、语言重/动作重模块预算分配进行了诊断分析，支撑了"冗余分布不均匀、需模块感知停用"的核心假设。

## 8. 不足与局限

- **覆盖范围有限**：AdaDE 仅针对 LLM 侧 FFN 块进行稀疏化，未处理视觉与流匹配组件（初步实验显示这些部分对激进停用更敏感）。
- **超参数敏感**：引入多个调度相关超参数（预热时长、更新间隔、EMA 系数、停用阈值等），其最优设置可能因架构与训练范式而异；消融显示 ΔT 过小会严重不稳定（50 步时成功率降至 68%）。
- **未降低端到端推理延迟**：batch=1 时稠密基线 212 ms，AdaDE（50%）反而增至 236 ms。原因是稀疏路由引入额外路由、专家选择与聚合开销，且转换后的 MoE 层执行多个较小的专家投影而非高度优化的稠密 GEMM 内核；流匹配推理中反复的动作专家评估会放大这一开销。核函数级优化留作未来工作。
- **真实机器人实验规模偏小**：仅 7 个任务，且部分任务执行时间因纠错动作而延长，执行时间反映的是整条轨迹而非纯模型开销。
- **统计严谨性**：未报告多次运行的方差、置信区间或显著性检验；主表任务选择存在一定主观性（"高稠密成功率"）。
- **安全与伦理考量**：论文自身指出，更易部署的机器人决策系统在可靠性、监控与任务约束不足的场景中可能放大风险；紧凑化不应替代安全验证，需配合任务级约束、人工监督与暴露失败模式的基准报告。
