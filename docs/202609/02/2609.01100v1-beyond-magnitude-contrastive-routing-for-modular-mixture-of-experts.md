## 摘要
在当前的混合专家架构中，路由基于由所有令牌共享的结构所主导的表示进行，这限制了专家的专业化。我们表明，将每个令牌与层隐藏状态的指数移动平均进行对比，而非基于绝对幅度进行路由，能够将路由信号集中到低维、高度可分离的子空间。在此基础上，我们提出了对比路由机制（CoRM），该机制通过每个专家对输入令牌的亲和力与其对该共享参考状态的亲和力之间的差距来对专家进行评分，并通过每个专家独特的投影进行解释。由此产生的专家路由边界在语言结构上比Top-k基线更为对齐。我们的实验表明，在九个零样本推理基准上，CoRM在Top-1和Top-2设置下的平均零样本准确率分别比标准Top-k MoE基线提高了+0.67到+1.69个百分点和+1.38到+1.77个百分点，而每令牌仅增加2.9%的参数和2.6%的FLOPs。

## Abstract
In current Mixture-of-Experts architectures, routing is performed based on representations dominated by structure shared across all tokens, limiting expert specialization. We show that contrasting each token against an Exponential Moving Average of the layer's hidden states, rather than routing on absolute magnitude, concentrates the routing signal onto a low-dimensional, highly separable subspace. Building on this, we propose the Contrastive Routing Mechanism (CoRM), which scores each expert by the gap between its affinity for the incoming token and its affinity for this shared reference state, interpreted through a distinct per-expert projection. The resulting experts have routing boundaries that align with linguistic structure significantly more than the Top-k baseline. Our experiments show that CoRM improves average zero-shot accuracy by +0.67 to +1.69 points (Top-1) and +1.38 to +1.77 points (Top-2) over standard Top-k MoE baselines on nine zero-shot reasoning benchmarks, at the minimal cost of 2.9% added parameters and 2.6% added FLOPs per token.

## 1. 论文的核心问题与整体含义

论文聚焦于当前稀疏混合专家（Sparse Mixture-of-Experts, SMoE）架构中的路由机制缺陷。在传统 MoE 模型中，路由决策基于 token 表示的"绝对幅度"（即原始点积或范数大小），而 token 表示的空间几何呈现出显著的各向异性，其大部分方差由跨所有 token 共享的低维背景结构（如句法共性、停用词模式等）所主导。这导致路由器将大量注意力投向"比较普遍的 token"，而非真正具有判别性的语义特征，致使专家的功能分化有限，甚至出现表示坍缩：各专家逐渐冗余，未能形成有意义的模块化分工。

本文的核心观点在于：专家选择应建立在 **"对比（Contrastive）"信号**之上——比较当前 token 与一个描述普遍状态的参考表示之间的差异，而非直接比较 token 的绝对大小。基于此，作者提出 CoRM（Contrastive Routing Mechanism，对比路由机制）。

整体含义上，该工作探索了如何利用表示几何中的先验冗余结构，设计一种轻量、隐式的归纳偏置，以较低成本引导 MoE 专家实现更彻底的功能模块化和语言结构对齐，进而提升下游零样本推理性能。

## 2. 论文提出的方法论

### 2.1 核心思想

CoRM 从两个基本观察出发：

1. **路由器应"去均值"化**：将每个 token 与该层隐藏状态的指数移动平均（EMA）进行比较，抑制公共背景结构对路由得分的支配；
2. **专家应拥有独立的解释视角**：通过每专家独有的查询（Query）投影，使共享的参考状态在各专家眼中产生不同的"锚点"，从而让不同专家在语义空间中占据不同的方向。

### 2.2 关键技术细节

CoRM 的完整路由计算流程可分解为以下步骤：

1. **维护参考状态**：在每一层中，以指数移动平均形式存储并更新"平均 token"表示，作为所有专家共用的动态基线。该参考状态不参与梯度计算，仅随训练批次滑动更新。

2. **共享 Key 投影**：将 token 原始隐藏表示经由一个统一的线性映射压缩到低维空间并完成 L2 归一化，得到方向化的语义标识。

3. **逐专家 Query 投影**：为每个专家各自配备一个独立的查询投影矩阵，也映射至该低维空间并归一化。对每个专家，同时计算它对当前 token 的 Query 以及它对 EMA 参考状态的 Query。

4. **计算对比注意力差距**：对于每个专家，计算该专家对 token 的亲和力分数（当前 token 的 Query 与共享 Key 的点积），减去该专家对参考状态的亲和力分数（参考状态的 Query 与共享 Key 的点积），差值即为最终路由分数。

5. **专家选择**：选用得分最高的 Top-1 或 Top-2 专家进行计算，并配合负载均衡损失（load balancing loss）确保专家使用率相近。

### 2.3 公式化表达（文字说明）

- 共享 Key 通过将输入向量 x 乘以一个可学习矩阵，再进行 L2 归一化，得到其低维语义表示。
- 每个专家的 Query 也做类似处理，分别对当前 token x 和 EMA 参考状态执行 L2 归一化投影。
- 路由分数定义为：该专家的 Token Query 与共享 Key 的余弦相似度，减去该专家的参考 Query 与共享 Key 的余弦相似度。这个分数实际上衡量的是"该专家认为当前 token 相对于其心目中'平均 token'的**特殊程度**"。
- 分数越高，说明该 token 对该专家的特异刺激愈强，因而该专家被选中。

### 2.4 设计要点

- **低维瓶颈**：采用远小于隐藏层的投影维度（64 维），既形成天然的正则约束，又将语义方向性突显出来；
- **L2 归一化**：Key 与 Query 归一化后置于单位超球面，有效抑制训练中异常大 logits 导致的梯度不稳定，同时使余弦相似度边界有限；
- **动态 EMA 基线**：相比静止的零向量，该线性滑动基线更能反映训练分布缓慢漂移下的"平均状态"，提高路由稳定性。

## 6. 论文的主要结论与发现

1. **性能全面提升**：
   - Top-1 路由的九任务平均零样本准确率由 dMoE 的 41.56% 提升至 42.23%；
   - Top-2 路由继而由 41.78% 提升至 43.43%；
   - 在单个任务（BoolQ、OBQA、RACE）上增益尤为突出。
   - 模型规模增至 469M 后，CoRM 仍保持竞争力（略优于 X-MoE、显著优于 dMoE，与 ReMoE 相当）。

2. **语言建模损失及复杂度同步改善**：在三种配置下，CoRM 验证损失均低于稠密与标准 MoE 的对应数值。

3. **背景抑制的机制验证成立**：
   - 移除 EMA 动态参考状态（改用零参考）后，平均任务得分从 42.23% 降至 41.09%，说明该动态中心的必要性；
   - SVD 显示，减去 EMA 并将特征映射到瓶颈空间后，第一主成分解释方差比从 8% 跃升至 81%，且 50% 方差可由 1 维捕获，显著精简了特征表示。

4. **专家功能独立性增强**：
   - 专家 Query 权重与参考嵌入呈现负的成对余弦相似度（趋近但不完全达到紧框架理论位置），表明专家在语义空间中散布良好；
   - 该独立性由负载均衡损失主动推动（去除该损失后独立性消失），并非恰巧来自初始化。

5. **语言结构专业化明显**：
   - 对所有 UPOS 语法类别（尤其封闭类功能词，如介词、连词、助词、代词等），CoRM 相对 MoE 基准在路由选择分布上表现出显著更高的集中度。
   - 专业化随网络深度逐步提升，表示深层的句法归纳确实发生了。

6. **额外开销几乎可忽略**：该机制仅引入 2.9% 的额外参数与 2.6% 的额外 FLOPs。

## 7. 优点

1. **动机清晰而自然**：从词表示几何的已知各向异性出发，提出将背景剔除纳入路由逻辑，具有较强的可解释性与直观合理性。
2. **方法简洁高效**：设计轻量、与主流 MoE 输入输出格式完全兼容，附加训练/推理成本极低，可作为现有路由模块的即插即用替代方案。
3. **启发式理论支撑**：明确引入了低维瓶颈、L2 归一化、动态 EMA 等结构因素，使路由置信度得以稳定约束，而不严重依赖额外正则损失。
4. **实验验证严谨全面**：可视化、统计显著性测试、消融分析、奇异值分解、功能词类别层面路由分解、分层分析……多角度共同验证假设，证据链条较缜密。
5. **开源可复现**：提供了代码和预训练检查点，方便后续验证与拓展。

## 8. 不足与局限

1. **模型规模仍然较小**：主要实验止步于 469M 激活参数量，未在数亿到数十亿量级（>1B）验证方法有效性。MoE 在超大规模下的收益曲线并不必然线性外推。
2. **超参数迁移问题未解决**：EMA 动量、瓶颈宽度等核心正则量是在 182M 规模调优后才用于 469M 的，未在更大尺度下重新优化，可能实际低估了模型在该规模的应有性能。
3. **参考状态推理时静止**：在推理阶段 EMA 参考是固定的，对长上下文中局部知识领域偏移适应能力有限。
4. **语义解释深度不足**：虽然从几何上证实了背景抑制的存在，但并未真正剖析 EMA 表示捕获的是哪种具体的语法/语义结构，路由此机制属于黑箱层面。
5. **训练数据域单薄且预算受限**：仅使用 The Pile 单语料 30B token，且在较多基准上模型的整体准确率绝对值仍处于较低水平，不足以完全归纳出该路由在“模型能力趋于涌现”时的优势。
6. **聚合各专家进行仅硬路由（Top-1/Top-2）存在天然的表达上限**：与可微软路由（如 Soft MoE、ReMoE 等利用凸组合的方式）相比，离散硬路由的理论极限或许导致部分性能损失。
