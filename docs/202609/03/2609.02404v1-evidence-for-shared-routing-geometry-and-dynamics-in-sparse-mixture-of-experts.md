## 摘要
稀疏混合专家（MoE）模型在每个稀疏层使用独立参数化的路由器为每个词元选择专家。先前的工作表明，跨深度的路由决策通常可以从更早的路由信号中预测，这表明路由在各层之间并非完全独立。然而，这种可预测性背后的结构仍不清楚。在这项工作中，我们提供了证据表明，跨层的路由相关状态共享一种常见的几何结构，而这种结构被各层特定的坐标系所掩盖。我们分离每个路由器的控制子空间，并通过广义正交 Procrustes 分析将这些空间对齐到一个共享的规范表示中。对齐后，一个线性转移的 $R^2$ 达到 0.39--0.71，并保留了分别拟合的层特定动力学预测能力的 79--90%，这表明路由状态演化在很大程度上遵循一种跨深度可复用的过程。然后我们探究这种共享动力学是路由特有的，还是仅仅反映了隐藏表示的平滑演化。匹配秩比较表明，残差表示在跨层时通常更容易预测，而路由器控制状态则更忠实地保留模型的专家选择。这区分了通用跨层可预测性与路由特定信息。最后，我们测试当使用预测的规范状态替代原生路由状态时，它们是否仍然有意义。传输的状态保留了局部路由行为，而学习到的状态演化在 OLMoE 上将 $\Delta\mathrm{NLL}$ 相对于简单持久性降低了 15.7%，在 Phi 上跨越 10 个路由器的范围降低了 6.2%。

## Abstract
Sparse mixture-of-experts (MoE) models use an independently parameterized router at each sparse layer to select experts for every token. Prior work has shown that routing decisions across depth can often be predicted from earlier routing signals, suggesting that routing is not fully independent across layers. However, the structure behind this predictability remains unclear. In this work, we provide evidence that routing-relevant states across layers share a common geometric structure that is obscured by layer-specific coordinate systems. We isolate the control subspace of each router and align these spaces into a shared canonical representation using generalized orthogonal Procrustes analysis. After alignment, a single linear transition reaches $R^2=0.39$--$0.71$ and retains 79--90\% of the predictive power of separately fitted layer-specific dynamics, indicating that much of routing-state evolution follows a reusable process across depth. We then ask whether this shared dynamics is specific to routing or simply reflects the smooth evolution of hidden representations. A matched-rank comparison shows that residual representations are often easier to predict across layers, while router-control states preserve the model's expert choices much more faithfully. This separates generic cross-layer predictability from routing-specific information. Finally, we test whether the predicted canonical states remain meaningful when used in place of native routing states. The transported states preserve local routing behavior, while learned state evolution reduces $Δ\mathrm{NLL}$ relative to simple persistence by 15.7\% on OLMoE and 6.2\% over a 10-router horizon on Phi.

## 一、核心问题与研究动机

- 稀疏 MoE 模型在每个稀疏层配备独立参数化的路由器，以决定每个 token 交由哪些专家处理。虽然已有工作观察到跨层路由决策存在可预测性，但多数分析仍将第 ℓ 层的路由器限制在该层自身的专家索引空间内。
- 本文核心研究问题：**跨层路由可预测性背后的几何结构是什么？不同层的路由相关状态能否被对齐到一个统一的规范表示？**
- 具体而言，作者想验证的不是“路由是否独立”，而是 **MoE 路由器本身是否具有跨层共享的、可复用的动力学结构**——即各层路由器看似不同，是否只是因为采用了各自层特定的坐标系，而实质上演化规律受某一共同过程支配。
- 回答该问题的困难在于：不同层的隐藏表示随深度变化、专家身份逐层不同，直接比较路由器权重或路由 logits 都无法进行有意义的跨层分析。作者为此提出一套“控制子空间 + 规范对齐 + 共享动力学”的分析框架。

## 二、方法论

### 1. 路由器控制因子分解（Router-Control Factorization）

- 路由器 logits 服从 `g = Wℓ hℓ`；由于 softmax 和 top-k 对全体 expert 的共同平移不变，首先将路由器按 expert 维度中心化：`fWℓ = Wℓ − 1E · w̄ℓ⊤`，消除平均行的影响。
- 对中心化后的权值矩阵作紧凑型 SVD：`fWℓ = Bℓ Uℓ⊤`（其中 `Bℓ = AℓSℓ`，秩 r ≤ E−1）。其列向量张成唯一能影响相对专家 logits 的残余流方向，即**路由器控制子空间**。
- 定义控制坐标 `xℓ,t = Uℓ⊤hℓ,t` 和重构 logits `ĝℓ,t = Bℓ xℓ,t`。该重构在完整秩下几乎逐位精确，且不改变原生 top-k 集合与语言模型损失。

### 2. 精确正交规范对称性

- **命题 1（路由器规范不变性）**：任意正交矩阵 `R ∈ O(r)` 作用在 `(Uℓ, Bℓ, xℓ)` 上均保持 `Bℓxℓ` 不变。即控制坐标仅定义到正交旋转等价类 `[Xℓ] = {XℓR : R ∈ O(r)}`。
- 因此跨层比较必须先消除该规范自由度，采用基于 SVD 闭式解的 **正交 Procrustes 距离** `dP([X],[Y]) = min_R ‖XR−Y‖F`。

### 3. 广义正交 Procrustes 分析（GPA）建立全局规范坐标系

- 由于逐对 Procrustes 对齐不一定能得到一个全局一致的坐标系，作者在训练 token 上对所有层联合求解：`min_{Qℓ,M} Σℓ ‖XℓQℓ − M‖F²`，其中 `Qℓ∈O(r)`。最优模板 `M` 是各层对齐后云的平均。
- 该目标等价于最小化层间平均成对距离（文中给出了恒等式证明）。正则化状态为 `zℓ,t = Qℓ⊤ · norm(xℓ,t)`，所有 `Qℓ` 只基于训练序列拟合并固定。

### 4. 共享线性动力学模型

- 在规范坐标系中，单独拟合的逐层转移 `xℓ+1 ≈ Fℓxℓ + cℓ` 经坐标变换后变为 `zℓ+1 ≈ (Q⊤_{ℓ+1}FℓQℓ)zℓ + Q⊤_{ℓ+1}cℓ`。
- 核心假设为：存在单一的低容量共享算子 `A` 使得 `Q⊤_{ℓ+1}FℓQℓ ≈ A` 在多层范围内成立。模型为 `ẑℓ+1 = A zℓ + b`（岭回归拟合，正则化按验证集选择）。
- 共享性指标 `ηshare = R²shared / R²layer-specific`，为一时说明共享转移与独立逐层转移一样强。

### 5. 本征解码与路由稳定性定理

- 将预测的规范状态代回 logits：`ĥℓ = BℓQℓẑ = Dℓẑ`。
- **命题 2（Top-k 稳定性）**：若状态误差的 logits 映射 `‖Dℓe‖∞ < γk/2`（γk 为 top-k 余量），则专家集合不变；在状态空间中给出充分条件 `‖e‖2 < γk / (2‖Dℓ‖_{2→∞})`。
- 该定理将连续的状态预测误差与离散的路由决策联系了起来——同样的误差对边界 token 和稳定 token 影响完全不同。

## 六、主要结论与发现

1. **对齐揭示了可复用跨层动力学**：在原始坐标/随机 Q/PCA-basis/CCA 坐标下共享线性转移均很弱，而正交 Procrustes 对齐后 R² 大幅跃升（图 2a：如 Granite 从 0.07→0.54）。shuffle 几乎消除该增益（Table 7），证明对齐效果来自真实的跨层结构对应关系。
2. **单一共享动力学几乎能达到逐层独立模型的效果**：共享转移模型的 R²=0.39–0.71（具体为 0.385–0.707），ηshare=0.79–0.90（Granite 0.88、OLMoE 0.88、Phi-tiny 0.90、IBM 0.79），参数仅为逐层模型的 ~4%（如 Granite 0.99k vs 22.8k）。
3. **路由特有动力学 ≠ 一般性残差平滑**：匹配秩对比显示，残差 PCA 的跨层可预测性（Next-state R² 0.788–0.861）高于路由器控制态（0.371–0.542），而路由控制态的 top-k recall 高达 0.989–0.999（PCA 只有 0.405–0.798）。说明路由器控制子空间占据的是“更难预测但承载路由决策的关键信息”。
4. **预测性与路由保真度随秩不同而分离**：低秩控制器状态更容易预测共享动力学，但高秩对保留专家选择以及因果传输的效果至关重要；各架构秩-性能曲线趋势不同（OLMoE 分离最明显，IBM 共享专家模型几乎随秩持续增长）。
5. **规范态因果传输在局部有效**：在 Granite 9–13 层，规范+共享转移的 ΔNLL（0.0070）远低于原始坐标（0.1120）和随机子空间（0.1495）；随机规范/随机子空间具有很强的破坏性，证明规范坐标承载了真实的路由信息。
6. **学习动力学优于持久性（在部分架构/长距离上）**：OLMoE 8–9 两路由器传输改进 ΔNLL 0.0059（相对改善 15.7%）；Phi-tiny 在 10 路由器传输范围（层 22–31）改进 0.0200（相对改善约 6.2%）。在长视野中优势更为明显。
7. **该共享结构是局部的、近似的、架构相关的**：IBM 共享专家模型表现出规范几何与可预测性，但显式学习转移并非在所有范围都优于恒等映射。反复跳跃/跳过路由器误差会快速积累，不能当作实用的“路由跳过”加速方法。

## 七、方法亮点/优点

1. **提出了精确的可证明对称性（Proposition 1）**：把“路由器控制状态不唯一”这一问题在数学上明确为 O(r) 规范等价类，整体研究建立在该对称性上，理论根基稳固。
2. **GPA 对齐求解全局规范坐标系**：不只做逐
