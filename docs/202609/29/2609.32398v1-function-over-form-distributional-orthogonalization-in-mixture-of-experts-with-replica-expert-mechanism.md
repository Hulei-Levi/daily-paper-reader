## 摘要
大语言模型（LLM）的扩展越来越依赖 MoE 架构，以将活跃计算量与总参数量解耦。然而，MoE 的有效性常常受到专家坍缩和表示冗余的制约，二者都会导致模型容量利用不足。为应对这些挑战，本文提出分布正交化损失（DO-loss），一种辅助正则化方法，将关注点从静态权重多样性转向动态路由行为。通过将每个专家的 token 分配历史表示为高维二值负载签名，DO-loss 惩罚签名重叠，以防止专家坍缩，同时鼓励功能特化。为使该算法设计与系统效率相匹配，我们进一步引入副本专家机制（REM），其通过双层策略改进负载均衡：在全局批次层面调整副本专家放置，并在微批次层面执行实时 token 调度。实证评估表明，我们的方法在 4.8BA0.5B 和 30BA3B MoE 模型的下游任务上优于所评估的路由算法，同时保持可比的训练效率。

## Abstract
The scaling of LLMs increasingly relies on MoE architectures to decouple active computation from total parameter count. However, the efficacy of MoE is often constrained by expert collapse and representation redundancy, both leading to underutilization of model capacity. To address these challenges, this paper proposes Distributional Orthogonalization Loss (DO-loss), an auxiliary regularization that shifts the focus from static weight diversity to dynamic routing behavior. By representing each expert's token assignment history as a high-dimensional binary load signature, DO-loss penalizes signature overlap to prevent expert collapse while encouraging functional specialization. To align this algorithmic design with system efficiency, we further introduce the Replica Expert Mechanism (REM), which improves load balancing through a two-tiered strategy: adjusting replica expert placement at the global-batch level and performing real-time token dispatching at the micro-batch level. Empirical evaluations demonstrate that our method outperforms the evaluated routing algorithms on downstream tasks for both 4.8BA0.5B and 30BA3B MoE models, while maintaining comparable training efficiency.

## 1. 核心问题与整体含义（研究动机与背景）

- **MoE 的扩展逻辑与瓶颈**：LLM 规模扩展日益依赖 MoE 架构，通过为每个 token 激活稀疏专家子集，将激活计算量与总参数量解耦。但 MoE 的有效性受两大问题制约：
  - **专家坍缩（Expert Collapse）**：热门专家获得更多 token、更新更频繁，形成正反馈循环，少数专家主导、其余闲置。
  - **表示冗余（Representation Redundancy）**：缺乏显式多样性机制时，标准梯度下降难以区分专家功能，多个专家覆盖相似领域。
- **现有方法的割裂与冲突**：
  - **负载均衡损失**（Switch Transformer、Global-LBL）惩罚不均匀分配，但强制均匀会让专家处理不兼容的 token，**抑制专门化**。
  - **参数空间正交化**（Orth-loss、MOORE、AES-MoE）促进权重多样性，但**不保证专家获得输入 token**——专家可以彼此正交却指向输入流形之外。
  - 简单组合两类方法会产生**冲突梯度**，导致训练不稳定；近期在专家输出空间施加正交约束的方案则带来显著计算/通信/内存开销，且与标准分布式训练框架集成困难。
- **论文的核心主张（Function Over Form）**：应把关注点从**静态权重多样性**转向**动态路由行为**；同时将"算法层促进专门化"与"系统层保障负载均衡"彻底解耦——负载均衡本质上是基础设施问题，不应在训练目标中强制解决。

## 2. 方法论

### 2.1 分布正交化损失（DO-loss）

- **核心思想**：将每个专家的 token 分配历史编码为高维二值负载签名，惩罚签名之间的重叠（即路由轨迹重叠），从而直接鼓励功能专门化并自我纠正专家坍缩。
- **二值负载签名**：对 batch 中 m 个 token，专家 i 的负载向量 $F_i \in \{0,1\}^m$，其中 $f_{it} = \mathbb{I}(i \in \text{Top-}K(x_t))$。
- **零和约束（结构关键）**：在 Top-K 路由下，每 token 恰好置 k 位，故所有专家对的汉明距离总和恒定：
  $$\sum_{i=1}^{n}\sum_{j=1}^{n}\|F_i - F_j\|_1 = 2mk(n-k)$$
  在该约束下最小化距离方差，即驱动所有专家对**等距化**，无需显式目标值。
- **抗坍缩机制**：当部分专家闲置（$F_i=0$）时，零和约束迫使活跃专家对呈现更大距离、增大方差；最小化方差即惩罚闲置配置。对闲置专家路由概率的梯度为负，推动路由器重新激活闲置专家（附录 C 给出形式化推导），形成**自纠正负反馈**。
- **梯度流处理**：离散分配阻断梯度，采用**直通估计（STE）**，用 $P_i + \text{sg}[F_i - P_i]$ 替换 $F_i$。
- **代理损失分解**：将损失拆为分离的幅度项 $G_{ij}=\|F_i-F_j\|_1$ 与梯度方向项 $C_{ij}=\sum_t p_{it}(f_{it}-f_{jt})$，最终损失为
  $$L_{DO} = \frac{1}{m^2 k}\sum_{i=1}^{n}\sum_{j=1}^{n} G_{ij}\cdot C_{ij}$$
  归一化系数 $1/(m^2k)$ 在附录 A 中通过平衡态尺度推导得到，使损失量级为 O(1)、可跨熵损失直接比较。
- **全局级正则化（Global-DO-loss）**：利用损失的解耦结构，对距离矩阵 $G_{ij}$ 在 DP 组内做 All-Reduce 同步（全局统计），而梯度方向项 $C_{ij}$ 保持本地计算：
  $$G^g_{ij} = \frac{1}{|D|}\sum_{d\in D} G^d_{ij}, \quad L^{(d)}_{\text{global DO}} = \frac{1}{m^2 k}\sum_{i,j} G^g_{ij}\cdot C^d_{ij}$$
- **总目标**：$L_{total} = L_{CE} + \lambda \cdot L_{DO}$，**不引入任何额外负载均衡辅助项**。计算复杂度 O(mn²)，由于专家数 n（64–256）远小于隐藏维度，开销可忽略。

### 2.2 副本专家机制（REM）

- **动机**：DO-loss 不保证严格负载均衡；专门化必然导致专家吸引不同 token 量。在专家并行（EP）部署中，过载 rank 成为拖慢吞吐的 straggler，并造成内存占用不均、增加 OOM 风险。
- **总体设计**：利用 MoE 训练中"热专家身份在稳定阶段保持一致"的性质，采用**两个解耦控制环**：
  - **全局批次层副本分配**：异步收集 EP 负载统计（滑动平均窗口），在每个全局批次边界贪心放置副本。定义理想 token 阈值 τ（所有 rank 平均负载），用**收益分数 S(e, rs, rr, τ)** 评估将专家 e 的副本从发送 rank $r_s$ 放到接收 rank $r_r$ 的最优可接受 token 量，迭代选择负载最低的 rank 为接收方、最大化 S 的专家进行放置，直到所有副本槽位填满。
  - **微批次层实时调度**：每个微批次开始时通过 AllGather 同步各 GPU 队列深度（仅传 |R| 个整数，开销远小于 AlltoAll），调度器执行 D 次迭代，每次按当前队列深度从轻到重排序 rank 并贪心路由 token，全程在设备上执行、无需全局控制器干预。
- **训练轨迹不变性**：REM 纯属系统级调度，不改变数学训练轨迹：
  - 副本专家独立分配内存，每次前向前异步点对点复制原专家参数（与计算重叠）。
  - 各微批次在副本上独立计算梯度，全局步后累积回原专家 rank 求和。
  - 优化器状态（Adam 动量）仅存于原专家 rank。
  - 三项等价条件（参数同步、梯度求和、仅原 rank 更新优化器）；10,000 步精度测试确认梯度对齐至小数点后三位。

## 6. 主要结论与发现

- **DO-loss 有效**：Global-DO-loss 在 4.8BA0.5B 规模上**全部 7 项指标领先**；在 30BA3B 上保持一致优势，且验证困惑度随 $G_{ij}$ 统计的全局 batch 增大单调改善。
- **正交化目标而非全局统计是主要驱动力**：2×2 消融显示全局统计对 LBL 与 DO-loss 均有增益，但 DO 目标在本地与全局层面均严格优于 LBL；30BA3B 上 Global-LBL 在多数指标上不如 Auxfree，说明收益来自正交化而非全局统计本身。
- **最优 λ 极小**：λ=10⁻⁵（4.8B）/ 5×10⁻⁶（2B），比典型负载均衡损失系数小约两个数量级，原因在于成对高维约束的梯度方差远大于标量辅助损失。
- **专家行为三准则无法被现有方法同时满足**：Auxfree 负载最平但 CKA 冗余最高、Top-K 分数最低；Global-LBL 居中；Orth-loss CKA 最稀疏但负载呈严重指数长尾、有坍缩风险；DO-loss
