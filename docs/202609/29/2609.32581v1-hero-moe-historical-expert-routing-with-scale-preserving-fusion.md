## 摘要
混合专家（MoE）架构已成为在保持计算稀疏的同时扩展模型容量的标准方式，但路由仍是决定 MoE 质量与训练行为的关键因素。已有实证研究表明，MoE 路由反映了输入语义以及跨深度的上游计算，但标准路由器并未显式利用前序层产生的路由分布。我们提出 HERO-MoE，即采用尺度保持融合的历史专家路由（Historical Expert ROuting with Scale-Preserving Fusion），一种通过复用从前序 MoE 层收集的经停止梯度（detached）处理的稠密路由分布，将历史路由先验注入 MoE 路由器的路由框架。其核心思想很简单：HERO-MoE 保留原始的以 token 为条件的路由分支，并在标准 softmax 和 top-k 分派之前加入一个残差历史路由贡献。为了稳定这一历史信号，HERO-MoE 引入一种尺度保持融合机制，使历史路由记忆的幅度与当前隐藏表示相匹配，并考虑可见历史层的数量，同时不引入辅助路由损失或融合专用的调优参数。通过复用前序 MoE 层已经计算出的路由分布，HERO-MoE 以适度的端到端开销提升了训练损失的降低效果。由此得到的路由器仍与标准稀疏分派兼容，包括 top-k 和组限制路由，并可在极小的架构改动下插入现有 MoE 主干。在一个约 8B 参数、0.5B 激活参数的 MoE 模型上，从头在 100B token 上训练的实验表明，HERO-MoE 将最终损失从 1.6393 降至 1.6184，而峰值内存和 FLOPs 分别仅增加 0.44% 和 0.64%。

## Abstract
Mixture-of-Experts (MoE) architectures have become a standard way to scale model capacity while keeping computation sparse, yet routing remains a key determinant of MoE quality and training behavior. Prior empirical studies suggest that MoE routing reflects input semantics and upstream computation across depth, but standard routers do not explicitly use the routing distributions produced by preceding layers. We propose HERO-MoE, Historical Expert ROuting with Scale-Preserving Fusion, a routing framework that injects historical routing priors into MoE routers by reusing detached, dense routing distributions collected from preceding MoE layers. The key idea is simple: HERO-MoE preserves the original token-conditioned routing branch and adds a residual historical routing contribution before the standard softmax and top-$k$ dispatch. To stabilize this historical signal, HERO-MoE introduces a scale-preserving fusion mechanism that matches the magnitude of historical routing memory to the current hidden representation and accounts for the number of visible historical layers, without introducing an auxiliary routing loss or a fusion-specific tuning parameter. By reusing routing distributions already computed by preceding MoE layers, HERO-MoE improves training-loss reduction with modest end-to-end overhead. The resulting router remains compatible with standard sparse dispatch, including top-$k$ and group-limited routing, and can be inserted into existing MoE backbones with minimal architectural changes. Experiments on an approximately 8B-parameter MoE model with 0.5B active parameters, trained from scratch on 100B tokens, show that HERO-MoE reduces the final loss from 1.6393 to 1.6184, while peak memory and FLOPs increase by only 0.44\% and 0.64\%, respectively.

- **整体含义**：论文提出 HERO-MoE，将路由历史视为一种轻量、可解释、无需额外训练目标的结构化先验，为提升 MoE 训练动态与下游泛化提供了一条实用路径。

## 2. 方法论

### 2.1 核心思想

- 保留原始 **token 条件路由分支**（当前隐藏表示 → logits），额外增加一个由前序 MoE 层稠密路由分布驱动的 **残差历史路由分支**；两路 logits 相加后，再走标准的 softmax + top-k 稀疏派发。
- 历史分布经 **停止梯度（StopGrad）** 处理，不向前序路由决策反传梯度，避免扰动已有优化轨迹。

### 2.2 关键技术细节

- **参数化（残差路由）**：
  - 原始分支：`Z_O(l) = X(l) W_O(l)⊤`，形状 `N×E`。
  - 历史记忆：`H(l) = [Q(j1), …, Q(jM_l)]`，其中每个 `Q(j) = StopGrad(softmax(Z(j)))` 为前序层 softmax 后的稠密分布，沿特征维拼接后维度为 `N × M_l·E`。
  - 最终 logits：`Z(l) = Z_O(l) + (ρ(l) ⊙ H(l)) W_R(l)⊤`，其中 `W_R(l) ∈ R^{E × M_l·E}`，`ρ(l)` 为逐 token 的尺度系数（行方向广播）。
  - 实现上等价于把 `X(l)` 与 `ρ(l)⊙H(l)` 在特征维拼接后经单个线性层 `[W_O(l) ‖ W_R(l)]`，当 `M_l = 0` 时精确退化为基线路由器。

- **尺度保持融合（Scale-Preserving Fusion）**：
  - 系数：`ρ(l) = RMS(X(l)) / (RMS(H(l)) + ε) · sqrt((l-1)/M_l)`。
  - 第一项做**动态幅度对齐**，把历史记忆的 RMS 拉到与当前隐藏表示同量级；第二项做**深度补偿**，补偿流水线并行导致可见历史层数减少的情况。
  - RMS 统计量同样为 stop-gradient，故 `ρ(l)` 是纯缩放因子，不产生梯度路径。

- **深度感知初始化**：
  - 初始化上界 `b_l = 1 / sqrt(d + (l-1)E)`，使用**全局层索引**而非局部可见层数，保证初始化不受流水线切分方式影响。
  - 权重按 `U(-b_l, b_l)` 均匀采样；附录 D 证明在该初始化下，初始 router logit 方差恒为 `σ_x²/3`，与深度 `l` 及可见历史层数 `M_l` 无关。

- **阶段局部历史路由（Stage-Local）**：
  - 可见前序层集合 `S(l) = { j | j < l, layer j 与 layer l 位于同一流水线阶段 }`，`M_l = |S(l)|`。
  - 仅在当前流水线阶段内复用历史，**避免跨阶段通信**，不干扰执行调度。
  - 历史分布在该层 logits 计算后、top-k 派发前被即时缓存并供后续层使用。

- **兼容性**：方法只改变供给路由算子的 logits，后续 softmax、top-k、组限制路由、容量处理与 token 派发均保持不变。

### 2.3 算法流程（文字说明）

1. 确定当前层所在流水线阶段内所有可见前序层，得到 `S(l)` 与 `M_l`。
2. 收集这些前序层的稠密路由分布（detached softmax），拼接为 `H(l)`。
3. 计算 RMS 比值与深度补偿因子，得到 `ρ(l)`，对 `H(l)` 做逐 token 缩放。
4. 将 `X(l)` 与缩放后的历史特征拼接，经路由器权重矩阵得到 `Z(l)`。
5. 对 `Z(l)` 做 softmax 得到稠密分布 `Q(l)`，并按配置执行稀疏派发（top-k / 组限制 / 容量控制）。
6. 缓存 `Q(l)` 作为后续层的历史记忆。

## 6. 主要结论与发现

- **训练损失**：最终训练损失从 **1.6393 降至 1.6184**；HERO-MoE 相对基线的优势随训练持续扩大，而 RCP 较早饱和。
- **下游性能**：13 项 benchmark 平均分从 **36.57 提升至 37.42（+0.85）**，9 项任务提升。增益最大的是 HumanEval (+3.66)、ARC-C (+2.31)、MATH (+1.46)、HellaSwag (+1.39)、GSM8K (+1.22)，集中在推理、代码与复杂语义建模任务；MathQA、ARC-E、BBH、CMMLU 略有下降。
- **历史窗口**：mask10 接近完整方法，mask1 明显更弱，说明**中长程路由轨迹比仅用相邻层更有价值**；no-scaling 变体虽也受益，但收敛损失更高，说明尺度保持对历史信号的有效注入至关重要。
- **开销**：峰值显存 +0.44%（+24.2 MiB），总 FLOPs +0.64%，训练墙钟时间 +3.85%；router 自身 FLOPs +87.5%、router 步时 +281%，但路由在整体计算中占比小，故端到端代价可控。
- **可解释性发现**：
  - 学到的层间依赖不局限于相邻层，形成**跨深度轨迹**；相邻层耦合最强，但在 Δ=13、14 等远距离处耦合比例回升。
  - 负耦合占比整体高于正耦合，说明跨层路由历史同时编码**专家竞争/抑制**与协作关系。
  - 专家级耦合矩阵呈结构化红蓝区块，可区分"广谱促进/抑制型源专家""弱影响型源专家"与"对历史不敏感的目标专家"。
- **负载均衡**：基线中 Layer 18 的 Expert 94 独占 13.74% token，HERO-MoE 将峰值专家负载降低 **31.2% 至 9.45%**，缓解 All-to-All 通信的 straggler 问题。
- **理论性质（附录 D）**：基线可精确恢复；历史路径对前序路由参数梯度为零；RMS 校准使可见历史能量等价于 `(l-1)` 个虚拟历史块；深度感知初始化使初始 logit 方差与深度无关。

## 7. 优点

- **方法极简且低侵入**：仅增加一个残差路由分支，不改动 softmax、top-k、组限制路由等标准稀疏派发流程，可低成本插入现有 MoE 主干。
- **无需辅助损失与专用超参**：与正则化类方法相比，不引入损失权重、多方法联调成本或融合专用调优参数。
- **设计动机清晰且相互配套**：stop-gradient 隔离历史梯度、RMS 尺度对齐、深度补偿因子、深度感知初始化四者协同解决"历史信号尺度失稳"这一核心挑战，逻辑自洽。
- **理论支撑较完整**：附录给出基线恢复、梯度隔离、RMS 校准恒等式、深度无关初始方差、分支方差分解等命题，为设计目标提供形式化解释。
- **可解释性价值**：训练后的残差路由权重可直接可视化为层间依赖与专家级协作/竞争矩阵，为 MoE 路由动力学研究提供了新视角。
- **开销透明**：同时给出 router-only 与端到端两套开销口径，未夸大效率优势。
